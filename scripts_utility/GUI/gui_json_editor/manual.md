# Редактор JSON-переменной контекста

## Назначение

Скрипт открывает визуальный редактор для переменной контекста PySM с типом `json`.
Он подходит для настройки сложных параметров, которые хранятся как вложенные
объекты или массивы.

Пример рабочей переменной:

```json
"enhancer_settings": {
  "type": "json",
  "value": {
    "brightness": 1.03,
    "contrast": 1.0,
    "export_watermarks": true
  },
  "read_only": false
}
```

## Аргументы

- `var_name` - имя JSON-переменной контекста.
- `title` - необязательный заголовок окна.
- `msg` - необязательный многострочный HTML-текст над таблицей. Если задан,
  заменяет стандартное сообщение редактора.

Скрипт должен запускаться внутри PySM, потому что читает и сохраняет данные через
`pysm_context`.

Пример `msg`:

```html
<b>Настройки экспорта</b><br>
Проверьте качество JPEG и включение водяных знаков перед запуском финального экспорта.
```

## Схема отображения

Для любой JSON-переменной можно создать связанную служебную схему. Имя схемы
строится из имени переменной и суффикса `__schema`.

Для `enhancer_settings` редактор ищет схему:

```text
enhancer_settings__schema
```

Схема не обязательна. Если ее нет, редактор строит дерево по фактическим типам
значений. Если схема есть, она используется для кратких меток, описаний,
иконок и диапазонов числовых редакторов.

Минимальный пример схемы:

```json
"enhancer_settings__schema": {
  "type": "json",
  "value": {
    "version": 1,
    "title": "Настройки улучшения фото",
    "fields": {
      "brightness": {
        "label": "Яркость",
        "description": "Коэффициент изменения яркости изображения.",
        "widget": "float",
        "min": 0.0,
        "max": 3.0,
        "step": 0.01,
        "icon": "SLIDERS"
      },
      "export_watermarks": {
        "label": "Водяные знаки",
        "description": "Включает или отключает экспорт файлов с водяным знаком.",
        "widget": "bool",
        "icon": "FILE_MASK"
      }
    }
  },
  "read_only": false
}
```

Ключи в `fields` могут быть обычными именами полей (`brightness`) или путями
через точку для вложенных значений (`masters.ubd.graphic_tags`).

`label` - короткое человекочитаемое имя параметра. Если схема содержит
осмысленные `label`, редактор показывает столбец `Метка`.

`description` или `help` - более подробное пояснение, для чего нужен параметр.
Этот текст показывается в нижней панели описания выбранного элемента и в
tooltip при наведении.

## Редактирование самой схемы

Если в `var_name` передать переменную, которая заканчивается на `__schema`,
редактор включает режим редактирования схемы. В этом режиме он не ищет
дополнительную схему для схемы.

Пример:

```text
var_name = enhancer_settings__schema
```

Окно будет подписано как схема для `enhancer_settings`.

В режиме редактирования схемы доступна кнопка `Заполнить свойства`. Она добавляет
к полям внутри `fields` недостающие стандартные свойства:

- `label`
- `description`
- `widget`
- `icon`
- `min`
- `max`
- `step`
- `decimals`

Также эти свойства можно добавить выборочно через контекстное меню поля:
`Свойства схемы`.

При редактировании свойства `widget` редактор показывает выпадающий список
допустимых типов: `string`, `int`, `float`, `bool`, `object`, `array`, `null`.
При редактировании свойства `icon` показывается выпадающий список иконок из
`pysm_lib.pysm_icons`.

## Иконки

В схеме поле может указать иконку:

```json
"icon": "SLIDERS"
```

Используются имена иконок из `pysm_lib.pysm_icons`, например:

- `SLIDERS`
- `SETTINGS`
- `FILE_CODE`
- `FILE_TXT`
- `LIST`
- `ADD`
- `DELETE`
- `LOCK`
- `WARNING`
- `INFO`
- `FILE_MASK`

Если иконка не задана, редактор выбирает ее по типу значения.

## Сохранение и отмена

- `Сохранить` записывает переменную через `pysm_context.set_structured(..., commit=True)`.
- `Отмена` или закрытие окна не сохраняют изменения и завершают скрипт с кодом `0`.
- При закрытии окна с несохраненными изменениями редактор просит подтвердить отказ от сохранения.
- Переменные с `read_only: true` не редактируются.

## Создание схемы

Кнопка `Создать схему` доступна при редактировании обычной JSON-переменной.
Она строит базовую схему по текущей структуре данных и сохраняет ее в
`<var_name>__schema`. После этого схему можно открыть этим же редактором и
дописать метки, диапазоны, подсказки и иконки.
