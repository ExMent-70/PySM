# История изменений gui_json_editor

## 2.2026.08.15

### Изменено

- Параметр скрипта `msg` переименован в `html_content`; публичный Python API
  сохраняет совместимый аргумент `message`.
- Добавлены параметры `html_align`, `html_margin`, `html_padding`,
  `html_output` и `html_style`.
- Пользовательский HTML оформляется стилем активной темы через общий модуль
  `_common/html_dialog.py`.
- Режим `console_dialog` дополнительно выводит HTML-сообщение в консоль PySM,
  а режим `dialog` оставляет его только в окне редактора.
- Перед HTML-блоком в консоли выводится пустая строка для отделения от
  предыдущего скрипта.
- При любом штатном способе закрытия редактора в консоль выводится итоговое
  значение переменной: после сохранения, подтверждения без изменений, отмены
  или закрытия системной кнопкой. Несохранённые правки при отмене не выводятся.

## 2.2026.07.10

### Изменено

- Визуальный редактор перенесен из `run_gui_json_editor.py` в публичный API PySM.
- `run_gui_json_editor.py` оставлен тонкой CLI-оболочкой, которая разрешает аргументы, вызывает API и преобразует результат в код завершения.
- Сохранены существующие аргументы `var_name`, `title` и `msg`, поддержка dotted-путей и схем `<var_name>__schema`.

### Добавлено

- Публичные функции `edit_json_variable()` и `create_json_editor()` через модуль `pysm_lib.pysm_json_editor`.
- Структурированный результат со статусами `SAVED`, `UNCHANGED` и `CANCELLED`.
- Поддержка вызова из существующего Qt-приложения без `sys.exit()` и без завершения общего `QApplication`.
- Автоматические тесты загрузки, сохранения, отмены, read-only переменных и обычных/dotted JSON-путей.
