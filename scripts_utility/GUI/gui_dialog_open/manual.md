# Руководство по скрипту "Выбор файла/папки"
Версия: **2.2026.08.28**

## Назначение

Скрипт показывает системное окно выбора файла или папки и сохраняет результат выбора в переменную Контекста.

Скрипт умеет:
- сохранять полный абсолютный путь либо только имя выбранного объекта;
- начинать выбор с заданной папки;
- запрещать выбор объектов за пределами начальной папки и её подпапок;
- использовать обычные и dotted-переменные контекста.

## Параметры

### Переменная результата (`dlg_open_var`)

Имя переменной контекста, в которую будет записан результат. Поддерживается точечная нотация, например `project.source_photo_dir`.

Значение по умолчанию: `dlg_open_user_var`.

### Тип выбора (`dlg_open_type`)

- `file` — выбрать существующий файл;
- `directory` — выбрать существующую папку.

Значение по умолчанию: `file`.

### Заголовок (`dlg_open_title`)

Текст в заголовке окна выбора. Значение по умолчанию: `Выберите путь`.

### Фильтр файлов (`dlg_open_filter`)

Используется только при `dlg_open_type=file`.

Примеры:

- `Все файлы (*.*)`;
- `Изображения (*.png *.jpg *.bmp)`;
- `Текстовые файлы (*.txt);;Документы CSV (*.csv)`.

### Формат результата (`dlg_open_result_mode`)

- `full_path` — сохранить полный абсолютный путь, например `D:\Фотосессии\Школа 1\JPG\IMG_0001.jpg`;
- `name` — сохранить только имя: `IMG_0001.jpg` для файла или `JPG` для папки.

Значение по умолчанию: `full_path`. Полный путь записывается в переменную контекста имеющую тип `file_path` или `dir_path`, а имя — как обычная строка.

### Начальная папка (`dlg_open_initial_dir`)

Папка, с которой откроется окно выбора. Можно использовать шаблоны контекста:

```text
{photo_session_dir}
{project.source_dir}
```

Относительный путь разрешается по правилам PySM относительно папки коллекции.
Если явно заданная начальная папка не существует, скрипт завершится с ошибкой.

Если параметр пуст, скрипт использует следующий алгоритм выбора начальной папки:

1. существующий путь из `dlg_open_var`, если используется режим `full_path`;
2. `pysm_info.collection_dir`;
3. текущая рабочая папка.

### Ограничить область (`dlg_open_limit_to_initial_dir`)

Определяет, где может находиться выбранный файл или папка:

- `only_in_initial_dir` — только объекты, расположенные непосредственно в `dlg_open_initial_dir`. Сама начальная папка и объекты в её подпапках выбирать нельзя;
- `only_in_initial_dir_and_subfolders` — объекты внутри начальной папки на любом уровне вложенности. Саму начальную папку выбрать нельзя;
- `initial_dir_and_subfolders` — начальная папка и любые объекты внутри неё на любом уровне вложенности;
- `all` — выбор без ограничения области. Значение по умолчанию.

Например, при начальной папке `D:\Проект`:

- `only_in_initial_dir` разрешает `D:\Проект\Фото`, но не разрешает `D:\Проект\Фото\Класс 1`;
- `only_in_initial_dir_and_subfolders` разрешает обе вложенные папки, но не разрешает выбрать `D:\Проект`;
- `initial_dir_and_subfolders` разрешает все три варианта;
- `all` также разрешает выбрать путь вне `D:\Проект`.

Для всех режимов, кроме `all`, параметр `dlg_open_initial_dir` обязателен.
Недопустимый выбор не записывается в контекст: скрипт показывает предупреждение и снова открывает окно из начальной папки. Проверка выполняется по разрешённым абсолютным путям, включая переходы через ссылки и Windows junction.

## Завершение

- Код `0`: пользователь подтвердил допустимый выбор, результат записан.
- Код `1`: пользователь отменил выбор, начальная папка некорректна либо запись в контекст завершилась ошибкой.
