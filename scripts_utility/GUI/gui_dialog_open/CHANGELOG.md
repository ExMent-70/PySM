# История изменений gui_dialog_open

## 2.2026.08.28

### Добавлено

- Режим `dlg_open_result_mode` для сохранения полного пути или только имени.
- Параметр `dlg_open_initial_dir` для явного задания начальной папки.
- Четыре режима `dlg_open_limit_to_initial_dir`: выбор непосредственно в
  начальной папке, на любом уровне внутри неё без выбора самой папки, с выбором
  самой начальной папки либо без ограничений.
- Проверка границ по разрешённым абсолютным путям и повторный выбор после
  попытки указать объект вне разрешённой области.

### Изменено

- `dlg_open_limit_to_initial_dir` изменён с `bool` на строковый параметр
  `choice`; прежние значения `true` и `false` не поддерживаются.
- Синхронизированы имена и значения по умолчанию параметров в коде, паспорте и
  руководстве.
- Удалён неиспользуемый и отсутствовавший в паспорте аргумент `dlg_path`.

## 2.2026.07.07

### Изменено

- Начальное значение и сохранение результата переведены на `context_variable_ops`.
- Добавлена единая поддержка обычных и dotted-переменных контекста.
- Прямой `--help` обрабатывается до проверки managed-run.
