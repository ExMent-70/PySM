# HTML-сообщение с диалогом

Версия: `2.2026.08.29`

## Назначение

Скрипт выводит HTML-текст или содержимое UTF-8 HTML-файла:

- только в HTML-консоль PySM;
- только в модальное диалоговое окно;
- одновременно в консоль и диалог;
- никуда не выводит и сразу успешно завершает работу.

Если показывается диалог, скрипт сохраняет выбор пользователя в переменную
Контекста Коллекции и завершает процесс кодом, который разрешает продолжение
цепочки или останавливает её.

## Источники HTML

Должен быть задан хотя бы один непустой источник:

- `html_content` — HTML-разметка непосредственно в параметрах скрипта;
- `html_file` — путь к файлу в кодировке UTF-8.

Можно указать оба источника. В этом случае сначала выводится `html_content`,
затем содержимое файла. Относительный `html_file` разрешается от папки текущей
Коллекции. Относительные ресурсы внутри HTML-файла, например изображения,
разрешаются от папки самого HTML-файла в диалоговом окне.

Обычные переводы строк в исходном тексте автоматически преобразуются в `<br>`.
Поэтому интервалы и разбиение на строки одинаково сохраняются в консоли PySM и
диалоговом окне; вручную добавлять `<br>` после каждой строки не требуется.

## Режим вывода

Параметр `html_output` принимает одно из четырёх значений:

- `console` — HTML выводится только в консоль. Диалог не создаётся,
  `dlg_msg_var` не изменяется, успешный вывод завершается кодом `0`;
- `dialog` — HTML выводится только в диалог. Результат сохраняется в контекст,
  но HTML и сообщение о выборе в консоль не отправляются;
- `console_dialog` — HTML показывается в обоих местах, а после закрытия диалога
  в консоль также выводится сохранённый результат;
- `none` — скрипт ничего не выводит, не загружает HTML-источники, не создаёт
  диалог, не изменяет `dlg_msg_var` и сразу завершается с кодом `0`.

Перед первым HTML-блоком в консоли выводится пустая строка, отделяющая его от
вывода предыдущего скрипта.

В режимах `console`, `dialog` и `console_dialog` ошибки конфигурации и чтения
файла выводятся независимо от места вывода HTML. В режиме `none` HTML-файл не
читается.

## Оформление HTML

- `html_align` — выравнивание: `left`, `center` или `right`;
- `html_margin` — внешний вертикальный отступ в пикселях;
- `html_padding` — внутренний отступ в пикселях;
- `html_style` — именованный стиль активной темы PySM.

Диалог использует прозрачный HTML-виджет без рамки, поддерживает прокрутку и
изменение размера. Благодаря прозрачному фону свободная область HTML-виджета
совпадает по оформлению с фоном диалогового окна, а HTML-блок занимает всю
доступную ширину области содержимого. Параметры
`dlg_msg_size_width` и `dlg_msg_size_height` задают его начальные размеры.
Искусственные минимальные значения для этих параметров не устанавливаются.
HTML-область сжимается вместе с окном и не задаёт ему отдельную минимальную
высоту.

## Кнопки и переменная результата

Параметр `dlg_msg_type` определяет кнопки:

- `ok` — `OK`;
- `yes_no` — `Да / Нет`;
- `yes_no_cancel` — `Да / Нет / Отмена`.

Подписи отдельных кнопок можно заменить произвольным текстом:

- `dlg_msg_text_ok` — подпись утвердительной кнопки: `OK` в режиме `ok` либо
  `Yes` в режимах `yes_no` и `yes_no_cancel`;
- `dlg_msg_text_no` — подпись кнопки `No`;
- `dlg_msg_text_cancel` — подпись кнопки `Cancel`.

Пустое значение оставляет системную подпись Qt. Параметр применяется только
тогда, когда соответствующая кнопка входит в выбранный `dlg_msg_type`.
Пользовательская подпись изменяет только внешний текст: в Контекст Коллекции
по-прежнему записывается стабильное значение `ok`, `yes`, `no` или `cancel`, а
логика кода выхода не меняется.

Результат записывается строкой в переменную `dlg_msg_var`. Возможные значения:
`ok`, `yes`, `no`, `cancel` и `unknown`. Значение `unknown` используется, если
окно закрыто системной кнопкой или клавишей Escape без выбора стандартной кнопки.

Имя переменной поддерживает точечную нотацию, например
`project.confirmation`.

## Коды выхода

| Тип диалога | Выбор | Код | Действие PySM |
|---|---:|---:|---|
| `ok` | `OK` | `0` | продолжить цепочку |
| `yes_no` | `Да` | `0` | продолжить цепочку |
| `yes_no` | `Нет` | `1` | остановить цепочку |
| `yes_no_cancel` | `Да` | `0` | продолжить цепочку |
| `yes_no_cancel` | `Нет` | `0` | продолжить цепочку |
| `yes_no_cancel` | `Отмена` | `1` | остановить цепочку |
| любой | закрытие окна / Escape | `1` | остановить цепочку |
| режим `none` | — | `0` | продолжить цепочку без вывода |

Ошибки конфигурации, отсутствующий файл, ошибка чтения или невозможность записи
результата в контекст также приводят к коду `1`.

## Пример

Для подтверждения операции с HTML-инструкцией можно задать:

```text
html_file = instructions.html
html_output = console_dialog
dlg_msg_type = yes_no
dlg_msg_var = project.confirmation
dlg_msg_title = Подтверждение операции
dlg_msg_size_width = 900
dlg_msg_size_height = 650
```

После нажатия `Да` в `project.confirmation` будет записано `yes`, и цепочка
продолжится. После нажатия `Нет` будет записано `no`, и цепочка остановится.
