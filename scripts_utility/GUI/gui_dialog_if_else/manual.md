# HTML-диалог с переходом Yes/No

Версия: `2.2026.09.07`

## Назначение и основные понятия

Скрипт объединяет HTML-диалог `gui_dialog_html` и прямое управление потоком
выполнения. Он показывает пользователю HTML-сообщение, сохраняет выбранную
команду в Контекст Коллекции и назначает следующий экземпляр скрипта:

- `Yes` — переход на `instance-id-yes`;
- `No` — переход на `instance-id-no`;
- `Cancel`, Escape или закрытие окна — переход не назначается, цепочка
  останавливается.

`dlg_msg_type` определяет набор кнопок, а `dlg_msg_var` — имя переменной
Контекста Коллекции. Эти параметры имеют разное назначение.

## Параметры запуска

### HTML-содержимое и вывод

- `html_content` — строка с HTML-разметкой;
- `html_file` — путь к UTF-8 HTML-файлу;
- `html_output` — `dialog` или `console_dialog`;
- `html_align` — `left`, `center` или `right`;
- `html_margin` — внешний вертикальный отступ HTML-блока;
- `html_padding` — внутренний отступ HTML-блока;
- `html_style` — стиль оформления из активной темы PySM.

Нужно указать хотя бы один непустой источник: `html_content` или `html_file`.
Если заданы оба, сначала выводится `html_content`, затем содержимое файла.

В режиме `dialog` HTML показывается только в окне. В режиме
`console_dialog` тот же блок показывается и в консоли PySM; перед ним выводится
пустая строка для отделения от вывода предыдущего скрипта.

### Диалог и результат

- `dlg_msg_var` — имя переменной Контекста Коллекции;
- `dlg_msg_type` — `yes_no` или `yes_no_cancel`;
- `dlg_msg_text_ok` — произвольная подпись кнопки `Yes`;
- `dlg_msg_text_no` — произвольная подпись кнопки `No`;
- `dlg_msg_text_cancel` — произвольная подпись кнопки `Cancel`;
- `dlg_msg_title` — заголовок окна;
- `dlg_msg_size_width` — начальная ширина окна;
- `dlg_msg_size_height` — начальная высота окна.

Пользовательские подписи меняют только видимый текст. В `dlg_msg_var`
записывается стабильное значение `yes`, `no`, `cancel` или `unknown`.
`unknown` означает, что окно закрыто системной кнопкой или Escape без выбора
стандартной кнопки.

### Целевые экземпляры

- `instance-id-yes` — обязательный ID экземпляра для ответа `Yes`;
- `instance-id-no` — обязательный ID экземпляра для ответа `No`.

Оба параметра обязательны: каждый допустимый ответ пользователя должен иметь
однозначную ветку выполнения.

## Логика переходов и коды выхода

| Тип диалога | Действие | Сохранённое значение | Переход | Код выхода |
|---|---|---|---|---:|
| `yes_no` | `Yes` | `yes` | `instance-id-yes` | `0` |
| `yes_no` | `No` | `no` | `instance-id-no` | `0` |
| `yes_no_cancel` | `Yes` | `yes` | `instance-id-yes` | `0` |
| `yes_no_cancel` | `No` | `no` | `instance-id-no` | `0` |
| `yes_no_cancel` | `Cancel` | `cancel` | не назначается | `1` |
| любой | Escape / закрытие окна | `unknown` | не назначается | `1` |

Результат сначала сохраняется в Контекст Коллекции, затем для `yes` или `no`
вызывается переход на соответствующий экземпляр. Ошибка конфигурации, чтения
HTML, записи результата или назначения перехода также даёт код `1`.

## Оформление окна

HTML-блок использует активную тему PySM, прозрачный виджет без рамки и те же
правила отступов, что `gui_dialog_html`. Окно можно изменять по размеру;
искусственные минимальные ограничения ширины и высоты не задаются.

## Пример

```text
html_content = <b>Продолжить обработку выбранным способом?</b>
html_output = console_dialog
dlg_msg_type = yes_no_cancel
dlg_msg_var = workflow.branch_choice
dlg_msg_text_ok = Основной вариант
dlg_msg_text_no = Альтернативный вариант
dlg_msg_text_cancel = Остановить
instance-id-yes = 11111111-1111-1111-1111-111111111111
instance-id-no = 22222222-2222-2222-2222-222222222222
```
