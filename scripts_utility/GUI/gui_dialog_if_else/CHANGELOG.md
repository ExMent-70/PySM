# История изменений gui_dialog_if_else

## 2.2026.09.07

### Добавлено

- HTML-текст и UTF-8 HTML-файл с оформлением из активной темы PySM.
- Режимы вывода `dialog` и `console_dialog`.
- Диалоги `yes_no` и `yes_no_cancel` с настраиваемыми подписями кнопок.
- Сохранение результата в Контекст Коллекции с поддержкой точечной нотации.
- Переход на `instance-id-yes` после `Yes` и на `instance-id-no` после
  `No`.
- Остановка цепочки без назначения перехода после `Cancel`, Escape или
  закрытия окна.
- Повторное использование общего HTML-виджета и функций рендеринга из
  `scripts_utility/GUI/_common/html_dialog.py`.
- Регрессионные тесты сохранения результата и выбора ветки для `yes`, `no`,
  `cancel` и закрытия окна.
