# Скрипт "Условный переход"

## 1. Назначение

Скрипт **"Условный переход"** — это мощный инструмент для создания нелинейных рабочих процессов. Он позволяет прервать стандартную последовательность выполнения скриптов и "перепрыгнуть" к любому другому скрипту в рамках текущего набора.

Это дает возможность реализовывать сложную логику, такую как:
-   **Циклы:** вернуться к предыдущему скрипту для повторной обработки.
-   **Ветвление:** в зависимости от какого-либо условия, перейти к разным веткам обработки.

Скрипт поддерживает два режима работы:
1.  **Интерактивный (по умолчанию):** Отображает пользователю диалоговое окно для выбора следующего шага.
2.  **Программный (через параметр):** Осуществляет переход к скрипту с заранее известным ID без участия пользователя.

**Внимание:** Этот скрипт предназначен для продвинутых пользователей и может работать только в среде PySM.

## 2. Параметры

### 2.1. Параметры интерактивного режима

-   **Заголовок окна** (`dlg_goto_title`):
    -   Текст в заголовке диалогового окна.

-   **Текст сообщения** (`dlg_goto_message`):
    -   Текст-приглашение, который отображается над выпадающим списком скриптов.

### 2.2. Параметры программного режима

-   **ID скрипта для перехода** (`dlg_goto_script_id`):
    -   ID экземпляра скрипта, к которому нужно перейти.
    -   Если этот параметр задан, скрипт работает в неинтерактивном режиме, и диалоговое окно не появляется.

## 3. Логика работы

### 3.1. Интерактивный режим (параметр `dlg_goto_script_id` не задан)

1.  При запуске скрипт получает от PySM список всех экземпляров скриптов, которые находятся в том же наборе, что и он сам.
2.  Этот список отображается пользователю в виде диалогового окна с выпадающим списком.
3.  Далее возможны два исхода:
    -   **Пользователь выбирает скрипт и нажимает "OK"**:
        -   PySM получает команду выполнить выбранный экземпляр следующим.
        -   Обычная последовательность прерывается, и управление передается указанному скрипту.
        -   Скрипт завершается с кодом **`0` (Успех)**.
    -   **Пользователь нажимает "Cancel"**:
        -   Выполнение всей цепочки останавливается.
        -   Скрипт завершается с кодом **`1` (Отмена)**.

### 3.2. Программный режим (параметр `dlg_goto_script_id` задан)

1.  Скрипт не отображает никаких диалоговых окон.
2.  Он немедленно передает PySM команду на переход к скрипту с ID, указанным в параметре `dlg_goto_script_id`.
3.  Скрипт завершается с кодом **`0` (Успех)**.
