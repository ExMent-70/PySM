# HTML-диалог пользовательского ввода

Версия: `2.2026.08.14`

## Назначение

Скрипт показывает изменяемое диалоговое окно с HTML-приглашением и полем
ввода. Введённое значение проверяется, преобразуется в выбранный тип и
сохраняется в Контекст Коллекции.

При успешном вводе скрипт завершается кодом `0`. При нажатии `Cancel`, закрытии
окна или критической ошибке возвращается код `1`, поэтому дальнейшая цепочка
PySM останавливается.

## HTML-приглашение

Параметр `html_content` заменяет прежний `dlg_input_msg` и поддерживает
HTML-разметку. Обычные переводы строк автоматически преобразуются в `<br>`.

Оформление задаётся параметрами:

- `html_style` — именованный стиль активной темы PySM;
- `html_align` — `left`, `center` или `right`;
- `html_margin` — внешний вертикальный отступ;
- `html_padding` — внутренний отступ цветного HTML-блока.

HTML-виджет прозрачен, не имеет рамки и поддерживает прокрутку. Свободная
область виджета совпадает с фоном диалогового окна. Его внешние границы
совпадают с границами расположенного ниже поля ввода.

## Режим вывода

Параметр `html_output` определяет, куда выводится `html_content`:

- `dialog` — только в диалоговое окно;
- `console_dialog` — в диалог и HTML-консоль PySM.

Диалог показывается в обоих режимах, поскольку без него невозможно получить
ввод пользователя. Сообщение об успешно сохранённом результате выводится в
консоль независимо от `html_output`, как и в предыдущей версии скрипта.
Перед HTML-блоком в режиме `console_dialog` выводится пустая строка, отделяющая
его от вывода предыдущего скрипта.

## Размер и кнопки

- `dlg_input_size_width` — начальная ширина окна в пикселях;
- `dlg_input_size_height` — начальная высота окна в пикселях;
- `dlg_input_text_ok` — произвольная подпись кнопки `OK`;
- `dlg_input_text_cancel` — произвольная подпись кнопки `Cancel`.

Пустая подпись оставляет системное название Qt. Пользовательский текст меняет
только внешний вид кнопки и не влияет на её действие или exit-код.

HTML-область не задаёт минимальную высоту окна: при уменьшении диалога она
сжимается первой, сохраняя место для поля ввода и кнопок.

## Значение и Контекст Коллекции

- `dlg_input_var` — имя переменной результата. Поддерживается точечная нотация,
  например `project.id`;
- `dlg_input_dvalue` — начальный текст, если переменная ещё отсутствует в
  контексте;
- если переменная уже существует, её текущее значение имеет приоритет над
  `dlg_input_dvalue`.

После успешной проверки значение сохраняется через общий `InputProcessor`.

## Преобразование типа

Параметр `dlg_input_value_type` принимает значения:

- `auto` — автоматическое распознавание строки, числа или логического значения;
- `string`;
- `int`;
- `float`;
- `bool`;
- `json`.

## Валидация

Параметр `dlg_input_valid_type` поддерживает:

- `none` — без проверки;
- `not_empty` — непустое значение;
- `filename_txt` — допустимое имя TXT-файла;
- `dirname_windows` — допустимое имя папки Windows;
- `integer` — целое число;
- `positive_integer` — положительное целое число или ноль;
- `float` — число с плавающей точкой;
- `email` — адрес электронной почты;
- `custom` — пользовательское регулярное выражение.

Для режима `custom` используются:

- `dlg_input_custom_regexp` — регулярное выражение;
- `dlg_input_custom_regexp_desc` — понятное пользователю описание формата.

Если проверка не прошла, скрипт показывает предупреждение и снова открывает
диалог. Последнее введённое значение сохраняется в поле, чтобы его можно было
исправить.

## Коды выхода

| Событие | Код | Результат |
|---|---:|---|
| Корректный ввод и `OK` | `0` | Значение сохранено, цепочка продолжается |
| `Cancel` | `1` | Значение не изменяется, цепочка останавливается |
| Закрытие окна | `1` | Значение не изменяется, цепочка останавливается |
| Ошибка конфигурации или сохранения | `1` | Цепочка останавливается |

## Пример

```text
dlg_input_var = project.id
dlg_input_title = Ввод ID проекта
html_content = <b>Введите ID проекта</b><br>Формат: ABC-1234
html_output = console_dialog
html_style = script_description
dlg_input_valid_type = custom
dlg_input_custom_regexp = ^[A-Z]{3}-\d{4}$
dlg_input_custom_regexp_desc = Введите ID в формате ABC-1234.
dlg_input_text_ok = Сохранить
dlg_input_text_cancel = Остановить
dlg_input_size_width = 800
dlg_input_size_height = 500
```
