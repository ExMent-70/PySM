# История изменений gui_dialog_input

## 2.2026.08.14

### Изменено

- `dlg_input_msg` заменён на поддерживающий HTML параметр `html_content`.
- `QInputDialog` заменён на изменяемый `QDialog` с общим прозрачным
  HTML-виджетом без рамки и отдельным полем ввода.
- HTML можно выводить только в диалог или одновременно в диалог и консоль PySM.
- Оформление HTML-блока выбирается из активной темы PySM; добавлены параметры
  выравнивания и отступов.
- Добавлены параметры размера окна и произвольных подписей кнопок `OK` и
  `Cancel`.
- Убраны искусственные минимальные значения ширины и высоты диалога.
- Убраны внутренние поля документа и горизонтальные поля таблицы HTML-виджета,
  чтобы границы HTML-блока и поля ввода совпадали по ширине.
- HTML-область больше не ограничивает минимальную высоту диалога.
- Перед HTML-блоком в консоли выводится пустая строка для отделения от
  предыдущего скрипта.
- Общая HTML-логика используется из `_common/html_dialog.py`.
- Значение, имя переменной и сообщение об успехе безопасно выводятся в консоль,
  а существующая валидация, преобразование типов и exit-коды сохранены.

## 2.2026.07.07

### Изменено

- Валидация, преобразование и сохранение ввода унифицированы через `InputProcessor`.
- Сохранение dotted-переменных и сообщения об успехе переведены на общий API PySM.
- Fallback-конфигурация сохраняет работоспособность прямого `--help` без импортов PySM API.
