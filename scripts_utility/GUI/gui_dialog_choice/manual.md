# HTML-диалог выбора из списка

Версия: `2.2026.08.14`

## Назначение

Скрипт показывает изменяемое диалоговое окно с HTML-приглашением и выпадающим
списком. Выбранная строка сохраняется в Контекст Коллекции.

При подтверждении скрипт завершается кодом `0`. При нажатии `Cancel` или
закрытии окна результат не сохраняется, возвращается код `1), и дальнейшая
цепочка PySM останавливается.

## HTML-приглашение

Параметр `html_content` заменяет прежний `dlg_choice_message` и поддерживает
HTML-разметку. Обычные переводы строк автоматически преобразуются в `<br>`.

Оформление задаётся параметрами:

- `html_style` — именованный стиль активной темы PySM;
- `html_align` — `left`, `center` или `right`;
- `html_margin` — внешний вертикальный отступ;
- `html_padding` — внутренний отступ цветного HTML-блока.

HTML-виджет прозрачен, не имеет рамки и поддерживает прокрутку. Его внешние
границы совпадают с границами расположенного ниже выпадающего списка.

## Режим вывода

Параметр `html_output` определяет, куда выводится `html_content`:

- `dialog` — только в диалоговое окно;
- `console_dialog` — в диалог и HTML-консоль PySM.

Диалог показывается в обоих режимах, поскольку в нём выполняется выбор.
Сообщение о сохранённом результате выводится в консоль независимо от режима.
Перед HTML-блоком в режиме `console_dialog` выводится пустая строка, отделяющая
его от вывода предыдущего скрипта.

## Список и начальный выбор

- `dlg_choice_list` — список доступных вариантов;
- `dlg_choice_dvalue` — начальный вариант, если переменная ещё отсутствует в
  контексте;
- `dlg_choice_var` — переменная для сохранения результата. Поддерживается
  точечная нотация, например `project.processing_mode`.

Если в Контексте Коллекции уже есть значение из списка, оно имеет приоритет над
`dlg_choice_dvalue`. Если ни одно начальное значение не найдено, выбирается
первый элемент списка. Пустые строки списка игнорируются.

## Размер и кнопки

- `dlg_choice_size_width` — начальная ширина окна в пикселях;
- `dlg_choice_size_height` — начальная высота окна в пикселях;
- `dlg_choice_text_ok` — произвольная подпись кнопки `OK`;
- `dlg_choice_text_cancel` — произвольная подпись кнопки `Cancel`.

Искусственные минимальные значения ширины и высоты не устанавливаются. Qt может
самостоятельно увеличить совсем маленькое окно только до размера, необходимого
выпадающему списку и кнопкам; HTML-область не ограничивает уменьшение высоты.

Пользовательские подписи меняют только внешний вид кнопок: подтверждение
сохраняет выбор, отмена всегда возвращает код `1`.

## Пример

```text
dlg_choice_var = project.processing_mode
dlg_choice_title = Выбор режима
html_content = <b>Выберите режим обработки</b><br>Он будет применён ко всей серии.
html_output = console_dialog
html_style = script_description
dlg_choice_list =
  Быстрая обработка
  Качественная обработка
  Только экспорт
dlg_choice_dvalue = Качественная обработка
dlg_choice_text_ok = Продолжить
dlg_choice_text_cancel = Остановить
dlg_choice_size_width = 500
dlg_choice_size_height = 250
```

После подтверждения выбранная строка будет доступна через
`project.processing_mode`.
