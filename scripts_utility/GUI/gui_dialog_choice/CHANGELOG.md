# История изменений gui_dialog_choice

## 2.2026.08.14

### Изменено

- `dlg_choice_message` заменён на поддерживающий HTML параметр `html_content`.
- `QInputDialog` заменён на изменяемый `QDialog` с прозрачным HTML-виджетом
  без рамки и выпадающим списком.
- HTML можно выводить только в диалог или одновременно в диалог и консоль PySM.
- Оформление HTML-блока выбирается из активной темы PySM; добавлены параметры
  выравнивания и отступов.
- Добавлены параметры начального размера окна без искусственных минимальных
  значений и произвольные подписи кнопок `OK` и `Cancel`.
- Общая HTML-логика используется из `_common/html_dialog.py`.
- Границы HTML-блока и выпадающего списка выровнены по ширине за счёт удаления
  внутренних полей документа и горизонтальных полей HTML-таблицы.
- HTML-область больше не навязывает окну собственную минимальную высоту, поэтому
  диалог можно уменьшать до высоты, необходимой списку и кнопкам.
- Перед HTML-блоком в консоли выводится пустая строка для отделения от
  предыдущего скрипта.
- Сохранены приоритет начального значения, поддержка dotted-переменных и
  управление цепочкой кодами выхода `0` и `1`.

## 2.2026.07.07

### Изменено

- Чтение и запись переменных переведены на общие API `InputProcessor` и `context_variable_ops`.
- Добавлена единая поддержка обычных и dotted-ключей и стандартное форматирование сообщений PySM.
- Прямой `--help` обрабатывается до проверки managed-run.
