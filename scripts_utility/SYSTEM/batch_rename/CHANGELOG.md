# История изменений batch_rename

## 2.2026.07.17

### Изменено

- Сохранена сортировка по времени создания, времени изменения, имени или исходному порядку, при этом временные метаданные читаются только на этапе сортировки.
- Ускорено построение плана переименования за счёт отказа от многократного `Path.resolve()` для каждого файла.
- Занятые целевые имена определяются одним чтением каталога вместо пофайловых проверок `exists()`.
- Проверка конфликтов учитывает уже назначенные целевые имена и отображает прогресс.
- Удалены токены шаблона `%created_date%` и `%created_time%`.
- Справка `--help` корректно отображает токены шаблона без ошибки форматирования `argparse`.
