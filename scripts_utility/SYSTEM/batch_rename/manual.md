# Руководство по скрипту "Пакетное переименование файлов" (2.2026.05.10)

## 1. Назначение

Скрипт переименовывает файлы в папке после выбранной сортировки: по дате создания, по дате изменения, по имени или без сортировки.

Основной сценарий - RAW-файлы с карты памяти фотоаппарата. Когда камера доходит до номера `9999`, она создает новую папку и начинает нумерацию с `0001`. После объединения файлов в одну папку сортировка по имени ломает хронологию. По умолчанию скрипт выстраивает файлы по времени изменения и выдает новые имена уже в правильном порядке.

## 2. Параметры

- **Папка с файлами** (`br_source_dir`): папка, в которой находятся файлы для переименования. Поддерживает переменные контекста PySM вида `{var_name}`.
- **Паттерны файлов** (`br_include`): glob-паттерны для выбора файлов. По умолчанию `*.CR3`.
- **Шаблон имени** (`br_template`): шаблон итогового имени файла. По умолчанию `%prefix%%index%%suffix%%ext%`.
- **Префикс** (`br_prefix`): значение токена `%prefix%`.
- **Суффикс** (`br_suffix`): значение токена `%suffix%`.
- **Первый номер** (`br_start_index`): стартовое значение индекса. По умолчанию `1`.
- **Количество цифр** (`br_index_digits`): ширина индекса. По умолчанию `4`, поэтому номера выглядят как `0001`, `0002`, `0003`.
- **Действие при конфликте** (`br_on_conflict`):
  - `error`: остановить операцию, если итоговое имя уже занято.
  - `skip`: пропустить файл с конфликтующим именем.
  - `rename`: подобрать уникальное имя с числовым суффиксом.
- **Метод сортировки** (`br_sort_method`):
  - `created_time`: по дате создания файла.
  - `modified_time`: по дате изменения файла. Используется по умолчанию.
  - `name`: по имени файла.
  - `none`: без сортировки.
- **Режим работы** (`br_mode`):
  - `rename`: реально переименовать файлы.
  - `dry_run`: только показать план переименования.
- **Рекурсивный поиск** (`br_recursive`): искать файлы во вложенных папках. Нумерация остается общей, но каждый файл переименовывается внутри своей текущей папки.

Скрипт всегда приводит расширение в токене `%ext%` к нижнему регистру и всегда заменяет недопустимые для Windows символы в итоговом имени файла.

## 3. Токены Шаблона

Скрипт использует токены вида `%token%`, чтобы не конфликтовать с переменными контекста PySM вида `{var_name}`.

Доступные токены:

- `%index%`: порядковый номер после выбранной сортировки.
- `%ext%`: исходное расширение файла, например `.CR3`.
- `%stem%`: исходное имя без расширения, например `PR5_5403`.
- `%name%`: полное исходное имя файла, например `PR5_5403.CR3`.
- `%prefix%`: значение параметра `br_prefix`.
- `%suffix%`: значение параметра `br_suffix`.
- `%created_date%`: дата изменения файла в формате `YYYY-MM-DD`.
- `%created_time%`: время изменения файла в формате `HH-MM-SS`.

Примеры:

```text
%index%%ext%                  -> 0001.CR3
RAW_%index%%ext%              -> RAW_0001.CR3
{session_name}_%index%%ext%   -> Выпуск_11А_0001.CR3
%created_date%_%index%%ext%   -> 2026-05-09_0001.CR3
```

## 4. Важное Про Переменные PySM

Фигурные скобки `{...}` обрабатываются PySM до запуска логики скрипта. Например:

```text
{session_name}_%index%%ext%
```

Сначала PySM заменит `{session_name}` на значение из контекста, а затем скрипт заменит `%index%` и `%ext%`.

Шаблон `br_template` должен задавать только имя файла, без папок. Скрипт не перемещает файлы между директориями.

## 5. Безопасность

Переименование выполняется в два этапа:

1. Все файлы получают временные служебные имена.
2. Временные имена заменяются на финальные.

Это защищает операцию от конфликтов между старыми и новыми именами.

Перед реальным запуском рекомендуется выбрать `br_mode: dry_run` и проверить план переименования в логе PySM.

## 6. Коды Выхода

- `0`: операция выполнена успешно, либо dry-run успешно показал план.
- `1`: произошла ошибка, например исходная папка не найдена или обнаружен конфликт имен в режиме `error`.
