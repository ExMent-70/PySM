# История изменений

## 2.2026.07.16

- Удалена специальная установка внешнего wheel InsightFace 0.7.3 для `cp311`.
- InsightFace 1.0.1 устанавливается с `--no-deps`, чтобы зависимость CPU `onnxruntime` не подменила `onnxruntime-gpu`.
- Удалён принудительный pin `numpy==1.26.4`; версия NumPy теперь определяется корневым `requirements.txt`.
- Добавлена постпроверка пакета `onnxruntime-gpu`, отсутствия конфликта CPU/GPU-дистрибутивов и наличия CUDA/TensorRT provider.
- `requirements.txt` стал единственным источником точных версий InsightFace и NumPy; неоднозначные, отсутствующие и дублирующиеся требования блокируются до установки.
- Для специальных команд Torch и ONNX Runtime динамически создаётся временный constraint с NumPy из requirements.
- При обнаружении CPU-пакета `onnxruntime` он удаляется, после чего `onnxruntime-gpu` принудительно переустанавливается для восстановления общих файлов.
- Ошибка чтения метаданных ONNX-дистрибутивов теперь блокирует установку вместо молчаливого пропуска проверки конфликта.
- Постпроверка сравнивает фактические версии InsightFace и NumPy с динамически прочитанными pins.
- `inst_plan_only` всегда показывает отдельную команду InsightFace с `--no-deps` и не оставляет временный constraint.
