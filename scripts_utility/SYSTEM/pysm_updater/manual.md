# 🔄 PySM System Updater (v2025.12.08)

## 1. Назначение
Скрипт предназначен для автоматического обновления ядра системы PySM и всех входящих в комплект скриптов напрямую из репозитория GitHub. Это позволяет поддерживать актуальность версий без ручного копирования файлов.

## 2. Как это работает
1.  **Бэкап:** Скрипт архивирует текущее состояние папки PySM в папку `_backups` (внутри корня проекта). Если что-то пойдет не так, вы всегда сможете восстановить старую версию.
2.  **Скачивание:** Загружает ZIP-архив ветки `main` (или другой указанной) с GitHub.
3.  **Установка:** Распаковывает файлы поверх существующих. Новые файлы добавляются, старые заменяются.
    *   *Примечание:* Скрипт пытается определить корневую папку внутри ZIP-архива (например, `PySM-main`) и распаковывает содержимое этой папки в корень вашей установки, чтобы избежать дублирования папок.

## 3. Параметры

*   **`repo_url`**: Ссылка на скачивание архива.
    *   Для публичных репозиториев формат: `https://github.com/ExMent-70/PySM/archive/refs/heads/main.zip`
*   **`token`**: Если ваш репозиторий приватный, здесь нужно указать Personal Access Token (PAT) от GitHub.
*   **`target_dir`**: Куда ставить обновление. Обычно определется автоматически (текущая папка PySM).
*   **`no_backup`**: Если отмечено, резервная копия создаваться не будет (быстрее, но опаснее).

## 4. Важные замечания
*   После завершения обновления **рекомендуется перезапустить PyScriptManager**, чтобы он подхватил изменения в коде ядра.
*   Если в обновлении есть новые библиотеки, проверьте консоль на наличие сообщения о `requirements.txt` и установите их через `pip`.
