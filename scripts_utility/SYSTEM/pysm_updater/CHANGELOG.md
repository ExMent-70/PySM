# Changelog

## 2026-08-30

- Обычное обновление больше не блокируется из-за локальных изменений `config.toml` и файлов из `script_collections/`.
- Если такие данные пересекаются с файлами обновления, updater сохраняет их в отдельный ZIP-архив, применяет fast-forward и возвращает локальную версию.
- Намеренно удаленные настройки и коллекции не восстанавливаются автоматически; отсутствующие файлы кода и ресурсов приложения по-прежнему восстанавливаются.
- Перед `force` теперь всегда создается отдельный архив всех существующих tracked-файлов в `_backups`, независимо от параметра `no_backup`.

## 2026-07-16

- Булев параметр `dry_run` заменен единым явным режимом `update_mode=plan|apply`.
- PySM и автономный CLI теперь используют одинаковые значения: `plan` только показывает изменения, `apply` выполняет обновление.
- Безопасным значением по умолчанию во всех режимах остается `plan`.

## 2026-07-14

- После успешного Git-обновления updater сравнивает хеш `requirements.txt` до и после применения изменений.
- Для portable-установки с `pysm-setup` создает marker отложенной синхронизации зависимостей; сам updater не запускает пакетный менеджер и не меняет активный venv.
