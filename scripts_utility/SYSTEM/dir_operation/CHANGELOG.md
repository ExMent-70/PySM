# История изменений

## 2.2026.11.05

- Режим `delete` удаляет только файлы по маскам `do_include`, а затем пустые папки, включая исходную.
- Символические ссылки и точки соединения пропускаются, маски с путями отклоняются.
- Файлы и опустевшие папки отправляются в корзину Windows; при её недоступности операция завершается ошибкой.

## 2.2026.10.09

- Добавлен режим `delete`, удаляющий исходную папку со всем содержимым через API PySM.
- Для удаления не требуется папка назначения; маски и параметры копирования игнорируются.
- Обновлены паспорт и руководство; описаны безвозвратность и ограничения удаления.
