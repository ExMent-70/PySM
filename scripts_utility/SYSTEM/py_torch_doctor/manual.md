# Диагностика PyTorch и CUDA

## Назначение

Скрипт проверяет не только обнаружение GPU библиотекой PyTorch, но и фактическое выполнение небольшой операции CUDA на каждом доступном устройстве.

Используйте его:

- после установки или обновления PyTorch;
- если рабочий скрипт сообщает об ошибке CUDA;
- если сводная диагностика видит GPU через драйвер, но не подтверждает работу PyTorch;
- для проверки нескольких GPU в одном окружении.

## Что проверяется

1. **Окружение Python** — версия и путь интерпретатора.
2. **Импорт PyTorch** — версия пакета, CUDA сборки и cuDNN.
3. **Доступность CUDA** — результат `torch.cuda.is_available()`, количество и свойства всех устройств.
4. **Практическая операция** — на каждом GPU создаётся маленький тензор, умножается на два, результат возвращается на CPU и проверяется.

Тест использует несколько чисел и занимает пренебрежимо малый объём видеопамяти. Он не является тестом производительности или стабильности под длительной нагрузкой.

## Как читать отчёт

- **Успех** — компонент доступен или тестовая операция выполнена корректно.
- **Предупреждение** — проверка неполна, но критического сбоя не обнаружено.
- **Ошибка** — PyTorch не загрузился, CUDA недоступна или операция на конкретном GPU завершилась сбоем.
- **Информация** — сведения об обнаруженном устройстве.

Главный результат находится в разделе «Итоговое заключение». Если устройств несколько, итог считается полностью успешным только после теста каждого GPU.

## Типичные результаты

### PyTorch не установлен

Скрипт сообщает об этом по-русски и завершает отчёт без необработанного исключения. Устанавливать пакет нужно именно в тот Python, путь к которому указан в первом разделе.

### Установлена сборка только для CPU

В строке «CUDA сборки PyTorch» будет указано, что это CPU-сборка. Такая установка не сможет использовать GPU NVIDIA независимо от наличия драйвера.

### Сборка поддерживает CUDA, но GPU не найден

Проверьте драйвер NVIDIA, доступность устройства для текущего процесса и совместимость версии драйвера со сборкой PyTorch. Для сравнения сведений драйвера запустите `py_gpu_doctor`.

### Одно устройство не проходит практический тест

Изучите технические сведения именно для этого GPU. Возможны нехватка доступной памяти, ошибка драйвера, ограничение видимости устройства или повреждённая установка библиотек CUDA Runtime.

## Требования и ограничения

- Нужен пакет `torch`.
- Для успешной GPU-проверки нужна сборка PyTorch с CUDA и рабочий драйвер NVIDIA.
- Проверка создаёт только временные тензоры в оперативной памяти и памяти GPU.
- Скрипт не создаёт файлы, не очищает кеш PyTorch и не меняет настройки системы.
- Успех маленькой операции подтверждает базовую работоспособность, но не гарантирует стабильность конкретной большой модели.
