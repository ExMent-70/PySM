# Скрипта "Удаление переменной" (v2025.11.19)

## 1. Назначение

Скрипт **"Удаление переменной"** предназначен для управления чистотой контекста приложения.
Он поддерживает удаление как отдельных переменных, так и полную очистку всех пользовательских данных.

## 2. Параметры

-   **Имя переменной** (`remove_var_name`) **[Обязательно]**:
    -   **Для удаления одной переменной:** Введите точное имя переменной (например, `my_temp_file`).
    -   **Для полной очистки:** Введите слово **`all`** (или `ALL`). В этом случае будут удалены ВСЕ пользовательские переменные.
    
    *Примечание: Системные переменные защищены и не будут удалены даже при команде `all`.*

-   **Строгий режим** (`remove_fail_if_missing`):
    -   Имеет смысл только при удалении конкретной переменной.
    -   **False (По умолчанию):** Игнорировать отсутствие переменной.
    -   **True:** Выдавать ошибку, если переменная не найдена.
    -   *При использовании режима `all` этот параметр игнорируется.*

## 3. Примеры использования

### Пример 1: Удаление конкретного значения
Очистка пути к временному файлу после обработки.
*   `remove_var_name`: `temp_result_path`

### Пример 2: Полный сброс (Global Reset)
Очистка всех данных перед началом новой большой задачи.
*   `remove_var_name`: `all`

### Пример 3: Строгая проверка удаления
Мы хотим убедиться, что флаг ошибки существовал и был удален. Если его не было — это подозрительно.
*   `remove_var_name`: `error_flag`
*   `remove_fail_if_missing`: `True`

## 4. Коды выхода

-   **Code 0 (Успех):** Операция выполнена успешно.
-   **Code 1 (Ошибка):**
    -   Имя переменной не указано.
    -   Переменная не найдена (в строгом режиме).
    -   Переменная защищена от удаления.
