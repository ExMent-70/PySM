# Скрипт "HWID Scanner" (v2025.12.07)

## 1. Назначение

Этот скрипт является вспомогательной утилитой безопасности. Он предназначен для получения уникального цифрового отпечатка (HWID) компьютера пользователя. Сгенерированный код используется разработчиком для создания персональной версии программного обеспечения, защищенной от копирования и запуска на неавторизованных устройствах.

**Ключевые особенности:**
*   **Безопасность:** Скрипт не собирает личные данные, пароли или файлы. Он считывает только заводской серийный номер (UUID) материнской платы.
*   **Автономность:** Не требует установки сторонних библиотек, работает на стандартном Python.

## 2. Логика работы

1.  **Определение окружения:** Скрипт проверяет операционную систему (Windows, Linux или macOS), чтобы выбрать подходящий метод опроса оборудования.
2.  **Запрос к оборудованию:**
    *   **Windows:** Выполняет системный запрос `wmic csproduct get uuid` для получения уникального идентификатора материнской платы.
    *   **Linux/Mac:** Использует стандартный модуль `uuid` для получения аппаратного адреса.
3.  **Хеширование:** Полученная строка с серийным номером не выводится в открытом виде. Она мгновенно преобразуется в необратимый хеш по алгоритму **SHA-256**.
4.  **Вывод результата:** Скрипт выводит финальный HWID (длинную строку из букв и цифр) в консоль.

## 3. Порядок использования

Скрипт не принимает входящих параметров командной строки, взаимодействие происходит в интерактивном режиме.
Запуск скрипта возможен как в программе PySM, так и через терминал.

1.  **Запуск:**
    *   Запустите файл `get_pc_hwid.py` двойным кликом мыши.
    *   *Альтернативно:* Запустите через терминал командой `python get_pc_hwid.py`.

2.  **Получение кода:**
    *   В окне консоли появится сообщение: `Ваш базовый HWID: <код>`.
    *   Выделите и скопируйте этот код.

3.  **Передача разработчику:**
    *   Отправьте скопированный код разработчику.
    *   Нажмите `Enter` в окне консоли для завершения работы утилиты.

**Возможные ошибки:**
*   Если скрипт выдает ошибку доступа или не может получить UUID, попробуйте запустить его **от имени Администратора** (правой кнопкой мыши -> "Запуск от имени администратора" для командной строки).
