# Скрипт "Вывод HTML в консоль" (v2025.12.28)

## 1. Назначение

Скрипт позволяет выводить произвольную HTML-разметку напрямую в консоль приложения PyScriptManager. Это мощный инструмент для создания кастомных отчетов, отображения таблиц, форматированного текста, встроенных фреймов или любых других элементов, поддерживаемых HTML-движком консоли.

## 2. Логика работы

Скрипт работает следующим образом:
1.  Принимает на вход строку с HTML-кодом и/или путь к файлу.
2.  Если переданы оба параметра, сначала берется текст из строки, а затем к нему присоединяется содержимое файла.
3.  Полученный итоговый HTML оборачивается в контейнер с заданными параметрами стилизации (выравнивание, отступы).
4.  Вызывает функцию API `pysm_context.log_html()`, которая рендерит результат в консоли.

> **Важно:** Необходимо указать хотя бы один источник данных (либо текст, либо файл).

## 3. Параметры

-   **HTML-текст** (`html_content`):
    -   Строка, содержащая HTML-теги. Удобно для вывода заголовков, коротких сообщений или динамически сформированных шаблонов.
    -   *Необязательный параметр (если указан файл).*

-   **Файл с HTML** (`html_file`):
    -   Путь к файлу, содержимое которого будет прочитано и выведено как HTML.
    -   Позволяет загружать большие шаблоны или предварительно сгенерированные отчеты.
    -   *Необязательный параметр (если указан текст).*

-   **Выравнивание** (`html_align`):
    -   Определяет, как блок с контентом будет расположен в консоли.
    -   Доступные варианты: `left` (слева), `center` (по центру), `right` (справа).
    -   *Значение по умолчанию:* `left`.

-   **Вертикальный отступ** (`html_margin`):
    -   Число, определяющее отступ сверху и снизу от блока в пикселях. Полезно для визуального отделения контента от других сообщений лога.
    -   *Значение по умолчанию:* `5`.
