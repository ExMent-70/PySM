# Скрипт "Изменение числовой переменной контекста" (v2.2026.07.07)

## 1. Назначение

Скрипт предназначен для увеличения или уменьшения числового значения переменной контекста без взаимодействия с пользователем.

Он используется в цепочках PySM, когда нужно автоматически изменить счетчик, индекс, номер шага или любое другое числовое значение.

Типовые задачи:

- увеличить счетчик на `1`;
- уменьшить значение переменной на заданное число;
- изменить порядковый номер текущей итерации;
- обновить числовой параметр между этапами цепочки;
- сохранить новое значение обратно в контекст.

## 2. Параметры

Скрипт принимает следующие аргументы командной строки.

### Имя переменной (`inc_var_name`) [Обязательно]

Имя переменной контекста, значение которой нужно изменить. Поддерживается точечная нотация для вложенных JSON-значений, например `project.counter`.

Пример:

```text
counter
````

```text
project.counter
```

Перед запуском скрипта переменная должна уже существовать в контексте и содержать числовое значение.

### Значение изменения (`inc_delta`) [Обязательно]

Число, на которое нужно изменить текущее значение переменной.

Примеры:

```text
1
```

```text
10
```

```text
0.5
```

Допускаются целые и дробные значения.

### Операция (`inc_operation`)

Определяет, как изменить значение переменной.

Варианты:

* `add` — увеличить значение;
* `subtract` — уменьшить значение.

Значение по умолчанию:

```text
add
```

### Тип результата (`inc_value_type`)

Определяет, в каком виде сохранить новое значение.

Варианты:

* `auto` — определить тип автоматически;
* `int` — сохранить как целое число;
* `float` — сохранить как число с плавающей точкой.

Значение по умолчанию:

```text
auto
```

## 3. Логика работы

1. Скрипт получает имя переменной из параметра `inc_var_name`.
2. Читает текущее значение этой переменной из контекста.
3. Преобразует текущее значение в число.
4. Преобразует значение `inc_delta` в число.
5. Выполняет операцию:

   * `add`: текущее значение + `inc_delta`;
   * `subtract`: текущее значение - `inc_delta`.
6. Форматирует результат согласно параметру `inc_value_type`.
7. Сохраняет новое значение обратно в ту же переменную контекста.

## 4. Особенности типов

### Режим `auto`

Если результат является целым числом, он будет сохранен без дробной части.

Пример:

```text
5 + 1 = 6
```

Если результат дробный, он будет сохранен как дробное число.

Пример:

```text
5 + 0.5 = 5.5
```

### Режим `int`

Результат должен быть целым числом.

Пример успешного результата:

```text
5 + 1 = 6
```

Пример ошибки:

```text
5 + 0.5 = 5.5
```

В этом случае скрипт завершится с ошибкой, потому что результат не является целым числом.

### Режим `float`

Результат сохраняется как число с плавающей точкой.

Пример:

```text
5 + 1 = 6.0
```

```text
5 + 0.5 = 5.5
```

## 5. Примеры использования

### Пример 1. Увеличить счетчик на 1

* `inc_var_name`: `counter`
* `inc_delta`: `1`
* `inc_operation`: `add`
* `inc_value_type`: `auto`

Если до запуска:

```text
counter = 5
```

После запуска:

```text
counter = 6
```

### Пример 2. Уменьшить значение на 1

* `inc_var_name`: `current_index`
* `inc_delta`: `1`
* `inc_operation`: `subtract`
* `inc_value_type`: `auto`

Если до запуска:

```text
current_index = 10
```

После запуска:

```text
current_index = 9
```

### Пример 3. Увеличить дробное значение

* `inc_var_name`: `exposure_offset`
* `inc_delta`: `0.25`
* `inc_operation`: `add`
* `inc_value_type`: `float`

Если до запуска:

```text
exposure_offset = 1.5
```

После запуска:

```text
exposure_offset = 1.75
```

## 6. Ошибки

Скрипт завершится с ошибкой, если:

* переменная `inc_var_name` не найдена в контексте;
* текущее значение переменной пустое;
* текущее значение переменной не является числом;
* значение `inc_delta` не является числом;
* выбран неизвестный тип результата;
* выбран неизвестный тип операции;
* выбран режим `int`, но результат получился дробным;
* не удалось сохранить новое значение в контекст.

## 7. Коды выхода

### Код выхода `0` — Успех

Означает, что:

* переменная была успешно прочитана;
* числовая операция выполнена;
* новое значение сохранено обратно в контекст.

### Код выхода `1` — Ошибка

Означает, что операция не была выполнена.

При ошибке новое значение в контекст не сохраняется, а выполнение цепочки может быть остановлено настройками PySM.

## 8. Рекомендации

Для счетчиков и индексов рекомендуется использовать:

```text
inc_value_type = auto
```

или:

```text
inc_value_type = int
```

Для дробных параметров рекомендуется использовать:

```text
inc_value_type = float
```

Если нужно просто увеличивать счетчик на единицу, используйте:

```text
inc_delta = 1
inc_operation = add
inc_value_type = auto
```
