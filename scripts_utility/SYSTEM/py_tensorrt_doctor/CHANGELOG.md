# История изменений

## 2.2026.07.16

- Добавлен единый русскоязычный формат диагностики со статусными значками PySM.
- Проверки прямого API TensorRT и ONNX Runtime стали независимыми.
- Заключение больше не приравнивает регистрацию провайдера к гарантированной работе любой модели.
- Добавлена отдельная проверка `CUDAExecutionProvider` и безопасная сборка минимального движка в памяти.
- Полностью переработано руководство пользователя.
