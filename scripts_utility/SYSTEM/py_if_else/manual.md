# Руководство по скрипту "Условный переход (If-Then-Else)"

## 1. Назначение

Скрипт реализует условную маршрутизацию выполнения в PyScriptManager.

Он проверяет значение переменной контекста по заданному условию и выбирает одну из веток выполнения:

* Then — условие истинно;
* Else — условие ложно.

Если ветка Else не указана, выполнение продолжается к следующему скрипту набора по умолчанию.

Скрипт является неинтерактивным и полностью управляется параметрами.

---

## 2. Поддерживаемые типы данных

Скрипт может работать со следующими типами:

* string
* number
* bool
* json
* auto

В режиме auto тип определяется автоматически по фактическому значению переменной.

---

## 3. Поддержка dot-notation

Для доступа к вложенным данным можно использовать точечную нотацию.

Примеры:

```text
wf_school_info.city
psd_meta.width
templates.0.name
users.5.email
```

Поддерживаются:

* словари (dict)
* списки (list)

---

## 4. Операторы сравнения

### равно

Проверяет равенство значений.

Для строк сравнение выполняется без учёта регистра.

Примеры:

```text
Yes == yes
SUCCESS == success
```

Результат:

```text
TRUE
```

---

### не равно

Проверяет неравенство значений.

Для строк сравнение выполняется без учёта регистра.

---

### больше

Числовое сравнение.

Пример:

```text
15 > 10
```

---

### меньше

Числовое сравнение.

Пример:

```text
5 < 10
```

---

### больше или равно

Числовое сравнение.

Пример:

```text
10 >= 10
```

---

### меньше или равно

Числовое сравнение.

Пример:

```text
10 <= 10
```

---

### содержит

Проверяет наличие значения.

Для строк:

```text
"Hello World" содержит "world"
```

Результат:

```text
TRUE
```

Для списков:

```text
["red", "green", "blue"]
```

проверяется наличие элемента.

Для словарей проверяется наличие ключа.

---

### не содержит

Обратная операция к оператору "содержит".

---

### пусто

Возвращает TRUE для:

```text
None
""
[]
{}
```

Возвращает FALSE для:

```text
0
False
```

---

### не пусто

Обратная операция к оператору "пусто".

---

### существует

Проверяет существование переменной или вложенного ключа.

Примеры:

```text
wf_school_info
wf_school_info.city
templates.0.name
```

---

### не существует

Обратная операция к оператору "существует".

---

## 5. Очистка переменной

Параметр:

```text
--clear-variable
```

Если флаг установлен, проверяемая переменная удаляется после вычисления условия.

Поддерживается удаление:

Верхнеуровневой переменной:

```text
wf_school_info
```

Вложенного ключа:

```text
wf_school_info.city
```

Элемента массива:

```text
templates.0
```

---

## 6. Логика выполнения

Последовательность работы:

1. Получение параметров.
2. Проверка существования переменной.
3. Получение значения переменной.
4. Вычисление условия.
5. Очистка переменной (если включено).
6. Установка следующего скрипта.
7. Завершение работы.

---

## 7. Примеры использования

### Проверка статуса обработки

Параметры:

```text
if-variable-name = processing_status
if-operator = равно
if-comparison-value = success
if-value-type = string
```

Если значение:

```text
SUCCESS
```

результат будет:

```text
TRUE
```

и выполнение перейдёт в ветку Then.

---

### Проверка ширины документа

Параметры:

```text
if-variable-name = psd_meta.width
if-operator = больше
if-comparison-value = 4000
if-value-type = number
```

Если ширина больше 4000 пикселей, будет выполнен переход в Then.

---

### Проверка существования ключа

Параметры:

```text
if-variable-name = wf_school_info.city
if-operator = существует
```

Если ключ присутствует в контексте, условие считается истинным.

---

### Проверка пустого списка

Параметры:

```text
if-variable-name = override_labels
if-operator = пусто
```

Если список пуст:

```json
[]
```

результат будет TRUE.

---

### Проверка булевого значения

Параметры:

```text
if-variable-name = export_enabled
if-operator = равно
if-comparison-value = true
if-value-type = bool
```

Поддерживаются варианты:

```text
true
false
yes
no
on
off
да
нет
1
0
```

---

## 8. Особенности

* Строковые сравнения выполняются без учёта регистра.
* Для строк используется casefold().
* Поддерживаются вложенные структуры JSON.
* Поддерживаются элементы списков через индексы.
* Все значения в логах безопасно экранируются для HTML.
* Ошибки преобразования типов не приводят к аварийному завершению скрипта.
* При невозможности выполнить сравнение условие считается ложным и выводится предупреждение.
