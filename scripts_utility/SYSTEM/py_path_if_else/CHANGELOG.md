# История изменений py_path_if_else

## 2.2026.07.10

### Добавлено

- Read-only проверки существования и типа файловых путей.
- Проверки пустых и непустых папок.
- Поиск файлов по одному или нескольким glob-шаблонам.
- Опциональный рекурсивный поиск во вложенных папках.
- Безопасная проверка glob-шаблонов без выхода за целевую папку.
- Маршрутизация `Then`, `Else` и стандартное продолжение выполнения.
- Подробный HTML-безопасный отчёт о результате условия.
