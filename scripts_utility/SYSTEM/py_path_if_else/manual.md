# Руководство по скрипту «Условный переход по пути»

## 1. Назначение

`py_path_if_else` выполняет read-only проверку файла или папки и выбирает ветку
выполнения набора PySM:

- `Then` — условие истинно;
- `Else` — условие ложно;
- стандартное продолжение — условие ложно, но ветка `Else` не задана.

Скрипт не создаёт, не изменяет, не перемещает и не удаляет файлы или папки.

## 2. Параметры

### `checked-path`

Путь к проверяемому объекту. Можно использовать шаблоны переменных контекста:

```text
{wf_session_path}/Output
{wf_session_path}/Output/result.jpg
```

В managed-запуске относительный путь разрешается от папки текущей коллекции
PySM. При прямом запуске — от текущей рабочей директории.

Параметр имеет тип `string`, потому что один и тот же скрипт должен принимать
путь к файлу, путь к папке и ещё не существующий путь.

### `condition`

Выбирает файловое условие. Все доступные варианты описаны ниже.

### `patterns`

Список glob-шаблонов для поиска файлов. Каждый шаблон задаётся с новой строки:

```text
*.jpg
*.jpeg
*.png
```

Значение по умолчанию:

```text
*
```

Шаблоны используются только условиями `папка содержит файлы` и
`папка не содержит файлы`. Из результатов поиска всегда исключаются папки.

Шаблон должен быть относительным. Абсолютные пути и сегменты `..` запрещены,
чтобы поиск не выходил за пределы проверяемой папки.

### `recursive`

Если включено, поиск файлов выполняется во всех вложенных папках. Если выключено,
проверяется только непосредственно указанная папка.

Параметр применяется только к условиям поиска файлов.

### `then-instance-id`

Обязательный ID экземпляра скрипта для перехода при результате `TRUE`.

### `else-instance-id`

Необязательный ID экземпляра скрипта для перехода при результате `FALSE`. Если
он не задан, PySM продолжит выполнение набора по стандартному порядку.

## 3. Условия

### `путь существует`

Возвращает `TRUE`, если указанный путь существует. Объект может быть файлом или
папкой.

### `путь не существует`

Возвращает `TRUE`, если по указанному пути нет существующего объекта.

### `файл существует`

Возвращает `TRUE`, если путь ведёт к существующему файлу. Для существующей папки
результат будет `FALSE`.

### `файл не существует`

Возвращает `TRUE`, если путь не ведёт к существующему файлу. Результат будет
истинным и для отсутствующего пути, и для существующей папки.

### `папка существует`

Возвращает `TRUE`, если путь ведёт к существующей папке.

### `папка не существует`

Возвращает `TRUE`, если путь не ведёт к существующей папке. Результат будет
истинным и для отсутствующего пути, и для существующего файла.

### `папка пуста`

Возвращает `TRUE`, если папка существует и не содержит никаких непосредственных
элементов. Даже пустая вложенная папка делает родительскую папку непустой.

### `папка не пуста`

Возвращает `TRUE`, если папка существует и содержит хотя бы один файл или одну
подпапку.

### `папка содержит файлы`

Возвращает `TRUE`, если найден хотя бы один файл, соответствующий одному из
`patterns`. Настройка `recursive` определяет, проверяются ли вложенные папки.

### `папка не содержит файлы`

Возвращает `TRUE`, если не найдено ни одного файла, соответствующего шаблонам.
Существующие подпапки сами по себе не считаются файлами.

## 4. Примеры

### Проверка существования готового файла

```text
checked-path = {wf_session_path}/Output/report.html
condition = файл существует
then-instance-id = open_report
else-instance-id = create_report
```

### Проверка пустой папки

```text
checked-path = {wf_session_path}/Output
condition = папка пуста
then-instance-id = prepare_output
else-instance-id = process_output
```

### Поиск изображений в одной папке

```text
checked-path = {wf_session_path}/Capture
condition = папка содержит файлы
patterns =
    *.jpg
    *.jpeg
    *.png
recursive = false
```

### Рекурсивный поиск RAW-файлов

```text
checked-path = {wf_session_path}/Capture
condition = папка содержит файлы
patterns =
    *.CR3
    *.NEF
    *.ARW
recursive = true
```

## 5. Обработка нестандартных ситуаций

- Если условию нужна папка, но путь отсутствует, результат будет `FALSE`.
- Если условию нужна папка, но путь ведёт к файлу, результат будет `FALSE`.
- Если содержимое папки невозможно прочитать, результат будет `FALSE`, а в лог
  попадёт предупреждение без необработанного traceback.
- Пустой список шаблонов для файлового поиска является ошибкой конфигурации.
- Один файл, найденный несколькими шаблонами, учитывается один раз.

## 6. Логирование

Скрипт выводит:

- абсолютный проверяемый путь;
- условие;
- признаки существования, файла и папки;
- glob-шаблоны и режим рекурсии;
- число найденных файлов;
- до десяти первых совпадений;
- результат `TRUE/FALSE`;
- выбранную ветку и целевой `instance_id`.

Пути, шаблоны и сообщения ошибок безопасно экранируются для HTML-лога PySM.
