# Cкрипт "Копирование переменной" (v2025.11.19)

## 1. Назначение

Скрипт **"Копирование переменной"** предназначен для дублирования данных внутри контекста приложения PyScriptManager. Он берет значение одной переменной и сохраняет его под другим именем.

**Ключевая особенность:** Скрипт сохраняет **типы данных**. Если исходная переменная была числом, списком или путем к файлу, новая переменная получит тот же тип, а не просто строковое представление.

## 2. Параметры

Скрипт принимает следующие параметры:

-   **Имя исходной переменной** (`copy_source_var`) **[Обязательно]**:
    -   Имя переменной (ключа), данные из которой нужно взять.
-   **Имя целевой переменной** (`copy_target_var`) **[Обязательно]**:
    -   Имя переменной, в которую будут записаны данные. Если переменная с таким именем уже существует, она будет перезаписана.
-   **Строгий режим** (`copy_fail_if_missing`):
    -   **True (по умолчанию):** Скрипт завершится с ошибкой (код 1), если исходная переменная не найдена. Это полезно для отладки логики.
    -   **False:** Скрипт просто запишет предупреждение в лог и завершит работу успешно (код 0), ничего не скопировав. Используйте это, если наличие переменной необязательно.

## 3. Примеры использования

### Пример 1: Создание резервной копии (Backup)
Перед выполнением сложной операции, которая может изменить данные, мы хотим сохранить оригинал текста.
*   `copy_source_var`: `processed_text`
*   `copy_target_var`: `processed_text_backup`
*   `copy_fail_if_missing`: `True`

### Пример 2: Адаптация имен переменных (Mapping)
Один скрипт (например, распознавание лиц) выдает результат в переменную `recognition_result`, а следующий скрипт в цепочке (сторонний модуль) ожидает входные данные строго в переменной `input_data`.
*   `copy_source_var`: `recognition_result`
*   `copy_target_var`: `input_data`

## 4. Коды выхода

-   **Code 0 (Успех):**
    -   Переменная успешно скопирована.
    -   ИЛИ исходная переменная не найдена, но параметр `copy_fail_if_missing` установлен в `False`.
-   **Code 1 (Ошибка):**
    -   Исходная переменная не найдена (и включен строгий режим).
    -   Ошибка записи в контекст (например, целевая переменная защищена от записи или системная ошибка ввода-вывода).
