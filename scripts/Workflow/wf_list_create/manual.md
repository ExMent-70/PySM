# Руководство по использованию: Редактор списков v1.1.1

## 1. Назначение

**"Редактор списков"** — небольшой скрипт с графическим интерфейсом для формирования списка класса/группы для фотосъемки. Скрипт импортирует неструктурированные данные, приводит их к единому формату, позволяет редактировать список и генерировать готовые к печати и экспорту документы.

---

## 2. Обновления в версии 1.1.1

-   **Визуализация парсинга:** Ячейки "Фамилия" и "Имя" в таблице теперь **раскрашиваются** в те же цвета, что и в предпросмотре на вкладке "Результат разбора". Это позволяет мгновенно оценить корректность парсинга и найти строки с ошибками (например, где имя и фамилия перепутаны местами).
-   **Интерактивная раскраска:**
    -   При смене имени и фамилии местами (через контекстное меню) **цвета ячеек также меняются местами**.
    -   При добавлении новой строки вручную ячейки сразу получают "правильные" цвета по умолчанию (синяя фамилия, зеленое имя).
-   **Гибкое автосохранение:** Добавлен новый параметр `wf_autosave_formats`, который позволяет точно настроить, какие файлы (`html`, `txt`, `csv`) будут автоматически сохраняться вместе с основным `.list` файлом.
-   **Сохранение и загрузка цветов:** Информация о цветах теперь сохраняется в `.list` файл и корректно загружается при повторном открытии списка.
-   **Исправление логики загрузки:** Устранена критическая ошибка, из-за которой при загрузке сохраненного списка индивидуальные цены учеников перезаписывались общей ценой из выпадающего списка. Теперь итоговая сумма всегда считается корректно.

## 3. Параметры запуска

Скрипт принимает следующие параметры:

-   **`wf_dest_dir`**:
    -   **Назначение:** Папка по умолчанию для сохранения всех файлов.
    -   **Источник:** Обычно автоматически заполняется из переменной контекста `session_path`.

-   **`wf_output_txt_file`**:
    -   **Назначение:** Позволяет указать точный, полный путь для сохранения файла `children.txt`. Если этот параметр задан, он имеет наивысший приоритет.
    -   **Источник:** Может быть установлен в контексте для сложных рабочих процессов.

-   **`wf_autosave_formats`**:
    -   **Назначение:** Управляет тем, какие дополнительные файлы будут созданы автоматически при сохранении основного `.list` файла.
    -   **Допустимые значения:** `html`, `txt`, `csv`. Можно выбрать несколько.
    -   **Значение по умолчанию:** `html`, `txt`.

## 4. Интерфейс приложения

Окно приложения разделено на несколько логических зон:

### 4.1. Верхняя панель
-   **Название класса:** Поле, автоматически заполняется из имени папки сессии. Рядом есть кнопка для быстрого открытия этой папки.
-   **Вид фотоуслуги:** Выпадающий список с основными видами услуг. При изменении услуги автоматически меняется цена для **всех** учеников в таблице. Список услуг и цен загружается из файла `_services.json`.
-   **Стоимость:** Нередактируемое поле, показывающее цену для выбранной услуги.

### 4.2. Левая панель (с вкладками)
-   **Вкладка "Ввод":**
    -   **Режим разбора:** Позволяет выбрать один из двух алгоритмов:
        -   `Интеллектуальный (Natasha)`: Рекомендуемый режим. Использует лингвистические модели для извлечения имен и фамилий.
        -   `Простой (по шаблону)`: Базовый режим, который ожидает, что в строке сначала идет фамилия, а потом имя.
    -   **Сырой список:** Текстовое поле для вставки скопированного списка учеников.
    -   **Кнопка "Обработать список":** Запускает парсинг текста и заполняет таблицу справа.
-   **Вкладка "Результат разбора":**
    -   Здесь отображается визуализация работы "Интеллектуального" парсера. Слова, распознанные как **Фамилия**, подсвечиваются синим, а как **Имя** — зеленым. Это помогает быстро оценить корректность разбора.

### 4.3. Правая панель
-   **Обработанный список:** Основной рабочий инструмент в виде таблицы. Ячейки "Фамилия" и "Имя" подсвечиваются для быстрой проверки.
-   **Итоги:** Под таблицей отображается актуальное количество учеников и общая сумма по всем услугам.

## 5. Работа с таблицей

Таблица обладает расширенной интерактивностью для удобного редактирования:

-   **Редактирование:** Дважды кликните на ячейку в редактируемых столбцах ("№ съемки", "Фамилия", "Имя", "Услуга", "Стоимость"), чтобы изменить ее значение.
-   **Навигация:** Используйте **Enter** и **стрелки вверх/вниз** для быстрого перемещения между ячейками в режиме редактирования.
-   **Валидация:** Система не позволит ввести некорректные данные (например, неуникальный номер съемки) и покажет сообщение об ошибке.
-   **Сортировка:** Кликните на заголовок столбца "№ съемки" или "Фамилия" для сортировки.
-   **Контекстное меню (правый клик мыши):**
    -   `Добавить строку`: Добавляет нового "Ученика" в конец списка.
    -   `Поменять Имя/Фамилию`: Меняет местами значения и **цвета** в ячейках "Имя" и "Фамилия".
    -   `Удалить выделенные строки`: Удаляет все выделенные строки.

---

## 6. Файловые операции (меню "Файл")

-   **Загрузить список...:** Позволяет выбрать и загрузить любой `.list` файл.
-   **Сохранить список (`Ctrl+S`):** Сохраняет все данные (включая цвета) в файл `.list` и запускает автосохранение других форматов.
-   **Сохранить как CSV...:** Экспортирует текущие данные в файл формата CSV (кодировка **UTF-16**, разделитель **;**).
-   **Экспортировать для обработки:** Сортирует таблицу по "№ съемки" и сохраняет результат (только ФИО) в текстовый файл (`children.txt`).

---

## 7. Кастомизация

-   **Услуги и цены:** Вы можете редактировать файл `_services.json`, который находится в той же папке, что и скрипт, чтобы изменить список услуг и их стоимость.
-   **Нормализация имен:** Вы можете добавлять свои варианты сокращенных имен в файл `_names_normalization.json`, чтобы улучшить их автоматическое преобразование в полные.

## 8. Зависимости

Для установки всех зависимостей выполните команду `pip install -r requirements.txt` или запустите файл `install_requirements.bat`

-   **PySide6:** Основной фреймворк для создания графического интерфейса.
-   **regex:** Продвинутая библиотека для работы с регулярными выражениями.
-   **natasha:** Библиотека для извлечения именованных сущностей из текста на русском языке.
-   **pymorphy3:** Морфологический анализатор (зависимость для natasha).
-   **ipymarkup:** Библиотека для подсветки и визуализации результатов разбора текста.
-   **Jinja2:** Шаблонизатор для генерации HTML-отчетов.
-   **beautifulsoup4:** Библиотека для парсинга HTML (используется для извлечения цветов).
