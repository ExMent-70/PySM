# Скрипт "Редактор списков" (v2026.01.11)

## 1. Назначение

**"Редактор списков"** — приложение с графическим интерфейсом для формирования списка класса/группы для фотосъемки. Скрипт позволяет:
*   Импортировать неструктурированные текстовые списки.
*   Автоматически разделять имена и фамилии (Smart Parsing).
*   Управлять услугами и рассчитывать итоговую стоимость.
*   **Новое:** Добавлять любую дополнительную информацию (цитаты, соцсети, даты) через динамические поля.
*   Генерировать отчеты (HTML, CSV) и файлы для автоматизации (TXT).

## 3. Параметры запуска

Скрипт принимает следующие параметры:

-   **`wf_dest_dir`**: Папка по умолчанию для сохранения файлов.
-   **`wf_output_txt_file`**: Полный путь для сохранения файла `children.txt`.
-   **`wf_autosave_formats`**: Форматы автосохранения (`html`, `txt`, `csv`).
-   **`wf_default_info_fields`** (Новое): Список строк. Пример: `["Цитата", "Любимый предмет"]`. Если указано, эти колонки будут созданы в таблице автоматически при запуске.

## 4. Работа с данными

### 4.1. Основная таблица
Таблица теперь поддерживает **динамические колонки**.
-   **Базовые колонки:** № съемки, Фамилия, Имя, Услуга, Доп. услуги, Итого.
-   **Пользовательские колонки:** Появляются справа, если вы добавите их через меню "Настройки".
-   **Расчет стоимости:** Колонка "Итого" не редактируется вручную. Она вычисляется автоматически: *Цена услуги + Сумма доп. услуг*.

### 4.2. Дополнительная информация (Цитаты и др.)
Для работы с данными, отличными от имени и цены, используется механизм Info Fields.

1.  **Настройка полей:**
    *   Перейдите в `Настройки -> Настроить поля информации...`.
    *   Здесь можно создать новые поля (например, "Цитата"), переименовать их или изменить порядок. Изменения применятся ко всей таблице.

2.  **Заполнение данных:**
    *   **Вариант А:** Писать прямо в ячейки таблицы (для коротких текстов).
    *   **Вариант Б:** Использовать расширенный редактор.
        *   Выберите ученика и нажмите `Ctrl+I` (или ПКМ -> Редактировать информацию).
        *   Откроется окно с большими текстовыми полями.
        *   **Навигация:** Используйте кнопки "Предыдущий/Следующий" или клавиши `Ctrl + ←` / `Ctrl + →` для переключения между учениками без закрытия окна.

## 5. Экспорт

### 5.1. HTML Отчет
Теперь есть два варианта сохранения (в меню "Файл"):
1.  **Сохранить HTML:** Создает компактный отчет (только имена и услуги).
2.  **Сохранить полный HTML:** Добавляет в отчет блок с дополнительной информацией (цитаты и т.д.) под именем каждого ученика.

### 5.2. CSV
При экспорте в CSV все пользовательские поля (Цитата, Хобби) добавляются как новые столбцы в конце файла. Кодировка файла — UTF-16LE, разделитель — точка с запятой (`;`), что гарантирует корректное открытие в Excel.

## 6. Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| **Ctrl + N** | Добавить новую строку |
| **Delete** | Удалить выделенные строки |
| **Ctrl + T** | Поменять местами Имя и Фамилию (и их цвета) |
| **Ctrl + E** | Редактировать доп. услуги (Extra Services) |
| **Ctrl + I** | Редактировать доп. информацию (Info Editor) |
| **Ctrl + S** | Сохранить список |
| **Ctrl + P** | Печать HTML |

---

## 7. Технические детали

*   **Шаблоны:** Скрипт использует файл `_list_template.html` для генерации отчетов. Если вы обновили скрипт, а шаблон старый, программа автоматически создаст резервную копию старого шаблона (`.old.html`) и запишет новый актуальный шаблон.
*   **Конфиги:** Файлы настроек (`_services.json`, `_names_normalization.json`) хранятся рядом со скриптом.
