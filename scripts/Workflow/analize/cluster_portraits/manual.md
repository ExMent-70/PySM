# Руководство: Кластеризация портретов (v2026.01.24)

## 1. Назначение

Скрипт **"Кластеризация портретов"** предназначен для автоматической группировки фотографий лиц. Он анализирует векторные представления (эмбеддинги) лиц с портретных снимков и объединяет их в группы (кластеры), где каждая группа соответствует одному уникальному человеку.

После формирования групп скрипт присваивает им имена из заранее подготовленного списка, основываясь на хронологии появления человека в кадре.

## 2. Логика работы

1.  **Загрузка данных:**
    *   Скрипт считывает эмбеддинги из папки `_Embeddings`, расположенной рядом с указанным JSON-файлом.
    *   Загружается список имен. Если основной файл имен не найден, скрипт автоматически ищет файл `children.txt` в той же директории.

2.  **Кластеризация:**
    *   Запускается выбранный алгоритм (`DBSCAN` или `HDBSCAN`).
    *   Алгоритм распределяет лица по кластерам. Лица, которые не удалось уверенно отнести ни к одной группе (например, размытые, закрытые глаза, единичные случайные кадры), помечаются меткой `-1` (Шум/Noise).

3.  **Присвоение имен:**
    *   Для каждого сформированного кластера определяется время его "старта" (по имени файла самого раннего снимка в группе).
    *   Кластеры выстраиваются в очередь по времени.
    *   Имена из списка присваиваются по порядку: 1-е имя -> 1-му кластеру, 2-е имя -> 2-му кластеру и т.д.

4.  **Сохранение:**
    *   Результат записывается в `info_portrait_faces.json` (поля `cluster_label` и `child_name`).

## 3. Параметры запуска и Рекомендации

### 3.1. Основные файлы и выбор алгоритма

*   **`--a_cp_portrait_json`** (Обязательно)
    *   Путь к файлу `info_portrait_faces.json`.

*   **`--a_cp_names_file`** (Обязательно)
    *   Путь к текстовому файлу с именами (одно имя на строку).

*   **`--a_cp_algorithm`** (По умолчанию: `dbscan`)
    *   Выбор движка кластеризации.
    *   **Рекомендация:** Для студийных портретов, где условия съемки стабильны, **DBSCAN** дает более предсказуемый результат. Используйте **HDBSCAN** только если данные очень "грязные" или разнородные (смесь профессиональных фото и репортажки с телефона).

---

### 3.2. Параметры DBSCAN (Префикс: `a_cp_db_`)

Эти настройки применяются, только если выбран алгоритм `dbscan`.

*   **`--a_cp_db_eps`** (По умолчанию: `0.25`)
    *   **Что это:** Радиус "похожести" (Epsilon). Максимальное расстояние между лицами, чтобы считать их соседями.
    *   **Настройка:**
        *   *Слишком мало (0.15 - 0.20):* **Дробление.** Один человек может разбиться на 2-3 кластера (например, "Петя улыбается" и "Петя серьезный" станут разными людьми).
        *   *Слишком много (0.35 - 0.45):* **Склеивание.** Похожие братья/сестры или просто похожие дети сольются в один кластер.
    *   **Совет:** Начните с `0.25`. Если видите дробление — повышайте с шагом 0.05.

*   **`--a_cp_db_min_samples`** (По умолчанию: `3`)
    *   **Что это:** Минимальное количество фотографий для формирования кластера.
    *   **Настройка:**
        *   Если у ребенка всего 2 портрета, при значении `3` он попадет в "Шум" (удален из результатов).
    *   **Совет:** Ставьте `2`, если хотите "выловить" всех, даже тех, кого мало снимали. Ставьте `3-5` для отсеивания случайных лиц.

*   **`--a_cp_db_metric`** (По умолчанию: `cosine`)
    *   Метрика расстояния. Для эмбеддингов лиц **всегда** используйте `cosine` или `euclidean` (евклидова подходит, только если вектора нормализованы).

---

### 3.3. Параметры HDBSCAN (Префикс: `a_cp_hdb_`)

Эти настройки применяются, только если выбран алгоритм `hdbscan`.

*   **`--a_cp_hdb_min_cluster_size`** (По умолчанию: `2`)
    *   **Что это:** Жесткий лимит размера. Кластеры меньше этого размера не создаются.
    *   **Совет:** Аналогично `min_samples` в DBSCAN. Не ставьте слишком большим, иначе потеряете детей с малым количеством фото.

*   **`--a_cp_hdb_min_samples`** (По умолчанию: `None` / Авто)
    *   **Что это:** Влияет на "консервативность" алгоритма. Чем больше число, тем больше точек будет отброшено в "Шум" как ненадежные.
    *   **Совет:** Если HDBSCAN дает слишком много шума, уменьшите это значение.

*   **`--a_cp_hdb_cluster_selection_epsilon`** (По умолчанию: `0.0`)
    *   **Что это:** Гибридный параметр. Позволяет принудительно объединять кластеры, находящиеся ближе указанного расстояния, даже если иерархия HDBSCAN говорит их разделить.
    *   **Совет:** Если HDBSCAN дробит одного человека на части, попробуйте установить здесь небольшое значение (например, `0.1` или `0.15`). Это добавит поведение DBSCAN внутрь HDBSCAN.

*   **`--a_cp_hdb_metric`** (По умолчанию: `cosine`)
    *   Метрика расстояния. Рекомендуется `cosine`.
