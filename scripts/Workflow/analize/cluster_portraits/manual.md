# Руководство: Кластеризация портретов (v2025.11.13)

## 1. Назначение

Скрипт **"Кластеризация портретов"** является первым шагом в процессе идентификации людей на фотографиях. Его основная задача — проанализировать все лица с одиночных (портретных) снимков, сгруппировать похожие лица вместе и присвоить каждой группе (кластеру) имя из заранее подготовленного списка.

Результатом работы является обновленный файл метаданных, где для каждого портретного лица указана его принадлежность к определенному человеку.

## 2. Логика работы

1.  **Загрузка данных:** Скрипт загружает три основных типа данных, пути к которым указываются в параметрах:
    *   Эмбеддинги (`portrait_embeddings.npy`) — математические представления лиц.
    *   Метаданные (`info_portrait_faces.json`) — исходная информация о найденных лицах.
    *   Список имен (`names.txt`) — текстовый файл с именами, по одному на строку.

2.  **Кластеризация:** Используя выбранный алгоритм (`DBSCAN` или `HDBSCAN`), скрипт группирует все эмбеддинги. Лица одного и того же человека попадают в один кластер, а уникальные или плохо распознанные лица помечаются как "шум".

3.  **Присвоение имен:** Скрипт последовательно присваивает имена из загруженного списка каждому полученному кластеру. Если имен в списке меньше, чем кластеров, оставшимся будут присвоены технические имена (`Unknown_1`, `Unknown_2` и т.д.).

4.  **Сохранение результатов:** Скрипт **перезаписывает** исходный файл `info_portrait_faces.json`, добавляя в него для каждого лица два новых поля:
    *   `cluster_label`: Номер кластера, к которому принадлежит лицо.
    *   `child_name`: Имя, присвоенное этому кластеру.

## 3. Параметры

-   **`a_cp_embeddings_dir`**:
    -   **Назначение:** Путь к папке `_Embeddings`, где лежат файлы `portrait_embeddings.npy` и `portrait_index.json`.

-   **`a_cp_portrait_json`**:
    -   **Назначение:** Путь к JSON-файлу с метаданными портретных лиц. **Важно:** этот файл будет изменен в процессе работы.

-   **`a_cp_names_file`**:
    -   **Назначение:** Путь к текстовому файлу, содержащему список имен для кластеров (каждое имя с новой строки).

-   **`a_cp_config`**:
    -   **Назначение:** Путь к файлу `config.toml`, который содержит технические параметры для алгоритмов (например, `eps` для `DBSCAN`).

-   **`a_cp_algorithm`**:
    -   **Назначение:** Выбор алгоритма кластеризации.
    -   **Значение по умолчанию:** `dbscan`.
