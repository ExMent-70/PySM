# Утилита миграции данных (v2025.12.24)

## 1. Назначение

Скрипт `migrate_json_format.py` — это одноразовый инструмент для обновления структуры данных проекта. Он предназначен для преобразования "старых" (монолитных) JSON-файлов с результатами анализа лиц в новый, оптимизированный формат.

**Зачем это нужно:**
В новой архитектуре "тяжелые" данные о геометрии лица (ландмарки 106 точек) вынесены в отдельные файлы. Это позволяет основным скриптам (кластеризация, отчеты) работать в разы быстрее, не загружая в память лишние мегабайты данных. Данная утилита автоматизирует переход на этот формат.

## 2. Логика работы

1.  **Поиск файлов:** Скрипт сканирует указанную папку на наличие файлов `info_portrait_faces.json` и `info_group_faces.json`.
2.  **Резервное копирование:** Перед любым изменением оригинальный файл переименовывается с добавлением суффикса `_OLD` (например, `info_portrait_faces_OLD.json`). Это гарантирует сохранность данных в случае сбоя.
3.  **Разделение:**
    *   Извлекает массивы `landmark_2d_106` и `landmark_3d_68`.
    *   Массив `kps` (5 точек) остается в основном файле.
4.  **Сохранение:**
    *   Перезаписывает исходный файл `info_*_faces.json` (теперь он содержит только легкие данные).
    *   Создает новый файл `info_*_landmarks.json` (содержит вырезанную геометрию).

## 3. Требования

*   Наличие в целевой папке файлов `info_portrait_faces.json` и/или `info_group_faces.json` старого формата (где ландмарки находятся внутри основного объекта лица).

## 4. Параметры запуска

*   **`--path`**: (Обязательный) Полный путь к папке анализа (обычно `.../Output/Analysis_{session}`), где лежат JSON-файлы.

## 5. Пример использования

Если вы обновили код проекта и хотите продолжить работу со старой сессией:
1.  Запустите этот скрипт, указав путь к папке с результатами анализа этой сессии.
2.  Дождитесь сообщения "Миграция завершена".
3.  После этого можно запускать любые новые скрипты (кластеризацию, XMP), они автоматически подхватят новый формат.
