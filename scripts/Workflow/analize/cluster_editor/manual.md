# Скрипт "Редактор кластеров" (v2025.11.13)

## 1. Назначение

**"Редактор кластеров"** — это интерактивный инструмент с графическим интерфейсом, предназначенный для визуальной проверки и ручной корректировки результатов автоматической кластеризации **по лицам или по локациям**, а также для **просмотра и анализа совпадений** между портретными кластерами и групповыми фотографиями из разных съемок.

Он позволяет легко исправлять ошибки, допущенные алгоритмом, сравнивать результаты разных анализов и генерировать итоговые артефакты (обновленные JSON, экспортированные фото).

## 2. Логика работы

1.  **Загрузка данных:** При запуске скрипт автоматически находит и загружает все необходимые данные (JSON-файл с информацией о портретах, папку с изображениями `JPG`) на основе контекста текущего рабочего процесса.

2.  **Выбор режима:** В зависимости от переданного параметра запуска (см. раздел "Параметры запуска"), редактор будет работать в одном из трех режимов.

3.  **Интерфейс:** Окно разделено на две основные части:
    *   **Левая панель:** Отображает список **эталонных** кластеров (портреты или локации).
    *   **Правая панель:** Отображает галерею изображений, связанных с выбранным в левой панели элементом.

4.  **Основные действия:**
    *   **Перемещение (Drag & Drop):** В режимах `face` и `location` вы можете выделить одно или несколько изображений в правой панели и перетащить их на любой другой кластер в левой панели.
    *   **Переименование:** Двойной клик по кластеру в левой панели (или через контекстное меню) позволяет изменить его имя.
    *   **Просмотр:** Двойной клик по изображению в правой панели открывает его в полноэкранном режиме с возможностью пролистывать все фото текущей галереи.
    *   **Создание/Удаление кластеров:** Через контекстное меню (правый клик на левой панели) можно создавать новые кластеры и удалять пустые.

5.  **Сохранение и Экспорт:**
    *   **Сохранение:**
        *   В режимах `face` и `location` кнопка **"Сохранить изменения"** обновляет исходные JSON-файлы, фиксируя все перемещения и переименования.
        *   В режиме `matches` кнопка **"Сгенерировать matches.json"** создает или перезаписывает файл `matches_portrait_to_group.json`. **Важно:** файл сохраняется в ту же папку `Analysis_...`, из которой были загружены групповые данные.
    *   **Экспорт:**
        *   Кнопка **"Экспорт"** позволяет выгрузить фотографии из выбранных кластеров в отдельные папки.
        *   **Важно:** папка для экспорта создается относительно той съемки, данные которой активны в данный момент (особенно актуально для режима `matches`).

## 3. Параметры запуска / Режимы работы

Скрипт имеет один ключевой параметр командной строки для выбора режима работы.

*   `--mode <режим>`

    Определяет режим работы редактора.

    **Доступные режимы:**

    1.  `--mode face` (значение по умолчанию)
        *   **Назначение:** Редактирование кластеров лиц.
        *   **Функционал:** Полный (Drag & Drop, переименование, сохранение в `info_...json`, экспорт).

    2.  `--mode location`
        *   **Назначение:** Редактирование кластеров локаций.
        *   **Функционал:** Полный (Drag & Drop, переименование, сохранение в `info_...json`, экспорт).

    3.  `--mode matches`
        *   **Назначение:** Просмотр и анализ совпадений между эталонными портретами и групповыми фотографиями из **любой съемки**.
        *   **Левая панель:** Список **эталонных портретных кластеров** из текущего контекста.
        *   **Правая панель:** Галерея **групповых** фотографий, на которых был найден человек из выбранного портретного кластера.
        *   **Ключевая особенность:** По умолчанию загружаются данные о совпадениях из текущей съемки. Однако, через контекстное меню (правый клик на левой панели -> "Загрузить групповые данные...") можно **"на лету"** выбрать любой другой файл `info_group_faces.json` и проанализировать результаты совершенно другой съемки, используя тот же набор эталонных портретов.
        *   **Функционал:** Просмотр и экспорт, генерация `matches_portrait_to_group.json`. Редактирование отключено.

## 4. История изменений

### Версия 2025.11.13
*   **Архитектурный рефакторинг режима `matches`:**
    *   **Динамическая загрузка данных:** Реализована ключевая возможность в режиме `matches` — загрузка и анализ файла `info_group_faces.json` из любой директории "на лету" через контекстное меню. Это позволяет использовать один набор эталонных портретов для проверки результатов сопоставления на множестве разных съемок без перезапуска приложения.
    *   **Корректное определение путей:** Логика сохранения (`matches_portrait_to_group.json`) и экспорта теперь динамически определяет правильный путь назначения на основе того, какой `info_group_faces.json` активен в данный момент. Это исключает случайную перезапись данных в неверной директории.
    *   **Улучшение UX:** При запуске в режиме `matches` редактор теперь автоматически загружает данные о совпадениях для текущей съемки по умолчанию, а не показывает пустой экран.
*   **Устранение ошибок и повышение надежности:**
    *   Исправлен ряд ошибок (`KeyError`, `TypeError`, `NameError`), возникавших в процессе рефакторинга.
    *   Упрощена и сделана более надежной логика инициализации и обработки путей к файлам.

### Версия 2025.10.19
*   **Рефакторинг системы стилей:**
    *   Полная интеграция с системой тем PySM.
    *   Централизованное управление внешним видом.
    *   Удален устаревший модуль `_lib/editor_styles.py`.

### Версия 2025.10.11
*   **Интеграция с контекстом:** В режиме `location` при сохранении скрипт обновляет переменную контекста `sys_location_name`.
*   **Новый режим `matches`:** Добавлена базовая версия режима просмотра совпадений.
*   **Оптимизация производительности:** Ускорена загрузка галереи и запуск приложения (`ijson`).
*   **Улучшения функционала и UI:** Добавлена генерация `matches_portrait_to_group.json`, экспорт в режиме `matches`, выпадающий список для имен локаций.
