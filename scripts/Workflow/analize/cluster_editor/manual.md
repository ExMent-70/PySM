# Руководство по "Редактору кластеров" (v1.2.0)

## 1. Назначение

**"Редактор кластеров"** — это интерактивный инструмент с графическим интерфейсом, предназначенный для визуальной проверки и ручной корректировки результатов автоматической кластеризации **по лицам или по локациям**. Он позволяет легко исправлять ошибки, допущенные алгоритмом, перед финальными этапами обработки.

## 2. Логика работы

1.  **Загрузка данных:** При запуске скрипт автоматически находит все необходимые данные (JSON-файлы с информацией о лицах, папку с изображениями `JPG`) на основе контекста текущего рабочего процесса.

2.  **Выбор режима:** В зависимости от переданного параметра запуска (см. раздел "Параметры запуска"), редактор будет работать в одном из двух режимов: кластеризация по лицам или по локациям.

3.  **Интерфейс:** Окно разделено на две основные части:
    *   **Левая панель:** Отображает список всех найденных кластеров (включая "шум" и групповые фото). Для каждого кластера показана миниатюра первого фото, имя и количество изображений.
    *   **Правая панель:** При выборе кластера слева, здесь отображается галерея всех фотографий, входящих в него.

4.  **Основные действия:**
    *   **Перемещение (Drag & Drop):** Вы можете выделить одно или несколько изображений в правой панели и перетащить их на любой другой кластер в левой панели. Это мгновенно обновит состав кластеров в модели данных.
    *   **Переименование:** Двойной клик по кластеру в левой панели (или через контекстное меню) позволяет изменить его имя.
    *   **Просмотр:** Двойной клик по изображению в правой панели открывает его в полноэкранном режиме с возможностью пролистывать все фото текущего кластера.

5.  **Сохранение изменений:**
    *   Все изменения (перемещения, переименования) накапливаются, но **не применяются автоматически**.
    *   Для фиксации результатов необходимо нажать кнопку **"Сохранить изменения"**.
    *   При сохранении скрипт обновляет **только** JSON-файлы (`info_portrait_faces.json` и `info_group_faces.json`), изменяя в них соответствующие поля кластеров.
    *   **Важно:** Скрипт больше не перемещает файлы на диске. Он работает исключительно как редактор метаданных в JSON.

## 3. Параметры запуска / Режимы работы

Скрипт имеет один ключевой параметр командной строки для выбора режима работы.

*   `--mode <режим>`

    Определяет, по какому полю в JSON будет производиться группировка, редактирование и отображение кластеров.

    **Доступные режимы:**

    1.  `--mode face` (значение по умолчанию)
        *   Редактор группирует изображения на основе поля `cluster_label` (кластеры лиц).
        *   Имена кластеров берутся из поля `child_name`.
        *   Это стандартный режим для проверки и исправления распознавания людей.

    2.  `--mode location`
        *   Редактор группирует изображения на основе поля `location_cluster` (кластеры локаций).
        *   Имена кластеров соответствуют названиям локаций.
        *   Этот режим используется для проверки и исправления группировки по местам съемки.
