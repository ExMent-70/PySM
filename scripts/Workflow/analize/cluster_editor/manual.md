# Скрипт "Редактор кластеров" (v2025.10.19)

## 1. Назначение

**"Редактор кластеров"** — это интерактивный инструмент с графическим интерфейсом, предназначенный для визуальной проверки и ручной корректировки результатов автоматической кластеризации **по лицам или по локациям**, а также для **просмотра совпадений** между портретными кластерами и групповыми фотографиями. Он позволяет легко исправлять ошибки, допущенные алгоритмом, и генерировать итоговые артефакты.

## 2. Логика работы

1.  **Загрузка данных:** При запуске скрипт автоматически находит и загружает все необходимые данные (JSON-файлы с информацией о лицах, папку с изображениями `JPG`) на основе контекста текущего рабочего процесса. Процесс загрузки оптимизирован для быстрой работы с большими объемами данных.

2.  **Выбор режима:** В зависимости от переданного параметра запуска (см. раздел "Параметры запуска"), редактор будет работать в одном из трех режимов.

3.  **Интерфейс:** Окно разделено на две основные части:
    *   **Левая панель:** Отображает список кластеров. Внешний вид зависит от режима.
    *   **Правая панель:** Отображает галерею изображений, связанных с выбранным в левой панели кластером.

4.  **Основные действия:**
    *   **Перемещение (Drag & Drop):** В режимах `face` и `location` вы можете выделить одно или несколько изображений в правой панели и перетащить их на любой другой кластер в левой панели. Это мгновенно обновит состав кластеров.
    *   **Переименование:** Двойной клик по кластеру в левой панели (или через контекстное меню) позволяет изменить его имя. В режиме `location` для этого используется удобный выпадающий список с предопределенными названиями.
    *   **Просмотр:** Двойной клик по изображению в правой панели открывает его в полноэкранном режиме с возможностью пролистывать все фото текущей галереи.
    *   **Создание/Удаление кластеров:** Через контекстное меню (правый клик на левой панели) можно создавать новые кластеры и удалять пустые.

5.  **Сохранение и Экспорт:**
    *   **Сохранение:**
        *   В режимах `face` и `location` кнопка **"Сохранить изменения"** обновляет исходные JSON-файлы (`info_portrait_faces.json`, `info_group_faces.json`), фиксируя все перемещения и переименования.
        *   В режиме `matches` кнопка **"Сгенерировать matches.json"** создает или перезаписывает файл `matches_portrait_to_group.json` на основе актуальных данных о совпадениях.
    *   **Экспорт:**
        *   Кнопка **"Экспорт"** позволяет выгрузить фотографии из выбранных кластеров в отдельные папки.
        *   Перед экспортом можно настроить параметры улучшения изображений (яркость, контраст и т.д.) и включить/выключить наложение водяных знаков.
        *   Имя корневой папки для экспорта включает название текущего режима (например, `Выбор_Фото_..._face`), чтобы результаты разных режимов не смешивались.

## 3. Параметры запуска / Режимы работы

Скрипт имеет один ключевой параметр командной строки для выбора режима работы.

*   `--mode <режим>`

    Определяет режим работы редактора.

    **Доступные режимы:**

    1.  `--mode face` (значение по умолчанию)
        *   **Назначение:** Редактирование кластеров лиц.
        *   **Левая панель:** Список портретных кластеров, "шумовой" кластер и кластер групповых фото.
        *   **Правая панель:** Фотографии из выбранного кластера.
        *   **Функционал:** Полный (Drag & Drop, переименование, сохранение в `info_...json`, экспорт).

    2.  `--mode location`
        *   **Назначение:** Редактирование кластеров локаций.
        *   **Левая панель:** Список кластеров локаций.
        *   **Правая панель:** Фотографии, снятые в выбранной локации.
        *   **Функционал:** Полный (Drag & Drop, переименование, сохранение в `info_...json`, экспорт).

    3.  `--mode matches`
        *   **Назначение:** Просмотр и экспорт совпадений портретнных и групповых фотографий.
        *   **Левая панель:** Список портретных кластеров. Счетчик показывает количество найденных групповых фото.
        *   **Правая панель:** Галерея **групповых** фотографий, на которых был найден человек из выбранного портретного кластера.
        *   **Функционал:** Просмотр и экспорт групповых фотографий,  генерация `matches_portrait_to_group.json`. Редактирование кластеров (Drag & Drop, переименование) отключено.

## 4. История изменений

### Версия 2025.10.19
*   **Рефакторинг системы стилей:**
    *   **Полная интеграция с системой тем:** Внешний вид "Редактора кластеров" теперь полностью соответствует активной теме главного приложения. Цвета выделения, рамок, фона и подсветки при наведении курсора унифицированы и имеют консистентный вид.
    *   **Централизованное управление:** Все правила внешнего вида вынесены в файлы темы (`style.qss` для основной стилизации и `theme.toml` для кастомных цветов отрисовки). Это упрощает кастомизацию и поддержку.
    *   **Повышение надежности:** Устранен конфликт между старой "ручной" отрисовкой и новой системой тем, что решило проблему с некорректным отображением элементов и индикаторов. Удален устаревший модуль `_lib/editor_styles.py`.

### Версия 2025.10.11
*   **Интеграция с контекстом:** В режиме `location` при сохранении изменений скрипт теперь обновляет переменную контекста `sys_location_name` актуальным списком имен локаций. Переменная `sys_location_name` используется скриптами каталогизатор шаблонов InDesign и автоматическая верстка альбомов.
*   **Новый режим `matches`:** Добавлен режим просмотра совпадений, позволяющий для каждого портретного кластера увидеть все групповые фотографии, на которых он был найден.
*   **Оптимизация производительности:**
    *   Полностью переработан механизм загрузки галереи. Устранены "зависания" при открытии кластеров с большим количеством фотографий (сотни и тысячи).
    *   Внедрена потоковая загрузка JSON-файлов (`ijson`), что значительно ускорило запуск приложения и снизило пиковое потребление оперативной памяти.
*   **Улучшения функционала:**
    *   Реализована генерация файла `matches_portrait_to_group.json` в режиме `matches` с сохранением корректных `match_distance`.
    *   Добавлена возможность экспорта групповых фотографий в режиме `matches`.
    *   Имя папки экспорта теперь включает название режима (`..._face`, `..._location`, `..._matches`).
*   **Улучшения UI:**
    *   В режиме `location` для переименования кластеров теперь можно используется выпадающий список с предопределенными именами.
    *   Улучшен визуальный отклик при перетаскивании изображений.
