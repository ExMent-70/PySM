# Руководство по скрипту "Создание/Обновление XMP" (v2025.12.24)

## 1. Назначение

Этот скрипт является связующим звеном между этапом AI-анализа изображений и профессиональными программами для каталогизации (Adobe Lightroom, Capture One). Его задача — экспортировать все полученные данные (имена детей, эмоции, точные координаты лиц и глаз) в стандартные `.xmp` файлы-сайдкары.

## 2. Логика работы

1.  **Автоматическое определение путей:** Скрипт получает пути к папкам сессии из Контекста PySM.

2.  **Умная загрузка данных:**
    *   Скрипт находит основные JSON-файлы (`info_*_faces.json`) с метаданными.
    *   **Новое:** Автоматически обнаруживает и подгружает файлы с детальной геометрией (`info_*_landmarks.json`).
    *   Производит слияние (merge) основных данных и геометрии в памяти. Это позволяет записывать в XMP полные технические данные (включая 106 точек лица), несмотря на то, что физически они хранятся в разных файлах для оптимизации.

3.  **Загрузка шаблона:** Использует `template.xmp` как базу для новых файлов.

4.  **Обработка изображений:** В многопоточном режиме для каждого фото:
    *   Формирует список ключевых слов (`dc:subject`): имена, локации, эмоции, состояние глаз.
    *   Формирует технические коды (`Iptc4xmpCore:SubjectCode`): закодированные координаты и ландмарки для использования плагинами кропа/ретуши.
    *   Записывает список персон в `photoshop:TransmissionReference`.

5.  **Атомарное сохранение:** Файлы сначала пишутся во временный буфер, а затем переименовываются, что исключает повреждение метаданных при сбое.

## 3. Параметры

-   **Количество потоков** (`all_threads`):
    -   Определяет степень параллелизма записи. По умолчанию (`0`) использует все доступные ядра процессора для максимальной скорости дисковых операций.

## 4. Результат

В папке `Capture` рядом с исходными изображениями (RAW или JPG) появляются `.xmp` файлы. При импорте или чтении метаданных в Lightroom вы увидите все результаты работы нейросетей в виде тегов и полей метаданных.

## 5. История изменений

### Версия 2025.12.24
-   **Архитектура:** Добавлена поддержка **раздельного хранения данных**. Скрипт научился загружать "тяжелые" геометрические данные (`landmark_2d_106`) из отдельных файлов `*_landmarks.json` и объединять их с основными метаданными перед записью в XMP. Это обеспечивает совместимость с оптимизированным пайплайном анализа.
-   **Надежность:** Улучшена обработка случаев, когда файлы ландмарков отсутствуют (скрипт корректно запишет XMP без детальной геометрии, не прерывая работу).

### Версия 2025.11.30
-   **Рефакторинг:** Логика работы с XMP вынесена в унифицированный модуль `_common/xmp_editor.py`.
-   **Безопасность:** Внедрено атомарное сохранение файлов.

### Версия 2025.10.09
-   **Функционал:** Добавлена поддержка записи названий локаций в поля `Iptc4xmpCore:Location` и ключевые слова.
