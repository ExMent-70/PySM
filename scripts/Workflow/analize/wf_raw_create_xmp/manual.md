# Скрипт "Создание/Обновление XMP" (v2026.01.01)

## 1. Назначение

Этот скрипт является связующим звеном между этапом AI-анализа изображений и профессиональными программами для каталогизации (Adobe Lightroom, Capture One). Его задача — экспортировать все полученные данные (имена детей, эмоции, точные координаты лиц и глаз) в стандартные `.xmp` файлы-сайдкары.

## 2. Логика работы

1.  **Автоматическое определение путей:** Скрипт получает пути к папкам сессии из Контекста PySM.

2.  **Умная загрузка данных:**
    *   Скрипт находит основные JSON-файлы (`info_*_faces.json`) с метаданными.
    *   **Оптимизация:** Файлы с детальной геометрией (`info_*_landmarks.json`) подгружаются **только** если включен параметр `landmark_enable`. Это значительно экономит оперативную память.
    *   Производит слияние (merge) основных данных и геометрии (если включено) перед записью.

3.  **Загрузка шаблона:** Использует `template.xmp` как базу для новых файлов.

4.  **Обработка изображений:** В многопоточном режиме для каждого фото:
    *   Формирует список ключевых слов (`dc:subject`): имена, локации, эмоции (`PySM_EMOTION_...`), состояние глаз (`PySM_EYE_...`) и **состояние рта** (`PySM_MOUTH_...`).
    *   Формирует технические коды (`Iptc4xmpCore:SubjectCode`): координаты лиц и (опционально) ландмарки.
    *   Записывает список персон в `photoshop:TransmissionReference`.

5.  **Атомарное сохранение:** Файлы сначала пишутся во временный буфер, а затем переименовываются, что исключает повреждение метаданных при сбое.

## 3. Параметры

-   **Количество потоков** (`all_threads`):
    -   Определяет степень параллелизма записи. По умолчанию (`0`) использует все доступные ядра процессора.

-   **Включить ландмарки** (`landmark_enable`):
    -   Флаг (переключатель). Если активирован, в XMP записываются детальные координаты 106 точек лица (`landmark_2d_106`).
    -   **По умолчанию выключено** для ускорения работы и уменьшения размера метаданных. Включайте только если планируете использовать плагины ретуши, требующие этих данных.

## 4. Результат

В папке `Capture` рядом с исходными изображениями появляются `.xmp` файлы. При импорте в Lightroom вы увидите теги с именами и атрибутами лиц.

## 5. История изменений

### Версия 2026.01.01
-   **Функционал:** Добавлено сохранение состояния рта (`mouth_state`) в ключевые слова и SubjectCode. Теперь можно искать фото по тегам вида `PySM_MOUTH_open` или `PySM_MOUTH_smile`.
-   **Оптимизация:** Внедрен параметр `--landmark_enable`. Запись "тяжелых" геометрических данных теперь отключена по умолчанию. Скрипт не загружает лишние JSON-файлы в память, если этот флаг не установлен.

### Версия 2025.12.24
-   **Архитектура:** Добавлена поддержка раздельного хранения данных. Скрипт научился загружать геометрические данные (`landmark_2d_106`) из отдельных файлов.
-   **Надежность:** Улучшена обработка отсутствующих файлов ландмарков.

### Версия 2025.11.30
-   **Рефакторинг:** Переход на модуль `_common/xmp_editor.py` и внедрение атомарного сохранения.
