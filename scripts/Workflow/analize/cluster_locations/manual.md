# Руководство по "Кластеризации по локациям" (v1.2.0)

## 1. Назначение

Скрипт **"Кластеризация по локациям"** предназначен для автоматической группировки фотографий на основе схожести их фона (места съемки). Скрипт может работать в двух режимах:

1.  **Режим кластеризации (по умолчанию):** Скрипт автоматически находит и группирует похожие локации, не имея о них предварительных знаний.
2.  **Режим классификации:** Скрипт распределяет фотографии по заранее заданным текстовым описаниям локаций (например, "класс с партами", "спортивный зал").

## 2. Логика работы

1.  **Требования:** Для работы скрипта необходимо, чтобы предварительно были сгенерированы **маски** — изображения, с которых удалены люди. Имя файла маски должно соответствовать шаблону `<имя_исходного_файла>_BiRefNet-portrait_output.jpg`.

2.  **Выбор режима:** Режим работы определяется параметром `a_cl_location_prompts`.
    *   Если список пуст (по умолчанию), включается **режим кластеризации**.
    *   Если в списке есть хотя бы одно текстовое описание, включается **режим классификации**.

3.  **Вычисление эмбеддингов:** В любом режиме скрипт в несколько потоков обрабатывает каждую маску:
    *   Загружает изображение фона (маску).
    *   Подает его на вход ONNX-модели CLIP Vision Encoder для получения **эмбеддинга** — уникального числового вектора, описывающего локацию.

4.  **Обработка:**
    *   **В режиме кластеризации:** Все полученные эмбеддинги группируются с помощью алгоритма **DBSCAN**. Алгоритм автоматически определяет количество уникальных локаций и присваивает каждой фотографии числовую метку (`0`, `1`, `2`, ...).
    *   **В режиме классификации:** Для каждого текстового описания (промпта) с помощью **токенизатора** вычисляется его собственный эмбеддинг. Затем для каждой фотографии находится наиболее семантически близкий текстовый промпт. Фотографии присваивается метка, соответствующая **индексу** этого описания в списке (`0`, `1`, `2`, ...).

5.  **Обновление и сохранение результатов:**
    *   Скрипт **открывает существующие файлы `info_portrait_faces.json` и `info_group_faces.json`**.
    *   Для каждой проанализированной фотографии он **добавляет новое поле `location_cluster`** с числовой меткой найденной локации.
    *   Обновленные JSON-файлы сохраняются.
    *   Дополнительно создаются файлы `location_embeddings.npy` и `location_index.json`.
    *   Для визуальной проверки исходные фотографии копируются в подпапки `LocationClusters/location_0`, `LocationClusters/location_1` и т.д. **Имена папок и метки в файлах всегда числовые, даже в режиме классификации, для сохранения единого формата.**

## 3. Параметры

-   `a_cl_config_file` (служебный): Путь к файлу `config.toml`.
-   `a_cl_location_prompts` (необязательный): Список текстовых описаний для включения режима классификации.
-   `all_threads`: Количество потоков для обработки. `0` — автоматический выбор.
-   **`a_cl_cluster_eps`**: (Только для режима кластеризации) Параметр `eps` для алгоритма DBSCAN. Определяет, насколько "близко" должны быть эмбеддинги, чтобы считаться одной локацией. Уменьшение этого значения (например, с `0.14` до `0.12`) приведет к созданию большего количества более "строгих" кластеров. Значение по умолчанию: `0.14`.


### Рекомендации по составлению промптов для `a_cl_location_prompts`

#### Язык промптов

Настоятельно рекомендуется писать промпты на **английском языке** для максимальной точности. Модель CLIP обучалась преимущественно на англоязычных данных и лучше всего понимает нюансы именно этого языка. Русский язык может работать для простых концепций, но для надежного различения сложных сцен английский даст неоспоримое преимущество.

#### Примеры промптов:

*   **Локация: Класс с партами**
    -   (EN): `a photograph of a classroom with school desks`
    -   (RU): `фотография класса с партами`

*   **Локация: У доски**
    -   (EN): `a photograph of a classroom with a blackboard`
    -   (RU): `фотография возле школьной доски`

*   **Локация: Спортивный зал**
    -   (EN): `a photograph of a school gymnasium`
    -   (RU): `фотография в спортивном зале`

*   **Локация: Школьный двор**
    -   (EN): `a photograph of a schoolyard with trees`
    -   (RU): `фотография на школьном дворе с деревьями`

*   **Локация: Коридор**
    -   (EN): `a photograph of a school hallway with lockers`
    -   (RU): `фотография в школьном коридоре`

#### Как правильно вводить список промптов:

Нужно ли использовать кавычки? **Нет, кавычки вводить не нужно.**

В диалоге PySM для редактирования списка строк каждый промпт вводится с новой строки. Приложение автоматически обработает каждую строку как отдельный элемент списка.

*Пример ввода в окне редактирования параметра `a_cl_location_prompts` в PySM:*
```
a photograph of a classroom with school desks
a photograph of a classroom with a blackboard
a photograph of a school gymnasium
```

#### Понимание режимов работы: Кластеризация vs Классификация

Важно понимать, как наличие или отсутствие промптов меняет логику скрипта.

*   **Сценарий 1: Промпты не заданы (список пуст)**
    *   **Режим:** Кластеризация.
    *   **Что происходит:** Скрипт работает как **исследователь**. Он не знает, сколько у вас локаций. Он анализирует сходство всех изображений между собой и сам решает, сколько групп (кластеров) нужно создать. Фото, не похожие ни на одну группу, получат метку `-1` (шум).

*   **Сценарий 2: Промпты заданы**
    *   **Режим:** Классификация.
    *   **Что происходит:** Скрипт работает как **сортировщик**. Он не ищет новые группы. Вместо этого он берет каждую фотографию и сравнивает ее с **каждым вашим промптом**, выбирая наиболее подходящий.
    *   Если у вас 2 промпта, а реальных локаций 5, то фотографии из "лишних" трех локаций будут либо ошибочно отнесены к одному из двух ваших вариантов, либо (если они совсем не похожи) получат метку `-1` (шум).
    *   Если у вас 5 промптов, а реальных локаций всего 2, то скрипт идеально рассортирует фото по двум нужным категориям. "Лишние" промпты просто не будут использованы.

## 4. Требования

Для корректной работы режима классификации по тексту необходимо установить дополнительную библиотеку. Откройте командную строку, активируйте ваше виртуальное окружение (`.venv\Scripts\activate`) и выполните команду:
```
pip install transformers
```
