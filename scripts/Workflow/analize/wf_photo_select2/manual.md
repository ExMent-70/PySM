# Скрипт "Выборка файлов: тегирование и переименование" (v2025.12.12)

## 1. Назначение

Этот скрипт — инструмент для интерактивной выборки фотографий на основе списка номеров, предоставленного клиентом. 
В отличие от предыдущих версий, он **не копирует файлы**, а работает с ними "на месте" (в папке `Capture`).

**Основные функции:**
1.  **Тегирование:** Прописывает в метаданные файлов (XMP) информацию о том, к какой выборке они относятся. Это позволяет мгновенно отфильтровать нужные кадры в Lightroom или Capture One.
2.  **Переименование:** (Опционально) Переименовывает исходные файлы, заменяя безликие номера (напр. `IMG_1234`) на имя человека (напр. `Вася-1234`).
3.  **Логирование:** Ведет историю всех операций.

## 2. Логика работы

1.  **Запуск:** Скрипт автоматически определяет рабочую папку сессии и загружает базу имен из файла `info_portrait_faces.json`.

2.  **Ввод данных:**
    *   Пользователь вставляет текст со списком номеров в левую панель.
    *   Нажимает **"1. Извлечь номера"**. Скрипт находит все числовые последовательности, длина которых соответствует параметрам `min_digits` и `max_digits` (по умолчанию — 4-значные).

3.  **Поиск файлов:**
    *   Нажатие **"2. Найти файлы"** запускает сканирование папки `Capture`.
    *   Результаты выводятся в таблицу. Группы файлов (RAW + XMP) по умолчанию свернуты для удобства.

4.  **Настройка операции:**
    *   **Выбор локации (тега):** В выпадающем списке необходимо выбрать имя текущей выборки (например, "Album_Selection"). Это значение будет записано в XMP.
    *   **Переименование:** Чекбокс **"Переименовать файлы"** (по умолчанию выключен).
        *   *Если включен:* Файлы получат имена вида `<Имя>-<Номер>.<ext>`.
        *   *Если выключен:* Имена файлов останутся оригинальными.

5.  **Выполнение:**
    *   Нажатие **"3. Выполнить"** запускает процесс.
    *   Скрипт обновляет `.xmp` файлы (поля `Iptc4xmpCore:Location` и ключевые слова `loc_<ИмяЛокации>`).
    *   Если выбрано переименование, меняет имена файлов на диске.

## 3. Требования

-   Запуск в среде PySM.
-   Наличие сформированных JSON-отчетов (`info_portrait_faces.json`) в папке анализа.
-   Наличие модуля `_common` в структуре проекта (скрипт использует общий редактор XMP).

## 4. Результат работы

После обработки файлы остаются в тех же папках, но:
1.  **Метаданные:** В их XMP-файлах прописана Локация и Ключевое слово (например, `loc_School_Album`). В каталогизаторе достаточно набрать этот тег в поиске, чтобы увидеть выборку.
2.  **Имена:** (При включенной опции) Файлы имеют понятные имена, соответствующие именам людей на фото.

## 5. Параметры

-   **`min_digits`** (служебный): Минимальное количество цифр в номере для поиска. По умолчанию `4`.
-   **`max_digits`** (служебный): Максимальное количество цифр в номере для поиска. По умолчанию `4`.

## 6. История изменений

### Версия 2025.12.12
-   **Улучшено:** Поиск номеров стал гибким. Теперь скрипт может искать не только 4-значные номера, но и числовые последовательности любой длины. Длина настраивается через параметры `min_digits` и `max_digits`.

### Версия 2025.11.30
-   **Смена парадигмы:** Переход от физического копирования файлов к логическому тегированию (изменение XMP "на месте").
-   **Опциональное переименование:** Добавлен чекбокс, позволяющий отключить переименование файлов, если требуется только проставить теги.
-   **Интерфейс:**
    -   Таблица результатов теперь показывает порядковый номер строки.
    -   Группы файлов в таблице по умолчанию свернуты (`collapseAll`).
    -   Улучшено визуальное разделение элементов управления.
-   **Архитектура:** Использование безопасного общего модуля `XmpEditor` для атомарной записи метаданных.

### Версия 2025.10.19
-   **Добавлено:** Сортировка в таблице результатов.
-   **Добавлено:** Поле для копирования номеров.
-   **Улучшено:** Интеграция с цветовыми темами PySM.

### Версия 2025.10.18
-   **Добавлено:** Система ведения журнала операций в `operations_log.json`.
-   **Добавлено:** Выбор сессии копирования из списка контекста.
