# Руководство: Сопоставление групповых лиц (v2025.11.13)

## 1. Назначение

Скрипт **"Сопоставление групповых лиц"** является вторым и завершающим шагом в процессе идентификации. Его задача — найти и опознать людей на групповых фотографиях, используя в качестве эталонов кластеры, созданные на предыдущем этапе ("Кластеризация портретов").

Результатом работы является обновленный файл метаданных для групповых фото и сводный JSON-отчет, показывающий, на каких групповых снимках был найден каждый человек.

## 2. Логика работы

1.  **Загрузка данных:** Скрипт загружает данные из нескольких источников:
    *   **Данные о кластерах:** Обработанный `info_portrait_faces.json` (с именами и метками кластеров) и `portrait_embeddings.npy`.
    *   **Данные для анализа:** Исходный `info_group_faces.json` и `group_embeddings.npy`.

2.  **Вычисление эталонов (центроидов):** Для каждого портретного кластера (т.е. для каждого уникального человека) скрипт вычисляет "среднее лицо" — центроид. Это усредненный эмбеддинг, который служит эталоном для сравнения.

3.  **Сопоставление:** Каждое лицо с групповых фотографий сравнивается со всеми вычисленными эталонами. Скрипт находит ближайший эталон и измеряет "расстояние" до него.

4.  **Принятие решения:** Если расстояние до ближайшего эталона меньше порогового значения (`match_threshold` из файла `config.toml`), лицо считается опознанным. Ему присваиваются имя и метка соответствующего кластера. Если расстояние больше, лицо помечается как `No Match`.

5.  **Сохранение результатов:**
    *   Скрипт **перезаписывает** файл `info_group_faces.json`, добавляя в него информацию о сопоставлениях (`matched_child_name`, `match_distance` и т.д.).
    *   Скрипт создает новый файл `matches_portrait_to_group.json` в указанной выходной папке. Этот файл содержит сводную информацию: для каждого человека (кластера) приводится список групповых фото, на которых он был найден.

## 3. Параметры

-   **`a_mg_embeddings_dir`**:
    -   **Назначение:** Путь к папке `_Embeddings`, где лежат файлы эмбеддингов для портретных и групповых фото.

-   **`a_mg_portrait_json`**:
    -   **Назначение:** Путь к JSON-файлу `info_portrait_faces.json`. **Критически важно:** это должен быть файл, уже обработанный скриптом "Кластеризация портретов", так как он содержит необходимые метки кластеров.

-   **`a_mg_group_json`**:
    -   **Назначение:** Путь к JSON-файлу с метаданными групповых лиц. Этот файл будет обновлен результатами сопоставления.

-   **`a_mg_output_dir`**:
    -   **Назначение:** Путь к папке, в которую будет сохранен итоговый JSON-отчет `matches_portrait_to_group.json`.

-   **`a_mg_config`**:
    -   **Назначение:** Путь к файлу `config.toml`, из которого будет взят параметр `matching.match_threshold` — порог для принятия решения о совпадении.
