# Руководство: Сопоставление групповых лиц (v2026.01.24)

## 1. Назначение

Скрипт **"Сопоставление групповых лиц"** является вторым и завершающим шагом в процессе идентификации. Его задача — найти и опознать людей на групповых фотографиях, используя в качестве эталонов кластеры, созданные на предыдущем этапе ("Кластеризация портретов").

Результатом работы является обновленный файл метаданных для групповых фото и два отчета:
1.  **matches_portrait_to_group.json**: сводный JSON-отчет, показывающий, на каких групповых снимках был найден каждый человек.
2.  **error_matches.json**: Список нераспознанных лиц (полезно для диагностики).

## 2. Логика работы

1.  **Загрузка данных:** Скрипт автоматически определяет пути к папкам с эмбеддингами (`_Embeddings`) на основе расположения переданных JSON-файлов. Загружаются:
    *   **Эталоны:** Портретные эмбеддинги и метаданные (из `info_portrait_faces.json`).
    *   **Анализируемые данные:** Групповые эмбеддинги и метаданные (из `info_group_faces.json`).

2.  **Вычисление эталонов (центроидов):** Для каждого портретного кластера (каждого ребенка) скрипт вычисляет "среднее лицо" — центроид. При вычислении используется L2-нормализация для корректной работы с косинусным расстоянием.

3.  **Сопоставление (Matching):** Каждое лицо с групповых фотографий сравнивается со всеми вычисленными эталонами. Используется метрика **Cosine Distance**.

4.  **Принятие решения:**
    *   Скрипт находит ближайший эталон.
    *   Если расстояние меньше порогового значения (параметр `--a_mg_threshold`), лицо считается опознанным. Ему присваиваются имя и ID кластера.
    *   Если расстояние больше порога, лицо помечается статусом `No Match`.

5.  **Сохранение результатов:**
    *   
    *   В папке с групповым JSON создается отчет `matches_portrait_to_group.json` со списком найденных соответствий.

5.  **Сохранение результатов:**
    *   Обновляется файл `info_group_faces.json` (добавляются поля `matched_child_name`, `match_distance`).
    *   В папке с групповым JSON создается файл `matches_portrait_to_group.json` со списком найденных соответствий.
    *   В папке с групповым JSON создается файл `error_matches.json` со списком фотографий и индексов лиц, для которых не удалось найти подходящий портретный кластер (расстояние до ближайшего > threshold). Включает минимальное найденное расстояние для анализа.

## 3. Параметры запуска

-   **`a_mg_portrait_json`**:
    -   **Назначение:** Путь к JSON-файлу `info_portrait_faces.json`.
    -   **Важно:** Файл должен содержать результаты кластеризации (поле `cluster_label`), иначе скрипт не сможет сформировать эталоны.

-   **`a_mg_group_json`**:
    -   **Назначение:** Путь к JSON-файлу с метаданными групповых лиц (`info_group_faces.json`). Этот файл будет обновлен.

-   **`a_mg_threshold`** (Опционально):
    -   **Назначение:** Порог схожести (Cosine Distance).
    -   **Значение по умолчанию:** `0.45`.
    -   **Как настраивать:**
        -   *Уменьшить (например, 0.35):* Более строгий режим. Меньше ложных срабатываний, но может не узнать ребенка при плохом свете.
        -   *Увеличить (например, 0.55):* Более мягкий режим. Узнает чаще, но может начать путать похожих детей.
