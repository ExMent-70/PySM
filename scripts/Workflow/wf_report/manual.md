# Руководство по скрипту "Генератор отчета" (v2026.01.22)

## 1. Назначение

Скрипт **"Генератор отчета"** предназначен для визуализации текущего состояния файловой системы проекта. Он сканирует ключевые папки (RAW, Capture One, Photoshop) и формирует интерактивный HTML-отчет со ссылками на ресурсы.

Скрипт поддерживает два визуальных стиля (шаблона) и режимы фильтрации данных.

## 2. Логика работы

Скрипт автоматически считывает глобальные переменные процесса (например, `wf_session_path`, `wf_photo_session`) и выполняет следующие действия:

1.  **Сканирование ресурсов:**
    *   Проверяет наличие корневых папок (RAW, PSD, Шаблоны).
    *   Анализирует структуру сессии Capture One.
    *   Ищет результаты работы AI (папки `Analysis_*`, файлы JSON, маски, сгенерированные отчеты).
    *   Проверяет наличие XMP-файлов (метаданных) в папках съемки.

2.  **Генерация HTML:**
    *   На основе собранных данных формирует HTML-код.
    *   Использует цветовую тему PySM для оформления (поддержка темной и светлой темы).
    *   Вставляет векторные иконки для наглядности.

3.  **Вывод:** Результат выводится непосредственно в консоль PySM в виде HTML-блока.

## 3. Параметры запуска

### Основные настройки

*   **`template` (Шаблон отчета):**
    *   `standard` (по умолчанию): Выводит данные в виде **иерархического дерева** (списка). Удобен для компактного просмотра структуры папок. Использует чередование цветов строк ("зебра").
    *   `dashboard`: Выводит данные в виде **блочной сетки (таблицы)**. Этот режим удобен для визуального контроля статуса обработки (например, наличие XMP, масок и отчетов сразу видно в соответствующих ячейках).

*   **`scope` (Объем данных):**
    *   `current` (по умолчанию): Отчет формируется **только** для текущей активной фотосессии (переменная `wf_photo_session`). Остальные папки `Analysis_*` игнорируются.
    *   `full`: Скрипт сканирует папку `Output` и выводит информацию по **всем** найденным фотосессиям в рамках текущего проекта.

### Настройки интерфейса

*   **`icon_size_tree`**: Размер иконок для шаблона `standard` (в пикселях). Рекомендуемое значение: `20` - `24`.
*   **`icon_size_dashboard`**: Размер иконок для шаблона `dashboard` (в пикселях). Рекомендуемое значение: `32` - `48`.

## 4. Особенности отображения

### Шаблон "Standard" (Дерево)
Отображает три основных блока:
1.  **Глобальные ресурсы:** Ссылки на корни дисков и каталоги.
2.  **Сессия Capture One:** Древовидная структура папок `Capture`, `Output`, `Selects` и их содержимое.
3.  **Работа с альбомами:** Структура PSD файлов и шаблонов.

### Шаблон "Dashboard" (Плитка)
Ориентирован на контроль выполнения этапов.
*   **Уровень Проекта:** Верхняя таблица со ссылками на основные папки сессии.
*   **Блоки Сессий:** Для каждой фотосессии создается отдельная панель:
    *   **Заголовок:** Имя сессии. Если в папке `Capture` найдены `.xmp` файлы, появится зеленый индикатор **[XMP найдены]**.
    *   **Таблица ресурсов:** Ссылки на `AI Analysis`, `JPG`, `Masks`, JSON-файлы и итоговый отчет.
    *   **Цветовая индикация:**
        *   **Зеленый:** Ресурс существует.
        *   **Красный:** Критический ресурс отсутствует.
        *   **Серый:** Некритичный ресурс отсутствует.
