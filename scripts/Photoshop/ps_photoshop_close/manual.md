# Руководство по использованию скрипта "Закрытие Photoshop" (v1.00.00)

## 1. Назначение

Этот скрипт является служебным и предназначен для корректного завершения работы Adobe Photoshop.

Его основные задачи:

1. Проверить, запущен ли Adobe Photoshop.
2. Если Photoshop не запущен — завершить работу без ошибки.
3. Если Photoshop запущен — подключиться к нему через программный интерфейс API.
4. Отправить команду штатного закрытия Photoshop.
5. Дождаться полного завершения процесса.
6. При необходимости принудительно завершить процесс Photoshop.

Скрипт рекомендуется ставить в наборах после всех скриптов, которые работают с Photoshop.

---

# 2. Параметры

## Принудительное завершение (`force_kill`)

- **Тип:** Логический параметр
- **Обязательный:** Нет
- **Значение по умолчанию:** `false`

### Описание

Если включено, скрипт принудительно завершит процесс Photoshop, если штатное закрытие через API не удалось или Photoshop не завершился за отведенное время.

---

# 3. Логика работы

## 3.1 Проверка процесса

Скрипт проверяет, есть ли в системе запущенный процесс Photoshop:

### Windows
```text
Photoshop.exe
````

### macOS

```text
Adobe Photoshop
```

---

## 3.2 Если Photoshop не запущен

Скрипт выводит сообщение:

```text
Photoshop не запущен.
```

После этого скрипт завершается успешно с кодом выхода `0`.

---

## 3.3 Подключение к Photoshop

Если Photoshop запущен, скрипт пытается подключиться к нему через библиотеку:

```text
photoshop-python-api
```

После успешного подключения скрипт получает информацию о приложении:

* имя Photoshop
* версия Photoshop

---

## 3.4 Штатное закрытие Photoshop

Для закрытия Photoshop используется ExtendScript-команда Photoshop, выполняемая через API:

```javascript
var idquit = charIDToTypeID("quit");
executeAction(idquit, undefined, DialogModes.ALL);
```

Команда отправляется через:

```python
app.doJavaScript(...)
```

## 3.5 Ожидание завершения

После отправки команды закрытия скрипт ожидает завершения процесса Photoshop.

### Таймаут ожидания

```text
60 секунд
```

Если процесс Photoshop завершился — скрипт завершается успешно.

---

## 3.6 Если Photoshop не закрылся

Возможны две ситуации:

### Вариант 1 — `force_kill = false`

Скрипт завершится с ошибкой.

### Вариант 2 — `force_kill = true`

Скрипт попытается принудительно завершить процесс Photoshop.

---

# 4. Принудительное завершение

Принудительное завершение используется только при включенном параметре:

```bash
--force_kill
```

В этом режиме скрипт завершает найденные процессы Photoshop напрямую через системный менеджер процессов.

---

## Важно

Принудительное завершение:

* может закрыть Photoshop без сохранения документов;
* может привести к потере несохраненных изменений;
* рекомендуется использовать только как резервный механизм.

---

# 5. Возможные причины невозможности штатного закрытия

Штатное закрытие Photoshop может не сработать, если:

* Photoshop завис;
* открыто модальное окно;
* открыто окно сохранения документа;
* открыт диалог подтверждения;
* Photoshop выполняет длительную операцию;
* API Photoshop недоступен;
* COM-подключение заблокировано;
* пользователь вручную отменил закрытие.

---

# 6. Типовые сценарии использования

## 6.1 Обычное закрытие Photoshop

Используется для корректного завершения Photoshop после обработки.

### Рекомендуемый режим

```text
force_kill = false
```

### Логика

1. Скрипт подключается к Photoshop.
2. Отправляет команду штатного закрытия.
3. Ожидает завершения процесса.
4. При ошибке завершает работу.

---

## 6.2 Гарантированное завершение Photoshop

Используется, когда Photoshop должен быть закрыт в любом случае.

### Рекомендуемый режим

```text
force_kill = true
```

### Логика

1. Скрипт пытается закрыть Photoshop штатно.
2. Если это не удалось — выполняется принудительное завершение процесса.
3. Проверяется, что Photoshop действительно завершен.

---

# 7. Коды выхода

## Код выхода `0` — Успех

Означает одно из следующих состояний:

* Photoshop не был запущен;
* Photoshop успешно закрыт штатно;
* Photoshop успешно завершен принудительно.

---

## Код выхода `1` — Ошибка

Ошибка возникает если:

* не удалось подключиться к Photoshop;
* Photoshop не завершился после штатной команды;
* принудительное завершение отключено;
* принудительное завершение не удалось;
* процесс Photoshop остался активным после всех попыток закрытия.

При получении кода `1` выполнение всей цепочки скриптов будет остановлено.

# 8. Рекомендации

## Рекомендуемый порядок использования

1. Скрипт запуска Photoshop
2. Скрипты обработки изображений
3. Скрипт закрытия Photoshop

---

## Рекомендации по режимам работы

### Для обычной работы

Рекомендуется использовать:

```text
force_kill = false
```

Это позволяет Photoshop завершиться штатно.

---

### Для автоматических batch-процессов

Рекомендуется использовать:

```text
force_kill = true
```

если необходимо гарантированно освободить систему от процесса Photoshop после завершения обработки.
