# Генератор HTML-отчёта

## Назначение

Скрипт создаёт интерактивный `face_clustering_report.html` для визуальной
проверки портретных кластеров и найденных лиц на групповых фотографиях.

ФИО ученика берётся только из файла `*.list` по `student_id`. Поля с именами в
`info_faces.json` и `matches_portrait_to_group.json` не используются.

## Входные данные

- `a_hr_target_dir` — папка `Output/Analysis_...` текущей фотосессии;
- `a_hr_ref_dir` — необязательная папка с эталонными портретами; если она не
  задана, используется `a_hr_target_dir`;
- `a_hr_student_list_file` — обязательный актуальный файл `*.list`.

Из эталонной папки читается `info_faces.json` с портретными кластерами. Из
целевой папки читаются `info_faces.json` и, если он существует,
`matches_portrait_to_group.json`.

В кросс-сессионном режиме файл `*.list` должен содержать `student_id`, которые
назначены эталонным портретам. Один список можно использовать для нескольких
фотосессий одной школьной сессии.

## Проверка идентичности

Перед созданием отчёта скрипт проверяет:

- формат `list_id` и `student_id` вида `A7K3-S001`;
- уникальность записей списка и наличие фамилии и имени;
- один `student_id` внутри каждого портретного кластера;
- отсутствие одного `student_id` в нескольких портретных кластерах;
- соответствие `student_id` между портретным кластером, matches и лицами на
  групповых фотографиях;
- структуру ссылок `group_photos`.

Неиспользованные ученики в `*.list` разрешены. Неидентифицированный портретный
кластер блокирует отчёт: сначала назначьте ученика в «Редакторе кластеров».
Кластер `-1` считается шумом и не требует `student_id`.

## Результат

В целевой папке создаются:

- `face_clustering_report.html`;
- `report_style.css`;
- `report_script.js`;
- `lazyload.min.js`.

В карточках отдельно отображаются ФИО, `Student ID` и `Cluster ID`. В сводке
также показываются `list_id`, число идентифицированных учеников и количество
неиспользованных записей списка.

Основные JSON-файлы читаются строго. Повреждённый или отсутствующий
`info_faces.json`, а также повреждённый matches завершают скрипт ошибкой.
Отсутствующий `matches_portrait_to_group.json` означает пустой раздел
совпадений. HTML записывается атомарно, поэтому при ошибке не остаётся
частично сформированный отчёт.
