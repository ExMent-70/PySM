# Changelog

## v2.2026.10.23

- Уточнена логическая семантика источников фотосессия/локация для плоских фотографий и JSON схемы 2.
- В таблице отображается «Локация / значение»; формат карточек и независимые override сохранены.

## v2.2026.10.20

- Добавлена работа с несколькими фотосессиями в одном шаблоне: обязательные
  назначения `фотосессия/папка` сохраняются для точных меток каждого мастера.
- Панель папок показывает сворачиваемые секции всех фотосессий из
  `sys_location_name`; папки без превью и пустые секции в панели скрыты.
- Выбор строки раскрывает нужную секцию и выделяет точный источник;
  смешанные групповые назначения обозначаются как «Разные источники».
- Неполные и отсутствующие в справочнике источники требуют переназначения.


## v2.2026.10.18

- Исправлена ошибка `Internal C++ object (FullScreenViewer) already deleted`
  при закрытии полноэкранного превью: убран повторный вызов удаления диалога,
  который уже освобождается Qt автоматически.
- Добавлены регрессионные тесты повторного открытия и закрытия превью,
  переключения масштаба и двойного клика по пустому превью.

## v2.2026.09.06

- Добавлена build-time настройка `DEMO_MAX_TEMPLATES` в отдельном файле
  `domain/demo_settings.py`.
- Положительное значение ограничивает создание и копирование карточек шаблонов;
  `0` сохраняет полноценный режим без искусственных ограничений.
- Существующие карточки не скрываются и остаются доступными для просмотра,
  редактирования и удаления, даже если каталог уже превышает демо-лимит.
- При достижении лимита интерфейс показывает явное сообщение демонстрационной
  версии до открытия диалога создания.
- Список локаций активной фотосессии читается из структурированной переменной
  `sys_location_name.<wf_photo_session>` вместо устаревшего имени с подчёркиванием.

## v2.2026.08.28

- В таблице плейсхолдеров произвольные нумерованные графические метки, включая
  `group_photo_01` и `group_photo_02`, больше не сворачиваются в общую строку
  `group_photo_*` и могут получать разные папки и настройки.
- Графическая группировка и наследование по числовому префиксу ограничены
  семействами `portrait_N` и `teacher_N`.
- Устаревшие правила позиционирования `by_prefix` для неподдерживаемых
  графических семейств разворачиваются в независимые настройки точных меток.
- Добавлены отрицательные регрессионные тесты для `group_photo_N`.

## v2.2026.08.02

- Устранены коллизии составных превью: новое имя содержит устойчивый ID
  карточки, а длинные компоненты сокращаются с сохранением уникальности.
- Повторные копии карточки получают уникальные названия `(копия)`, `(копия) 2`
  и далее.
- Превью внешних IDML сохраняются внутри `_CatalogPreviews/_external` текущего
  каталога и больше не создают служебную папку рядом с внешним шаблоном.
- Сохранена загрузка старых имён превью; устаревшие соседние
  `*_catalog_preview.jpg` больше не дублируются в карусели.
- Ошибки создания папки или записи JPG превью обрабатываются без падения
  карточки шаблона.
- Выбор карточки больше не запускает синхронный повторный разбор IDML в
  GUI-потоке; полная проверка выполняется при редактировании и сохранении.
- Закрытые модальные диалоги тегов, сниппетов и полноэкранного просмотра
  освобождаются после извлечения результата.
- Переименование категории сниппетов в существующую категорию запрещено и
  больше не приводит к молчаливому объединению данных.
- Исправлена обработка ошибок валидации при создании карточки сниппета.
- Добавлена единая проверка обязательных полей карточки шаблона.
- Составные превью `*_catalog_preview.jpg` сохраняются в отдельной папке
  `_CatalogPreviews` рядом с `templates` с повторением структуры подпапок шаблонов.
- Базовые превью по-прежнему загружаются рядом с IDML; сохранена поддержка ранее
  созданных составных превью в старом расположении.
- Отсутствующее составное превью больше не считается ошибкой и заново создаётся
  при следующем сохранении карточки шаблона.

## v2.2026.07.27

- Уточнён контракт взаимодействия с Генератором: специализированными
  нумерованными слотами общей виньетки являются только `portrait_N` и
  `teacher_N`; для остальных графических меток персональность определяется
  исключительно настройкой override.
- В контекстное меню категорий каталога сниппетов добавлена команда
  «Обновить категорию».
- Команда в фоне пересканирует актуальные IDMS выбранной категории и её
  подкатегорий, обновляя файловые сведения карточек.
- Пользовательские теги, названия, описания, категории и ID карточек
  сохраняются.
- Поврежденные или отсутствующие IDMS показываются в итоговом отчете без
  удаления прежних данных карточки; отмена отбрасывает частичный результат.
- Добавлены регрессионные тесты обновления вложенной категории, сохранения
  тегов и обработки отсутствующего файла.

## v2.2026.07.26

- Добавлен режим карточки `multipage_personal_vignette`.
- Новый режим получает полный набор мастеров, их индивидуальные override,
  positioning и IDMS-привязки.
- Точная персональная метка `child_fullname` больше не считается старой
  маской семейства: отключённые `child_fullname_N` не включаются повторно
  при сохранении карточки.
- Семейства из двух и более нумерованных меток сворачиваются в групповую
  строку `prefix_*` для общего управления override, папкой и
  позиционированием.
- Добавлена настройка `move_duplicate_small_portrait` в пространстве имён
  нового режима.
- Добавлен режим карточки `multipage_vignette`.
- Для нового режима в контекст передаются все мастер-страницы с их точными
  метками, сопоставлениями, override, позиционированием и IDMS-привязками.
- Сохранена active-only передача данных для существующих режимов.
- Документирован контракт взаимодействия с `idsgn_spread_generator`.

## v2.2026.07.25

- Исправлена ошибка фонового импорта IDMS: запоздалые сигналы worker больше не обращаются к уже удалённому окну прогресса.
- В контекстное меню панели шаблонов добавлено подменю «Сортировка».
- Доступна естественная сортировка по названию, основе имени IDML-файла и типу шаблона.
- Сортировка по названию используется по умолчанию, а выбранный режим сохраняется в состоянии основного окна.

## v2.2026.07.20

- Исправлен регресс последней итерации: текстовые override-настройки подключённых сниппетов больше не удаляются до объединения меток базового IDML и IDMS.
- Настройки обычных плейсхолдеров разворота (`placeholder_map`, графические и текстовые override, позиционирование) снова сохраняются в JSON каталога и передаются через `model_dump()`.
- Разбор IDML кэшируется по пути, размеру и времени изменения файла; метки, мастер-страницы и слои извлекаются за один проход.
- Массовый импорт IDMS из папки перенесён из GUI-потока в фоновый worker; добавлены прогресс, отмена и атомарное применение результата.
- Подготовка составного превью при сохранении карточки стала асинхронной и больше не блокирует GUI ожиданиями до 20 секунд.
- Локальный кэш полноразмерных исходников превью ограничен байтовым LRU-лимитом.
- Группы плейсхолдеров со смешанным состоянием override теперь отображаются tri-state чекбоксом.
- Нормализация и развёртывание текстовых плейсхолдеров вынесены в единый доменный модуль.
- Исправлен контракт нумерованных текстовых плейсхолдеров: метки `child_name_0`, `child_name_1` и аналогичные больше не сокращаются до базового имени и передаются Генератору как отдельные элементы `override_text_labels`.
- Старые настройки с базовыми именами текстовых плейсхолдеров автоматически разворачиваются по фактическим нумерованным меткам текущего IDML.
- Добавлена обязательная проверка уникальности `BaseName` мастер-страниц. Карточка не сохраняется, если в IDML есть мастера с одинаковым базовым именем.
- Выбранный мастер повторно сверяется с текущим IDML перед записью контекста, даже если пользователь не менял выбранный шаблон.
- При переименовании активного мастера безопасно выбирается первая доступная мастер-страница; устаревший UID больше не передается Генератору.
- Добавлено предупреждение о несопоставленных неактивных мастер-страницах и сниппетах, которые не удалось перенести.
- Ошибки чтения поврежденного или неполного IDML обрабатываются без падения диалога и блокируют сохранение некорректной карточки.
- Удаляются устаревшие настройки позиционирования плейсхолдеров, отсутствующих в актуальном IDML и подключенных сниппетах.
- Исправлено открытие карточек шаблонов после повторного экспорта исходного IDML из InDesign: активная мастер-страница и подключенные сниппеты восстанавливаются по имени мастер-страницы, если InDesign пересоздал UID Master Spread.
- В карточке шаблона дополнительно сохраняется имя активной мастер-страницы, а у привязок сниппетов - имя целевой мастер-страницы.
- Предпросмотр мастер-страницы больше не прерывает открытие диалога при устаревшем UID в старой карточке.
- Если мастер-страница была переименована и не может быть сопоставлена автоматически, диалог показывает предупреждение и выбирает первую доступную мастер-страницу.
- Исправлен регресс: при открытии карточки больше не сбрасываются папки, override и позиционирование плейсхолдеров, добавленных подключенными IDMS-сниппетами.

## v2.2026.07.18

- Добавлен массовый импорт IDMS-сниппетов из выбранной папки в текущую категорию каталога сниппетов.
- Добавлен экспорт выбранной категории сниппетов в JSON.
- Добавлен импорт сниппетов из JSON в текущую категорию.
- Повторный импорт одного и того же IDMS обновляет существующую карточку вместо создания дубля.
- В отчете импорта перенос существующего сниппета в другую категорию учитывается отдельно от обновления.
