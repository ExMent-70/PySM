# История изменений cluster_editor

## 2.2026.10.24

### Добавлено

- В режиме `matches` после ручного назначения выполняется фоновый поиск похожих неопознанных лиц по эмбеддингам рабочей фотосессии.
- В строке фильтров добавлена настройка максимального косинусного расстояния «Порог сходства» (начальное значение `0.30`).
- Найденные лица подтверждаются по фотографиям через диалог выбора: назначение, пропуск или завершение очереди. Поддерживаются несколько исходных образцов без цепочного расширения поиска.
- Добавлены отмена поиска, проверки актуальности кандидатов и подтверждение дополнительного лица уже присутствующего ученика.
- Добавлены синтетические проверки поиска, фоновой обработки, подтверждений и сохранения.
- В диалогах подтверждения поиска похожих лиц и повторного назначения явно заданы русские подписи кнопок «Да» и «Нет».
- Предупреждение о повторном назначении показывает фотографию и ученика, объясняет последствия кнопок «Да» и «Нет» и сохранение прежнего соответствия.
- В диалоге сохранения перед выходом и сменой съёмки кнопки явно переведены: «Сохранить», «Не сохранять», «Отмена».

## v2.2026.06.30

### Изменено

- Редактор разделён на специализированные контроллеры хранения, экспорта, фильтрации и обработки изображений.
- Усилены атомарное сохранение JSON, контроль student ID, режимы стратегий и обработка ошибок экспорта.
- Галерея и предпросмотр переведены на общий асинхронный image-cache pipeline PySM.
- Добавлены необязательные параметры `ce_working_img_dir` и `ce_reference_img_dir` для явного указания папок с изображениями.
- Режим `cleaning` больше не требует наличия `ce_student_list_file`.
- В режиме `location` ключ контекста для списка локаций и обложек изменён с `sys_location_name_{wf_photo_session}` на `sys_location_name.{wf_photo_session}`.
- В режиме `matches` список лиц выбранного фото сортируется так, чтобы неопознанные лица или лицо текущего портретного кластера были первыми.
- При экспорте с водяными знаками подпись на фото теперь использует последние 6 цифр имени файла, а не 4.

### Добавлено

- Контроллер экспорта, типизированные image requests, фильтр photo selection и загрузка реестра учеников.
- Автоматические тесты сохранения, экспорта, фильтров, hover-поведения, student ID и image pipeline.
