# Скрипт "Анализ лиц" (v2025.12.24)

## 1. Назначение

Скрипт **"Анализ лиц"** является ядром рабочего процесса фотографа. Он выполняет глубокий анализ изображений с использованием нейросетевых моделей. Его задача — найти все лица на подготовленных JPEG-файлах, извлечь их ключевые характеристики и сохранить эту информацию в структурированном виде для последующих этапов (кластеризации, поиска, XMP).

## 2. Логика работы

1.  **Загрузка конфигурации:** Скрипт использует локальный файл `config.toml`, который содержит параметры моделей (`insightface`, модели атрибутов) и настройки ускорения (ONNX Provider).
    **Поддерживаемые модели детекции:** `antelopev2`, `buffalo_l` (рекомендуемая), `buffalo_m`, `buffalo_s`, `buffalo_sc`.

2.  **Автоматическое определение путей:** Скрипт считывает переменные контекста PySM:
    *   **Входная папка:** `{папка_сессии}/{имя_сессии}/Output/Analysis_{фото_сессия}/JPG`
    *   **Выходная папка:** `{папка_сессии}/{имя_сессии}/Output/Analysis_{фото_сессия}`

3.  **Поиск изображений:** Сканирование входной папки на наличие `.jpg` файлов.

4.  **Параллельный анализ:** Обработка выполняется в многопоточном режиме:
    *   **Детекция:** Поиск координат лиц.
    *   **Векторизация:** Вычисление уникального цифрового отпечатка (эмбеддинга) для каждого лица.
    *   **Атрибуты:** Определение пола, возраста, эмоций и состояния глаз (открыты/закрыты).

5.  **Сохранение результатов (Оптимизированное):**
    Результаты сохраняются в разделенные JSON-файлы для максимальной производительности системы:
    *   `info_portrait_faces.json` / `info_group_faces.json`: Основные данные (координаты, атрибуты, имена). Используются большинством скриптов.
    *   `info_portrait_landmarks.json` / `info_group_landmarks.json`: Детальная геометрия лица (106 точек). Загружаются только по требованию (например, для детального анализа глаз).
    *   `_Embeddings/`: Папка с бинарными файлами `.npy` (векторы лиц) для быстрого поиска.

## 3. Параметры запуска

-   **`a_af_config_file`**: Путь к `config.toml`. Обычно не требует изменения.
-   **`all_threads`**: Количество потоков обработки. `0` — использовать все доступные ядра CPU.
-   **`a_af_det_thresh`**: Порог уверенности детектора (0.0 - 1.0). Переопределяет настройку в конфиге.

## 4. Подробное описание параметра det_thresh

Параметр `det_thresh` (Detection Threshold) — это **фильтр по уверенности** нейросети.

Когда модель сканирует изображение, она находит сотни потенциальных областей и присваивает им вероятность (score) от **0.0** до **1.0**. `det_thresh` устанавливает границу отсечения.

### Как это работает на практике:

#### 1. ВЫСОКИЙ порог (0.8 - 0.9): "Строгий контролер"
*   **Что происходит:** Пропускаются только лица с уверенностью близкой к 100%.
*   **Плюсы:** Нет "ложных срабатываний" (узоров на обоях, коленок).
*   **Минусы:** Высокий риск пропустить смазанные лица, профили или лица в тени.

#### 2. НИЗКИЙ порог (0.1 - 0.3): "Искать всё, что похоже"
*   **Что происходит:** Помечается всё, что отдаленно напоминает лицо.
*   **Плюсы:** Находятся сложные лица (размытые, мелкие, закрытые рукой).
*   **Минусы:** Много "мусора" (призраков в листве, складках одежды).

#### 3. Баланс (0.5 - по умолчанию)
"Золотая середина". Обеспечивает баланс между чистотой выборки и полнотой поиска.

### Рекомендации для фотографа:

*   **Портреты:** Можно ставить порог выше (**0.6 - 0.7**). Лицо главное и четкое, мусор на фоне не нужен.
*   **Групповые фото:** Если пропускаются лица на задних рядах, понизьте порог до **0.35 - 0.4**.
    *   *Совет:* Мусор, который может появиться при низком пороге, обычно легко отсеивается на этапе кластеризации (попадает в папку "Noise" или мелкие кластеры).

## 5. История изменений

### Версия 2025.12.24
-   **Архитектура:** Внедрено разделение данных. "Тяжелые" геометрические данные (landmarks 106 точек) вынесены в отдельные файлы `*_landmarks.json`. Это значительно ускорило чтение/запись данных в последующих скриптах (кластеризация, отчеты).
-   **Оптимизация:** Переписан модуль записи результатов (`ResultWriter`) для поддержки новой структуры данных.
-   **Надежность:** Улучшена обработка Unicode-путей в Windows.

### Версия 2025.06.10
-   **Релиз:** Первая стабильная версия с поддержкой InsightFace buffalo_l и многопоточности.
