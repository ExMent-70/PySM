# Скрипт «Выбор фотографий по номерам» (v2.2026.06.21)

## Назначение

Скрипт извлекает номера фотографий из произвольного текста, ищет связанные
RAW/JPG/XMP-файлы, показывает данные анализа и копирует найденные файлы в
папки локаций. По выбору пользователя он синхронизирует
`matches_portrait_to_group.json`.

Скрипт не изменяет XMP. Для создания XMP используется отдельный `create_xmp`.

## Источники данных

- `info_faces.json` — фотографии, лица, `student_id` и локации;
- `matches_portrait_to_group.json` — связи учеников с групповыми кадрами;
- `*.list` — единственный источник фамилии и имени.

Файл `*_children.txt` этому этапу не нужен.

Перед открытием рабочего интерфейса проверяется согласованность ID. Неизвестный
ID, портретный кластер без ID или конфликт между `matched_portrait_cluster_label`
и matches блокирует обработку. Неопознанные лица групп и шум допустимы.

## Работа в интерфейсе

1. Вставьте текст с номерами и нажмите `1. Извлечь номера`.
2. Нажмите `2. Найти файлы`.
3. Проверьте найденные файлы, учеников и локации.
4. Нажмите `3. Копировать файлы`.
5. При необходимости включите `Синхронизировать matches.json`.

Для одиночного портрета столбец `Ученики` показывает ФИО. Для группового кадра
выводится компактная строка `Список учеников (N)`, чтобы таблица не растягивалась.
Наведите указатель на ячейку: во всплывающей многострочной подсказке будут
показаны все уникальные распознанные ученики фотографии.

## Копирование и переименование

Файлы копируются в подпапки `location_name` внутри `dest_dir`. Относительная
структура исходных подпапок сохраняется.

Если включён `--rename-files`:

- фотография одного уникального ученика получает имя
  `Фамилия Имя-Номер.ext`;
- фотография без ID сохраняет исходное имя;
- групповая фотография с несколькими учениками сохраняет исходное имя;
- запрещённые Windows-символы в ФИО заменяются безопасными символами.

## Синхронизация matches

Синхронизация выполняется по `student_id`, а не по ФИО. Если на выбранной
групповой фотографии найдено несколько учеников, файл добавляется в
`group_photos` каждой соответствующей записи.

Ключи портретных кластеров и поле `student_id` сохраняются. ФИО в JSON не
записывается. Файл обновляется атомарно через временный файл.

## Параметры запуска

- `--analysis_dir` — папка с `info_faces.json` и matches;
- `--source_dir` — корневая папка поиска исходных файлов;
- `--student_list_file` — обязательный файл `*.list`;
- `--dest_dir` — папка результатов, обязательна при копировании;
- `--min_digits`, `--max_digits` — длина номера фотографии;
- `--exclude_dirs` — исключаемые подпапки;
- `--rename-files` — переименовывать одиночные идентифицированные фотографии;
- `--copy-files` — выполнять физическое копирование.

## История изменений

### Версия 2.2026.06.21

- идентификация и синхронизация переведены на `student_id`;
- ФИО загружается только из `*.list`;
- интерфейс показывает всех учеников группового кадра;
- неоднозначные групповые кадры больше не переименовываются по первому лицу;
- запись matches стала атомарной;
- руководство приведено в соответствие с фактическим CLI.
