# Скрипт "Пакетная обработка по номерам" (v2025.12.12)

## 1. Назначение

Этот скрипт является универсальным инструментом для пакетной обработки фотографий на основе списка номеров. Он позволяет, как из конструктора, собрать необходимую последовательность действий, управляя ими через параметры запуска.

**Ключевые операции:**
1.  **Обновление XMP:** Прописывает в метаданные файлов информацию о "локации" (выборке).
2.  **Переименование:** Готовит новые имена для файлов по шаблону `<Имя>-<Номер>`.
3.  **Копирование:** Копирует файлы в целевую папку, раскладывая их по подпапкам-локациям и применяя (если включено) новые имена.
4.  **Синхронизация (GUI):** Опционально обновляет файл `matches_portrait_to_group.json` на основе ручной выборки.

## 2. Логика работы

1.  **Запуск и конфигурация:** При запуске скрипт считывает параметры командной строки, которые определяют, какие операции будут выполнены (`--update-xmp`, `--rename-files`, `--copy-files`).

2.  **Ввод и анализ номеров:** Пользователь вставляет текст с номерами и нажимает **"1. Извлечь номера"**. Скрипт находит все числовые последовательности нужной длины.

3.  **Поиск и сопоставление:** После нажатия **"2. Найти файлы"**, скрипт сканирует исходную папку, находит все файлы по номерам и сопоставляет их с данными из JSON-отчетов (`info_*.json`) для определения имени и локации.

4.  **Выполнение операций:** Нажатие кнопки **"3. Выполнить операции"** запускает последовательное выполнение всех **включенных** в параметрах задач:
    *   **Если включен `--update-xmp`:** Скрипт проходит по всем найденным файлам и записывает в их XMP-сайдкары `Location` и ключевое слово `loc_{Location}`.
    *   **Если включен `--copy-files`:**
        *   Скрипт создает в папке `--dest-dir` подпапки, соответствующие `location_name`.
        *   **Если включен `--rename-files`:** Файлы копируются в эти подпапки с новыми именами (`<Имя>_<Номер>.ext`).
        *   **Если `--rename-files` выключен:** Файлы копируются с оригинальными именами.
    *   **Если в GUI включен чекбокс "Синхронизировать matches.json"**: После всех операций обновляется файл `matches_portrait_to_group.json`.

## 3. Требования

-   Запуск в среде PySM.
-   Наличие и корректное указание путей к файлам `info_portrait_faces.json` и `info_group_faces.json`.
-   Наличие модуля `_common` в структуре проекта.

## 4. Параметры

-   **`--portrait_json`**, **`--group_json`**, **`--source_dir`**: (обязательные) Пути к файлам данных и исходным файлам.
-   **`--dest_dir`**: (условно-обязательный) Корневая папка для результатов. **Обязателен, если включена опция `--copy-files`**.
-   **`--min_digits`**, **`--max_digits`**: (необязательные) Диапазон длины искомых номеров.
-   **`--exclude_dirs`**: (необязательный) Список подпапок для исключения из поиска.
-   **`--update-xmp`**: (флаг) Включить обновление XMP-тегов.
-   **`--rename-files`**: (флаг) Включить переименование файлов при копировании.
-   **`--copy-files`**: (флаг) Включить копирование файлов.

## 5. История изменений

### Версия 2025.12.12
-   **Улучшено:** Скрипт преобразован в модульный "комбайн". Операции обновления XMP, переименования и копирования стали независимыми и управляются через флаги командной строки (`--update-xmp`, `--rename-files`, `--copy-files`).
-   **Улучшено:** Поиск номеров стал гибким, настраивается через параметры `min_digits` и `max_digits`.
-   **Добавлено:** Возможность исключать подпапки из поиска с помощью параметра `--exclude-dirs`.

### Версия 2025.11.30
-   **Создание скрипта:** Первая версия, реализующая функционал сортировки по папкам-локациям и опциональной синхронизации `matches.json`.
