# История изменений cluster_locations2

## v2.2026.09.11

### Исправлено

- Маркер успешного выполнения location-анализа теперь записывается в
  `var_claster_run.<wf_photo_session>.location` по переменной контекста
  `wf_photo_session`. Ранее использовалась ошибочная переменная
  `ws_photo_session`, из-за чего при отсутствии такого ключа результат мог
  записываться в fallback-сессию `SCHOOL`.

## v2.2026.09.06

### Исправлено

- При чтении PNG chunk `iCCP` удаляется из копии файла в памяти перед передачей
  в OpenCV. Это устраняет предупреждение libpng
  `iCCP: known incorrect sRGB profile`, не изменяя исходные изображения.
