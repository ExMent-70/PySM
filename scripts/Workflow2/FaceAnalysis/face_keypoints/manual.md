# Руководство по скрипту "Анализ ключевых точек" (v2025.12.24)

## 1. Назначение

Скрипт **"Анализ ключевых точек"** является промежуточным этапом обработки, который обогащает данные, полученные после анализа и кластеризации. Его основная задача — на основе точных координат ключевых точек лица (`landmark_2d_106`) и данных о позе (`pose`) вычислить и записать более высокоуровневые характеристики:

*   **Состояние глаз:** Открыты, закрыты, прищурены (Wide Open, Open, Squinting, Closed).
*   **Состояние рта:** Закрыт, приоткрыт, открыт.
*   **Положение головы:** Фронтальное, в профиль (Yaw/Pitch/Roll).

Эта информация критически важна для последующих этапов, таких как создание детализированных XMP-тегов и фильтрация фотографий.

## 2. Логика работы

1.  **Автоматическое определение путей:** Скрипт автоматически определяет путь к папке с результатами предыдущих этапов на основе информации о текущем рабочем процессе из PySM:
    *   **Папка с данными:** `{папка_сессии}/{имя_сессии}/Output/Analysis_{папка_фото_с_камеры}`

2.  **Загрузка данных (Smart Load):**
    *   Скрипт загружает основные файлы (`info_portrait_faces.json` и `info_group_faces.json`).
    *   **Новое:** Автоматически находит и подгружает "тяжелые" файлы с геометрией (`info_portrait_landmarks.json` и `info_group_landmarks.json`). Это позволяет работать с новой оптимизированной структурой данных.

3.  **Загрузка порогов:** Из локального файла `config.toml` считываются численные пороги, которые определяют, как интерпретировать рассчитанные метрики (например, какое значение EAR — Eye Aspect Ratio — считать "закрытым глазом").

4.  **Слияние и Анализ:** Скрипт объединяет в памяти данные о лице с его геометрическими точками и выполняет математические расчеты углов и расстояний.

5.  **Обновление JSON:** Результаты анализа (текстовые статусы) добавляются в виде нового поля `keypoint_analysis` к записи о каждом лице в **основные** JSON-файлы. Сами файлы ландмарков не изменяются.

6.  **Сохранение результатов:** После обработки всех лиц обновленные основные файлы перезаписываются на диск. Также создаются файлы со статистикой и рекомендациями по тонкой настройке порогов.

## 3. Параметры

-   **`a_ak_config_file`** (служебный):
    -   **Назначение:** Путь к файлу `config.toml` с техническими параметрами (порогами) для анализа.
    -   **Источник:** Определяется автоматически.

## 4. История изменений

### Версия 2025.12.24
-   **Архитектура:** Добавлена поддержка загрузки ландмарков (`landmark_2d_106`, `landmark_3d_68`) из отдельных файлов `*_landmarks.json`.
-   **Оптимизация:** Скрипт адаптирован к новой схеме раздельного хранения данных: тяжелая геометрия читается из отдельных файлов, а легкие результаты анализа записываются в основные файлы метаданных.
