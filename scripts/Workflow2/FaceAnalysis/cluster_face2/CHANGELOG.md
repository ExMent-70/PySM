# История изменений cluster_face2

## 2.2026.08.20

### Изменено

- Идентификация лиц переведена с полей ФИО на постоянный `student_id`;
  устаревшие `child_name` и `matched_child_name` удаляются из результатов.
- Режим `face` загружает порядок `student_id` из структурированной переменной
  `wf_student_ids_order.{wf_photo_session}_ids_order`.
- Удалены поиск и загрузка файлов `*_children.txt`; параметры пути не требуются.
- Проверки формата, уникальности, общего `list_id` и порядка сопоставления
  сохранены для JSON-массива контекста.
- При несовпадении количества портретных кластеров и ID частичное назначение
  отключается, а кластеры сохраняются для ручной идентификации.
- Режим `matches` проверяет согласованность ID в эталонах и отчётах, округляет
  дистанции до четырёх знаков и записывает JSON атомарно.
- Маркеры завершения режимов сохраняются в `var_claster_run` по текущему
  значению `wf_photo_session`.
