# Руководство по скрипту "Экспорт в JPEG" (v2.2026.03.16)

## 1. Назначение

Скрипт **"Экспорт в JPEG"** является первым и обязательным шагом в рабочем процессе анализа фотографий. Его основная задача — преобразовать исходные тяжелые файлы изображений из форматов RAW (например, `.CR2`, `.NEF`, `.ARW`) или PSD в универсальный и легкий формат JPEG. Это необходимо для того, чтобы последующие ресурсоемкие скрипты (например, распознавание лиц) могли работать с файлами максимально быстро.

*Примечание к версии v2.2026.03.16: Скрипт полностью переписан для работы в многопоточном режиме, оптимизировано потребление оперативной памяти и добавлена нативная поддержка кириллических символов в именах файлов и папок.*

## 2. Логика работы

1.  **Определение путей (Универсальность):** Скрипт принимает явные параметры исходной (`input_dir`) и целевой (`output_dir`) папок. При работе в экосистеме PySM эти пути могут формироваться и передаваться автоматически на основе переменных контекста сессии.

2.  **Безопасное чтение:** Скрипт сканирует исходную папку и находит все файлы, соответствующие выбранному типу. Открытие файлов происходит через бинарные потоки, что гарантирует 100% считывание даже если в пути есть русские буквы или спецсимволы.

3.  **Конвертация (Многопроцессорность):** Каждый найденный файл обрабатывается в изолированном процессе ОС. Это позволяет обойти ограничения Python (GIL) и задействовать все ядра вашего процессора на 100%, кратно ускоряя пакетную обработку.
    *   Для **RAW-файлов**: мгновенно извлекается встроенное в файл превью (без долгой дебайеризации).
    *   Для **PSD-файлов**: извлекается финальное композитное (сведённое) изображение.

4.  **Высококачественное масштабирование и сохранение:** Каждое извлеченное изображение масштабируется с использованием профессионального алгоритма (Lanczos) так, чтобы его длинная сторона не превышала заданный размер (`a_r2j_preview_size`). Затем оно сохраняется в выходную папку в формате JPEG с сохранением исходного цветового профиля (ICC).

## 3. Параметры

-   **`input_dir`** (Обязательный):
    -   **Назначение:** Полный путь к папке, содержащей исходные RAW/PSD файлы.
    
-   **`output_dir`** (Обязательный):
    -   **Назначение:** Полный путь к папке, куда будут сохранены конвертированные JPEG-файлы. Если папка не существует, она будет создана автоматически.

-   **`a_r2j_image_type`**:
    -   **Назначение:** Определяет, какие типы файлов искать в исходной папке.
    -   **Варианты:**
        -   `raw`: Обрабатывать только RAW-файлы.
        -   `psd`: Обрабатывать только PSD-файлы.
        -   `all`: Обрабатывать и RAW, и PSD.
    -   **Значение по умолчанию:** `raw`.

-   **`a_r2j_preview_size`**:
    -   **Назначение:** Устанавливает максимальный размер длинной стороны для создаваемых JPEG-файлов. Например, значение `4096` означает, что итоговое изображение будет не более 4096px по ширине или высоте.
    -   **Значение по умолчанию:** `4096`.

-   **`a_r2j_jpeg_quality`**:
    -   **Назначение:** Качество сжатия JPEG по шкале от 1 до 100. Более высокое значение означает лучшее качество и больший размер файла.
    -   **Значение по умолчанию:** `95`.

-   **`all_threads`**:
    -   **Назначение:** Количество одновременно работающих процессов (workers) для ускорения конвертации.
    -   **Значение по умолчанию:** `0`, что означает автоматическое определение оптимального числа процессов на основе количества логических ядер вашего процессора.
