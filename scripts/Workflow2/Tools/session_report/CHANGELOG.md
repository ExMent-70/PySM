# История изменений session_report

## 2.2026.08.28

### Изменено

- В поэтапном отчёте отсутствующие ресурсы получили серые иконки, а ресурсы
  этапов с предупреждениями — красные.
- Перед таблицей папок альбома добавлен общий результат копирования со ссылкой
  на `Альбом/Фото/<фотосессия>`; заголовок шаблонов InDesign теперь открывает
  папку `_ШАБЛОНЫ_`.

## 2.2026.08.27

### Изменено

- Добавлен третий шаблон `workflow` — последовательный отчёт по этапам
  подготовки заказа, обработки фотосессий и выпуска готовых материалов.
- Строка этапа теперь содержит индикатор, иконку-ссылку с подсказкой полного
  пути и описание. Отдельная дублирующая колонка состояния удалена.
- Общий сканер теперь собирает счётчики RAW/JPG/масок/XMP, читает маркеры
  `var_claster_run`, проверяет папки альбомных фотографий рекурсивно и учитывает
  папку `Выпускникам` в корне заказа.
- Обнаружение фотосессий больше не зависит только от содержимого `Capture`:
  учитываются также `Output/Analysis_*`, альбомные папки и `var_claster_run`,
  поэтому поздние этапы обработки видны и после перемещения исходных RAW.
- Путь к маскам обновлён до `Analysis_*/Masks/Cutout`; в блок фотосессии
  добавлены `photo_selection.json` и `photo_assignments.json`.
- Ссылка на эталонную фотосессию теперь ведёт в
  `Output/Analysis_{wf_portrait_session}` текущей сессии.
- Сбор путей и ресурсов вынесен в общий пакет
  `Tools/_common/project_resources`, используемый также Project CRM.
- Стандартный и dashboard-шаблоны теперь строятся из одного неизменяемого
  снимка файловой структуры и больше не выполняют собственное сканирование.
- Точка входа приведена к контракту `get_config()`; значения параметров и
  внешний HTML-вывод сохранены.
- Режим `current` явно сообщает об отсутствующем `wf_photo_session` вместо
  неявного показа всех папок `Analysis_*`.
- Добавлены характеристические и контрактные тесты рендереров, контекста и
  нестандартных состояний.

## 2.2026.08.20

### Изменено

- Из стандартного и dashboard-отчётов удалён файловый ресурс списка учеников.
- Скрипт больше не читает `wf_children_file_name`: порядок `student_id` хранится
  в контексте PySM и не отображается как файл.
- Исправлено определение корня репозитория для импорта API и работы `--help`.
