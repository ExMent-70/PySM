# Руководство по скрипту "Создание структуры папок для рабочего процесса" (v2.2026.03.18)

## 1. Назначение

Этот скрипт автоматизирует рутинную задачу подготовки рабочего пространства для новой фотосессии. Он стандартизирует процесс, создавая из заранее заготовленных шаблонов новую сессию в **Capture One** и иерархию папок для работы с **PSD-альбомами**. 

Скрипт поддерживает безопасное копирование: если целевые папки уже существуют, он может "слить" новые данные с существующими, предотвращая случайную потерю файлов.

## 2. Логика работы

Скрипт выполняет следующие шаги:

1.  **Принимает параметры:** имя проекта (сессии), пути для создания базы Capture One и рабочих PSD-файлов, а также флаги перезаписи.
2.  **Валидирует данные:** проверяет существование базовых директорий на диске и корректность имени новой сессии (отсутствие спецсимволов).
3.  **Создает структуру Capture One:** 
    *   Копирует внутренний шаблон `_TEMPLATE_SESSION_` в указанную директорию.
    *   Переименовывает шаблонный файл базы данных `.cosessiondb` в соответствии с именем сессии.
    *   Если папка уже существует, файлы копируются внутрь. При конфликте имен (если файл уже есть) решение о перезаписи принимается на основе флага `--wf_overwrite_session`.
4.  **Создает структуру Альбома:**
    *   Копирует внутренний шаблон `_TEMPLATE_ALBUM_` в указанную директорию для PSD.
    *   Логика слияния и перезаписи работает аналогично, управляясь флагом `--wf_overwrite_album`.
5.  **Логирует ссылки:** Выводит кликабельные ссылки на созданные директории в интерфейс PyScriptManager.

*Примечание: Скрипт **не** занимается копированием исходных RAW-файлов с флешки. Его задача — только подготовка структуры папок.*

## 3. Параметры

-   **Имя для новой сессии** (`wf_session_name`):
    -   Уникальное имя, которое будет присвоено папкам сессии C1, альбома и файлу `.cosessiondb`.
    -   *Пример:* `5A_class_photos`. Не должно содержать спецсимволов (`< > : " / \ | ? *`).

-   **Папка с исходными RAW-файлами** (`wf_raw_path`):
    -   Информационный параметр. Исторически используется в пайплайне для определения базового пути. В данном скрипте служит значением по умолчанию для папки PSD, если она не задана явно.
    -   *Пример:* `D:\PhotoArchive\RAW\2025`.

-   **Папка для создания сессии C1** (`wf_session_path`):
    -   Родительская директория, внутри которой будет создана рабочая папка Capture One. **Должна существовать на диске.**
    -   *Пример:* `E:\PhotoArchive\2025_Capture_One_Sessions`.

-   **Папка для создания Альбома (PSD)** (`wf_psd_path`):
    -   Родительская директория, внутри которой будет развернута структура для дизайна и верстки PSD. **Должна существовать на диске.**
    -   *Пример:* `E:\PhotoArchive\2025_Albums_PSD`.

-   **Перезапись файлов сессии C1** (`wf_overwrite_session`):
    -   Флаг (Вкл/Выкл). Если включен (`True`), при совпадении имен скрипт заменит существующие файлы в папке сессии C1 файлами из шаблона. Если выключен — существующие файлы будут пропущены и сохранены.

-   **Перезапись файлов Альбома** (`wf_overwrite_album`):
    -   Флаг (Вкл/Выкл). Работает аналогично предыдущему пункту, но для структуры папок PSD.
