## Копирование без окна: проверка 2026-09-17

Полная точка входа №2 проверена в отдельном процессе с `PY_SCRIPT_MANAGER_ACTIVE=1`.
Проверяются начальный, промежуточный и конечный счётчики JSON-протокола прогресса,
его закрытие, код 0 при успехе/повторном запуске и код 1 при ошибке входов или записи.
Создание `QApplication` и запуск `QThread` в этой проверке явно запрещены.
Нет загрузки GUI назначения и image pipeline; файлы выбора/назначений не меняются.
Проверен отказ от копирования при изменении selection-файла во время проверки.

Это проверка протокола, принимаемого главным окном PySM; само главное окно PySM
для испытания не запускалось. После добавления `mode` все 43 теста прошли.

Полная точка входа копирования запускается с тремя обязательными путями и
`exclude_dirs=Masks` по умолчанию. Проверен запуск без файла списка учеников,
с некорректными matches/assignments JSON и неизвестным распознанным ID:
копирование от них не зависит. Проверяются объединение выбора нескольких

независимо от содержимого, соседний XMP копируется, итоговый код — 0.
Остальные два скрипта сохраняют прежние параметры.

Через полную точку входа проверены `overwrite` и `rename`, повторные запуски,
поиск первого свободного числового суффикса и сохранение JSON. Отдельно проверены
ошибка во время записи временного файла и отказ публикации при `overwrite`:
прежний файл не повреждается, временный файл удаляется. Проверены совпадение
источника и назначения во всех режимах и появление занятого имени между
проверкой и публикацией для `skip`/`rename`. Проверки проводятся на Windows.
