# Копирование выбранных фотографий

## Назначение и основные понятия

Скрипт выполняет копирование/перемещение выбранных клиентом и/или фотографом фотографий с автоматической группировкой по папкам локаций/сюжетов.
Читает выбор учеников из `photo_selection.json` и учитывает выбор фотографа — файлы с префиксом `PH_` в начале имени, без учёта регистра.

Для работы обязателен `info_faces.json`. Файл `photo_selection.json` необязателен:
если его ещё нет, скрипт копирует/перемещает только выбор фотографа по `PH_`
и сообщает об этом в журнале. Файл выбора автоматически не создаётся.
Если нет ни клиентского выбора, ни файлов выбранных фотографом номеров,
скрипт завершается успешно без переноса файлов.
Существующий, но повреждённый или недоступный `photo_selection.json` остаётся ошибкой.
Скрипт объединяет выбранные номера всех учеников и учитывает файлы `PH_`.
Фото идентифицируются по шестизначному номеру.

## Параметры запуска

| Параметр | Назначение | Значение по умолчанию в PySM |
|---|---|---|
| `--analysis_dir` | Папка с обязательным info_faces.json и необязательным photo_selection.json. Сам параметр обязателен. | `{wf_session_path}/{wf_session_name}/Output/Analysis_{wf_photo_session}` |
| `--source_dir` | Исходная папка с изображениями для поиска и копирования выбранных номеров. Обязателен. | `{wf_session_path}/{wf_session_name}/Output/Analysis_{wf_photo_session}/JPG` |
| `--dest_dir` | Целевая папка для выбранных RAW или готовых фотографий; создаётся автоматически вместе с отсутствующими родительскими папками. Подпапки создаются по локациям. Обязателен. | `{wf_psd_path}/{wf_session_name}/Альбом/Фото/{wf_photo_session}` |
| `--exclude_dirs` | Имена подпапок, исключаемых при поиске и копировании на любой глубине. Необязателен. | `Masks` |
| `--on_conflict` | Действие при совпадении имени: `skip`, `overwrite` или `rename`. Необязателен. | `skip` |
| `--mode` | `copy` — копировать с сохранением оригиналов; `move` — переместить. Необязателен. | `copy` |


## Правила копирования

Источники и назначение сканируются рекурсивно.
Копируются все файлы имеющие в имени номер выбранного кадра, включая XMP и сопоставленные настройки Capture One и т.д.

В служебных именах Capture One вида `photo_271787.cr3.[UUID].cot` полный UUID
в квадратных скобках не участвует в поиске номера. Такой файл относится к кадру
`271787`, даже если UUID содержит цифры другого известного кадра. Имя и содержимое
служебного файла сохраняются. Правило действует и после `rename` (`…[UUID] (1).cot`).
Если в остальной части имени несколько известных номеров, операция блокируется
как неоднозначная.

Файлы `PH_` учитываются в исходной и целевой папках и выбирают весь номер кадра.
Без клиентского выбора их номера должны присутствовать в `info_faces.json`;
неизвестные номера пропускаются с предупреждением. Исключения `exclude_dirs`
применяются и к файлам фотографа. Если `photo_selection.json` появляется или
изменяется во время проверки, скрипт просит повторный запуск; до начала переноса
такая ситуация блокирует копирование.

Название подпапки берётся из `location_name` в `info_faces.json`. Если локация не задана либо выбранный номер отсутствует в анализе, используется `unknown`.
Вложенная структура сохраняется. Если первая подпапка источника уже называется как локация, её имя повторно не добавляется.

Записи анализа вида `photo_270013.jpg` и `photo_270013_1.jpg` считаются вариантами
одного кадра при одинаковой локации. Также допускаются суффиксы ` (1)`, ` (2)`
после номера, разные расширения, регистр и префикс `PH_`. Все найденные файлы
выбранного номера копируются/перемещаются с сохранением имён.
Если различается остальная часть имени либо локация, операция останавливается:
в ошибке указаны обе конфликтующие записи. Отсутствующая папка назначения
создаётся вместе с родительскими папками после успешной проверки входных данных,
до переноса файлов, даже если выбранных файлов нет. Ошибка создания папки
останавливает операцию до переноса файлов.

Создание папки не изменяет правила выбора: если `photo_selection.json` отсутствует
и нет файлов `PH_`, обычные JPG/PSD/RAW не переносятся. Сообщение «Нет исходных файлов
для копирования/перемещения» означает отсутствие файлов, подходящих под выбор,
а не обязательно пустую исходную папку.

Если путь назначения уже занят, применяется `--on_conflict`:

- `skip` (по умолчанию) — пропустить файл, оставив существующий без изменений.
- `overwrite` — заменить существующий файл новой копией.
- `rename` — сохранить новый файл под первым свободным именем с числовым
  суффиксом перед расширением: `photo (1).jpg`, `photo (2).jpg` и так далее.

### Режим перемещения

При `--mode move` оригинал выбранного файла удаляется только при успешном перемещении. Пустые исходные папки не удаляются.

- `skip`: существующий целевой файл и оригинал остаются без изменений.
- `overwrite`: целевой файл заменяется, затем удаляется оригинал.
- `rename`: новый файл получает свободное имя с суффиксом, затем удаляется оригинал.

Если удалить оригинал не удалось либо обнаружено изменение оригинала во время операции, сохраняются обе версии и выводится ошибка.
В отчёте отдельно указано число файлов, скопированных без удаления оригинала; они не считаются успешно перемещёнными.
Остальные файлы продолжают обрабатываться, итоговый код — `1`.


## Последовательности RAW и JPG

Приведённые ниже последовательности описывают работу с клиентским выбором.
Фотограф может запустить `selection_copy` раньше импорта, подготовив файлы `PH_`
и `info_faces.json`. Когда клиенты сделают выбор, выполните импорт и повторите
копирование с нужным режимом `on_conflict`.

Для всех этапов одной фотосессии используйте одинаковый `analysis_dir`.
В импорте и создании плана также должны совпадать `student_list_file`,
`session_name` и `photo_session`.

### RAW

1. Запустите `selection_import` и сохраните выбор.
2. Запустите `selection_copy` с папками:

   ```text
   --source_dir: {wf_session_path}/{wf_session_name}/Capture/{wf_photo_session}
   --dest_dir: {wf_session_path}/{wf_session_name}/Selects/{wf_photo_session}
   ```

3. Обработайте фотографии в Capture One и экспортируйте их в:

   ```text
   {wf_session_path}/{wf_session_name}/Output/Альбом/Фото/{wf_photo_session}
   ```

4. Повторно запустите `selection_copy`:

   ```text
   --source_dir: {wf_session_path}/{wf_session_name}/Output/{wf_session_name}/Альбом/Фото/{wf_photo_session}
   --dest_dir: {wf_psd_path}/{wf_session_name}/Альбом/Фото/{wf_photo_session}
   ```

5. Запустите `selection_assignments` с папками из шага 4 и создайте план вёрстки.

### JPG

1. Запустите `selection_import` и сохраните выбор.
2. Запустите `selection_copy`:

   ```text
   --source_dir: {wf_session_path}/{wf_session_name}/Output/Analysis_{wf_photo_session}/JPG
   --dest_dir: {wf_psd_path}/{wf_session_name}/Альбом/Фото/{wf_photo_session}
   ```

3. Запустите `selection_assignments` с теми же папками и создайте план вёрстки.

Для финального копирования и плана должны совпадать также `exclude_dirs`.
Пример списка класса: `{wf_psd_path}/{wf_session_name}/{wf_session_name}.list`.
Папка анализа: `{wf_session_path}/{wf_session_name}/Output/Analysis_{wf_photo_session}`.

Если нужно изменить выбор, повторно откройте импорт, выполните копирование
и заново создайте план. В уже открытом окне нажмите «Обновить список».
Генератор альбомов запускается после успешного завершения этих этапов.
