# История изменений selection_copy

## 2.2026.09.17

- Общая папка комплекта переименована из `Photo_Selection04` в `photo_selection2`; обновлены пути в тестах, руководствах и workflow-наборах.
- Исправлены пакетные импорты и переносимый запуск. Копирование без установленного API PySM сохраняет обычный прогресс в терминале.
- Сохранён итоговый отчёт со ссылками на исходную и целевую папки. Ошибка оформления отчёта выводится как предупреждение и не меняет успешный результат операции.
- Добавлен `--mode`: `copy` (по умолчанию) и `move`. Перемещение сохраняет правила локаций и `on_conflict`, удаляя оригинал только после успешной записи в назначение.
- При пропуске, ошибке записи, изменении оригинала или отказе удаления оригинал сохраняется. Прогресс и итоговый отчёт различают копирование и перемещение; пустые папки не удаляются.
- Добавлен `--on_conflict`: `skip` (по умолчанию), `overwrite`, `rename`. Совпадение имени больше не является ошибкой; сравнение содержимого удалено.
- `overwrite` заменяет файл после успешной записи временной копии; `rename` выбирает первое свободное имя с суффиксом ` (1)`, ` (2)` и далее. Совпадение исходного и целевого физического файла всегда пропускается.
- Удалены параметры `--student_list_file`, `--session_name` и `--photo_session`.
- Подготовка копирования читает только номера из `photo_selection.json` и локации из `info_faces.json`; список учеников, matches-файл и расчёт назначений больше не требуются.
- Сохранены правила поиска `PH_` и рекурсивного копирования. Ошибки записи не прерывают обработку остальных файлов; скрипт возвращает код 1.
- Удалено отдельное окно: копирование начинается сразу при запуске скрипта.
- Прогресс передаётся в главное окно PySM через `pysm_progress_reporter.tqdm`.
- Итоговые счётчики, предупреждения и ошибки выводятся в журнал. Блокирующие ошибки возвращают код 1; успешное завершение — 0.
- Удалены неиспользуемые параметры окна `--title` и `--message`.
- Проверки локаций и форматы данных сохранены.

## 2.2026.09.16

- Создан отдельный скрипт «Копирование выбранных фотографий» на основе базового `photo_selection`.
- Копирование выбранных учениками и фотографом файлов по локациям. Не изменяет JSON выбора и назначений.
- Общие компоненты размещены в `Photo_Selection04/_common`; интерфейс поддерживает темы PySM.
