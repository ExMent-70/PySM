# История изменений selection_assignments

## 2.2026.10.22

- Добавлена автоматическая проверка расположения всех известных файлов в `dest_dir` по текущим локациям `info_faces.json`, включая файлы вне персонального выбора.
- Кнопка «Исправить расположение файлов» перемещает подготовленные файлы внутри `dest_dir`, сохраняя имена, вложенные папки и содержимое. Пустая исходная папка не мешает исправлению.
- Несоответствия блокируют публикацию плана. Занятые пути и несколько источников на одну цель остаются конфликтами без перезаписи; доступные переносы выполняются в фоне с последующим пересчётом.
- Добавлены проверки актуальности показанного списка, анализа, выбора и файлов; защищена публикация прежнего JSON при изменении данных. Ссылки и junction не обходятся.
- Убрано сравнение имён вариантов кадра: для объединения записей анализа используются только шестизначный номер и локация. Пометки `База`, `Донор`, `бБаза` и другие части имени не вызывают конфликта.
- Распознанные ученики из вариантов объединяются, номер в назначениях не дублируется. Конфликт локаций одного номера остаётся ошибкой.

## 2.2026.10.17

- Общий поиск файлов исключает полный UUID Capture One из разбора номера фотографии. Служебные файлы больше не вызывают ложную неоднозначность или связь с другим кадром при построении плана.

## 2.2026.09.27

- Общее ядро объединяет записи вариантов одного кадра с числовыми суффиксами и одинаковой локацией. Распознанные ученики сохраняются из всех вариантов, номер в назначениях не дублируется.
- Конфликтующие имена кадров или локации по-прежнему блокируют создание плана; диагностика содержит обе записи.

## 2.2026.09.17

- Общая папка комплекта переименована из `Photo_Selection04` в `photo_selection2`; обновлены пути в тестах, руководствах и workflow-наборах.
- Исправлены пакетные импорты и запуск из другой рабочей папки; комплект переносится вместе с `_common` без зависимости от дерева `scripts/Workflow2/Tools`.
- Сохранён новый заголовок журнала, исправлен закрывающий HTML-тег. Заголовок выводится при запуске окна, а не при импорте модуля.
- Уточнены общие параметры этапов: список учеников и параметры сессии нужны импорту и плану, но не копированию.
- В руководстве уточнено: скрипт копирования работает без отдельного окна; интерфейс этого скрипта не изменён.

## 2.2026.09.16

- Создан отдельный скрипт «План вёрстки» на основе базового `photo_selection`.
- Просмотр персональных назначений и создание photo_assignments.json после копирования готовых изображений.
- Общие компоненты размещены в `Photo_Selection04/_common`; интерфейс поддерживает темы PySM.
