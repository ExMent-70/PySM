# План вёрстки

## Назначение и основные понятия

Скрипт показывает персональные назначения фотографий и создаёт
`{analysis_dir}/photo_assignments.json` для генератора альбомов.
Выбор читается из `photo_selection.json`, технические сведения — из
`info_faces.json`, ФИО и идентификаторы — из общего `*.list`.
Существующий `matches_portrait_to_group.json` дополняет распознанные связи.

План хранит `student_id → локация → шестизначные номера` (schema_version=2).
Локации берутся из `info_faces.json`, пути и ФИО в JSON не копируются.
Готовые JPG/JPEG/PSD находятся непосредственно в `dest_dir`. Скрипт проверяет
файлы и актуальность данных, но не перемещает их и не редактирует выбор.

## Параметры запуска

| Параметр | Назначение | Значение по умолчанию в PySM |
|---|---|---|
| `--student_list_file` | Список класса/группу содержащий имена и фамилий *.list. Обязателен. | `{wf_psd_path}/{wf_session_name}/{wf_session_name}.list` |
| `--analysis_dir` | Папка с photo_selection.json, info_faces.json и итоговым photo_assignments.json. Обязателен. | `{wf_session_path}/{wf_session_name}/Output/Analysis_{wf_photo_session}` |
| `--source_dir` | Исходная папка для поиска номеров и выбора фотографа. Может быть пустой после перемещения файлов. Обязателен. | `{wf_session_path}/{wf_session_name}/Output/Analysis_{wf_photo_session}/JPG` |
| `--dest_dir` | Целевая папка, куда копируются выбранные файлы и где генератор альбома ожидает готовые JPG/JPEG/PSD. Обязателен. | `{wf_psd_path}/{wf_session_name}/Альбом/Фото/{wf_photo_session}` |
| `--session_name` | Уникальный идентификатор класса/группы Обязателен. | `{wf_session_name}` |
| `--photo_session` | Название текущей фотосессии. Обязателен. | `{wf_photo_session}` |
| `--exclude_dirs` | Имена подпапок, исключаемых при поиске исходных файлов.  | `Masks` |
| `--title` | Заголовок главного окна.  | `План вёрстки` |
| `--message` | HTML-инструкция, выводимая первым блоком правой информационной панели.  | — |

При прямом запуске обязательные параметры передаются явно. В PySM шаблоны
подставляются из контекста. `--message` отображается в окне, но не включается
в итоговый лог. Геометрия окон импорта и плана сохраняется отдельно; копирование выполняется без окна.

## Быстрый старт

При переносе сохраняйте папку `photo_selection2` целиком, включая `_common`.
Запуск не зависит от текущей рабочей папки; интерфейсу необходим API PySM.

1. Выполните импорт и финальное копирование фотографий.
2. Откройте этот скрипт с теми же исходной и целевой папками, что при финальном копировании.
3. Проверьте обе вкладки и диагностический отчёт. Для финального переноса используйте `selection_copy --layout flat`.
4. Нажмите «Создать план вёрстки».
5. После успешного сохранения и проверки готовности переходите к генератору альбомов.

## Интерфейс

«Общий список выбранных фотографий» показывает кадры, источник выбора,
распознанных и назначенных учеников, физические файлы.
«Персональные списки выбранных фотографий» представляет данные обычной таблицей:
одна строка — один ученик, первый столбец — «ФИО ученика», остальные — названия
локаций. В ячейках находятся шестизначные номера фотографий, каждый с новой строки.
При отсутствии выбора показывается прочерк с лёгкой подсветкой.

Перед номером показаны существующие иконки PySM: выбор клиента и/или фотографа,
затем наличие файла в исходной и/или целевой папке. Предупреждение означает,
что физические файлы для номера не найдены. Обозначения приведены под таблицей;
подсказка номера содержит источники выбора и полные пути ко всем его файлам.

Щелчок по конкретному номеру показывает справа его сведения и асинхронный
JPG-предпросмотр. Стрелки вверх/вниз позволяют выбирать номера внутри ячейки,
затем переходят к соседней строке. Щелчок по ФИО показывает сведения об ученике,
по пустой ячейке — сведения о соответствующей локации.
Столбцы сортируются по заголовку. Ширина столбцов локаций автоматически
подбирается по заголовкам и содержимому всех строк, включая иконки.
Столбец «ФИО ученика» занимает оставшуюся ширину таблицы. Высота строки
подбирается под все номера. При обновлении сохраняются доступное выделение
и сортировка, размеры пересчитываются по актуальным данным.

Слева находятся сведения о списке и фотосессии, вкладки с таблицами и легенда
иконок. Справа — справочный текст и отчёт, предпросмотр и две кнопки под ним:
«Обновить список» с иконкой обновления и «Создать план вёрстки» с иконкой сохранения.
Ширину частей окна и высоту областей отчёта и предпросмотра можно менять разделителями.

Кнопки «Обновить список» и «Создать план вёрстки» расположены рядом.
В предупреждении о неизвестном источнике выбора показаны ссылки на каждый
найденный файл в целевой папке и на его расположение в проводнике.
Контекстное меню персональной таблицы содержит открытие файла/папки, сведения
об ученике или локации и экспорт HTML/CSV. Подменю «Все файлы кадра» сохраняет
доступ к каждому физическому варианту выбранного номера, включая исходники
и служебные файлы. Меню и подменю используют активную тему PySM.
Сворачивание и разворачивание для плоской таблицы не нужны.
В CSV фамилия, имя и отчество записываются в отдельные столбцы. Затем для каждой
локации используется один столбец с префиксом `@` в заголовке; после локаций выводятся все поля `info`,
встречающиеся в записях учеников файла `.list`. Если у ученика нет значения,
ячейка остаётся пустой. Несколько файлов в ячейке локации
перечисляются через запятую с пробелом. Разделитель столбцов — точка с запятой,
кодировка — UTF-8 с BOM. Переносы строк в дополнительных данных сохраняются
внутри CSV-поля в кавычках.
Состав экспортируемых HTML/CSV, назначения и проверки готовности сохранены.
Изменение и очистка выбора отсутствуют.
Для изменения выбора повторно запустите импорт, затем копирование и создание плана.

## Проверка файлов и актуальности

Проверяются готовые файлы непосредственно в `dest_dir`. Подпапки не определяют
локацию и не используются как резервный источник для плоского процесса.
Снимок файлов и отпечаток анализа перепроверяются перед атомарной записью JSON.
Изменённые во время операции данные требуют обновления и повторного запуска.

После смены локации обновите список и пересоздайте план. Физический путь и
содержимое фотографии сохраняются. Старые файлы в подпапках автоматически
не перемещаются и не удаляются.

## Правила назначений

Номер из выбора ученика назначается этому ученику. Ошибка распознавания его лица
не отменяет выбор. Фотография с `PH_` назначается распознанным на ней ученикам.
Если кадр выбран обоими способами, наборы учеников объединяются.
Обычный файл без `PH_` и без выбора ученика не считается выбором фотографа.

Записи `info_faces.json` объединяются только по шестизначному номеру и локации
(регистр локации не учитывается). Остальные части имени, включая любые префиксы,
пометки `База`, `Донор`, `бБаза` и расширения, не влияют на объединение.
Распознанные ученики объединяются, номер в плане не дублируется.
Разные локации для одного номера остаются блокирующей ошибкой с указанием
конфликтующих записей. В имени должен определяться один шестизначный номер.

Префикс распознаётся без учёта регистра в исходной и целевой папках.
При сканировании служебных файлов Capture One (`photo_271787.cr3.[UUID].cot`)
цифры полного UUID не считаются номерами фотографий. Служебный файл связывается
с исходным кадром по имени перед UUID; сам по себе он не заменяет готовое изображение.
Сначала сохраняется порядок ученического выбора, затем добавляются остальные
назначения без повторов. Файл фотографа без найденных пользователей не создаёт назначений; выводится предупреждение.

Пример результата:

```json
{"schema_version":2,"list_id":"A7K3","assignments":{"A7K3-S001":{"portrait":["901256"],"group_photo_01":["901270"]}}}
```

## Готовность и ошибки

Для каждого назначенного номера в целевой папке должен находиться JPG, JPEG или PSD
непосредственно в `dest_dir`. Локация определяется только по анализу и сохраняется в JSON.
Одного RAW либо XMP недостаточно. При блокирующей ошибке план не публикуется,
ранее существовавший JSON остаётся на месте. Запись выполняется атомарно.

Готовность определяется текущим содержимым файла, совпадением с рассчитанными
назначениями и наличием целевых изображений. Сам факт создания плана в прошлом
не означает актуальность. Повреждённый или устаревший файл не считается готовым.

Отчёт отдельно показывает количество уникальных назначенных номеров и количество
тех из них, для которых найден готовый файл. Также показано физическое число
JPG/JPEG/PSD непосредственно в целевой папке и число дополнительных файлов,
не относящихся к назначениям; несколько форматов одного номера считаются
отдельными файлами. Дополнительные файлы перечисляются со ссылками для проверки
и сами по себе не препятствуют готовности. RAW, XMP и вложенные папки в эти
счётчики не входят. Если папку не удалось проверить, счётчики недоступны.

Перед основной операцией источники перечитываются. Если выбор или анализ меняется во время
расчёта, устаревший результат отбрасывается и выполняется обновление.
Изменённый выбор требует повторного копирования и создания плана. Устаревшие
фотографии автоматически не удаляются, оставшиеся `PH_` продолжают учитываться.
Проверка готовности не заменяет проверку результата вёрстки в InDesign.

## Последовательности RAW и JPG

Для всех этапов одной фотосессии используйте одинаковый `analysis_dir`.
В импорте и создании плана также должны совпадать `student_list_file`,
`session_name` и `photo_session`; копированию эти три параметра не нужны.

### RAW

1. Запустите `selection_import` и сохраните выбор.
2. Запустите `selection_copy` с папками:

   ```text
   --source_dir: {wf_session_path}/{wf_session_name}/Capture/{wf_photo_session}
   --dest_dir: {wf_session_path}/{wf_session_name}/Selects/{wf_photo_session}
   ```

3. Обработайте фотографии в Capture One и экспортируйте их в:

   ```text
   {wf_session_path}/{wf_session_name}/Output/Альбом/Фото/{wf_photo_session}
   ```

4. Повторно запустите `selection_copy`:

   ```text
   --source_dir: {wf_session_path}/{wf_session_name}/Output/Альбом/Фото/{wf_photo_session}
   --dest_dir: {wf_psd_path}/{wf_session_name}/Альбом/Фото/{wf_photo_session}
   ```

5. Запустите `selection_assignments` с папками из шага 4 и создайте план вёрстки.

### JPG

1. Запустите `selection_import` и сохраните выбор.
2. Запустите `selection_copy`:

   ```text
   --source_dir: {wf_session_path}/{wf_session_name}/Output/Analysis_{wf_photo_session}/JPG
   --dest_dir: {wf_psd_path}/{wf_session_name}/Альбом/Фото/{wf_photo_session}
   ```

3. Запустите `selection_assignments` с теми же папками и создайте план вёрстки.

Для финального копирования и плана должны совпадать также `exclude_dirs`.
Пример списка класса: `{wf_psd_path}/{wf_session_name}/{wf_session_name}.list`.
Папка анализа: `{wf_session_path}/{wf_session_name}/Output/Analysis_{wf_photo_session}`.

Если нужно изменить выбор, повторно откройте импорт, выполните копирование
и заново создайте план. В уже открытом окне нажмите «Обновить список».
Генератор альбомов запускается после успешного завершения этих этапов.
