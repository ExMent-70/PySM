# Персональный выбор фотографий

## Назначение

Скрипт собирает номера фотографий, выбранных каждым учеником, применяет этот выбор к результатам AI-анализа фотографий, копирует найденные файлы в папки локаций и создаёт список назначений для генератора альбомов. Общий `*.list` остаётся единственным источником `student_id`, фамилии и имени.

Основные результаты:

```text
photo_selection.json
photo_assignments.json
файлы в целевых папках локаций
```

`photo_selection.json` — рабочий файл выбора учеников. Его можно импортировать и редактировать.

`photo_assignments.json` — производный файл для верстки. Он создаётся из текущего выбора, `*.list`, AI-анализа и файлов в исходной/целевой папках.

## Формат `photo_selection.json`

```json
{
  "schema_version": 1,
  "list_id": "A7K3",
  "session_name": "9А",
  "photo_session": "Основная съемка",
  "students": {
    "A7K3-S001": {
      "selected_numbers": ["901087", "901105"],
      "responded": true,
      "source": "csv"
    }
  }
}
```

`selected_numbers` — упорядоченный список без классификации «основной/дополнительный». Тип кадра и локация будут определяться позднее по результатам анализа фотографий. `responded: true` с пустым массивом означает явный пустой ответ; отсутствие записи означает, что ответ ещё не получен.

## Место в рабочем процессе

```text
CSV / AI JSON / ручной ввод
        ↓
photo_selection.json
        ↓
файлы по локациям + photo_assignments.json
        ↓
генератор альбома
```

`photo_selection.json` сохраняется отдельно для каждой фотосессии в её папке анализа.
Общий `*.list` может использоваться несколькими фотосессиями одного класса.

## Вкладки окна

Окно содержит три вкладки.

### Импорт

Используется для импорта CSV, AI JSON и ручного редактирования выбора учеников. После изменения выбора скрипт сохраняет `photo_selection.json`, помечает `photo_assignments.json` неактуальным и пересчитывает вкладки назначений через фоновую операцию `refresh`, если в папке анализа уже есть `info_faces.json`.

### По фотографиям

Показывает выбранные и назначенные кадры, источник выбора, распознанных и назначенных учеников, физические файлы и предпросмотр JPG из `{analysis_dir}/JPG`.

Контекстное меню строк позволяет открыть файл или открыть папку с выделением файла.

### По ученикам и локациям

Показывает выбор каждого ученика по локациям. Если для локации выбор отсутствует, строка выделяется предупреждением.

Контекстное меню позволяет:

- свернуть или развернуть дерево;
- сохранить матрицу выбора как HTML;
- сохранить матрицу выбора как CSV;
- изменить выбранные номера ученика;
- очистить выбор ученика;
- открыть файл или папку с файлом.

## Панели кнопок

У окна две панели кнопок.

На вкладке `Импорт` доступны:

- `Импорт`;
- `Изменить выбранные номера`;
- `Очистить`;
- `Сохранить`.

На вкладках назначений доступны:

- `Обновить список`;
- `Копировать выбранные файлы`;
- `Создать список`;
- `Копировать и создать список`.

## Варианты импорта

Все варианты импорта находятся в выпадающем меню кнопки «Импорт».

Справа от таблицы расположен отчёт о последней операции импорта. Области разделены сплиттером, поэтому ширину отчёта можно менять. В отчёте отдельно показаны корректные и неразрешённые записи, их номера, причины и кандидаты. Текст и номера можно выделять и копировать. Цвета успешных результатов и ошибок берутся из активной темы PySM.

### Общая таблица CSV

Поддерживаются UTF-8, UTF-16 и Windows-1251, а также разделители `;`, `,` и табуляция. После открытия файла нужно указать:

- один столбец с `student_id` или ФИО;
- один или несколько столбцов с номерами фотографий.

ФИО сопоставляется только однозначно. Неизвестные и неоднозначные строки не применяются автоматически.

### Персональные CSV

Можно выбрать сразу несколько файлов. Имя каждого файла должно совпадать с фамилией и именем ученика, например:

```text
Бугаева Виктория.csv
```

Из содержимого извлекаются числовые номера допустимой длины.

### AI-промпт и JSON

Скрипт не обращается к AI-сервису напрямую. Вставьте неструктурированный текст, сформируйте промпт и передайте его выбранной нейросети. Полученный JSON вставьте на второй вкладке либо откройте как `.json`-файл, затем выполните проверку.

Промпт включает справочник учеников из `*.list` и требует:

- вернуть проверенные `student_id`;
- не считать нумерацию строк номерами фотографий;
- сохранить ведущие нули;
- не делить номера на основные и дополнительные;
- сохранить явный пустой ответ;
- поместить неоднозначные записи в `unresolved`.

Для каждой записи `unresolved` AI также должен вернуть `selected_numbers`, чтобы номера не терялись и их можно было скопировать из отчёта.

## Применение и сохранение

Перед применением показываются добавляемые и удаляемые номера. Доступны два режима:

- «Да» — заменить выбор только затронутых учеников;
- «Нет» — добавить новые уникальные номера к существующим;
- «Отмена» — ничего не менять.

Таблица защищена от непосредственного ввода произвольного текста. Столбец «Ответ» представлен тематизируемым флажком. Для исправления номеров выберите ученика и нажмите «Изменить выбранные номера» либо дважды щёлкните по любой ячейке его строки. Диалог принимает только числа, разделённые пробелами, запятыми или точками с запятой, и не применяет данные при ошибке. Удаление существующих номеров требует отдельного подтверждения.

В столбце **Фамилия Имя** перед ФИО показывается тематическая иконка
`PHOTO_PORTRAIT`. В столбце **Источник** текст заменён иконкой `FILE_CSV` для CSV или
`FILE_CODE` для AI JSON, а ручной ввод обозначается `FILE_TXT`; точный источник
доступен в подсказке. Значения столбцов `student_id`, **Количество**, **Ответ** и
**Источник** выровнены по центру. Строки таблицы используют чередующиеся цвета
активной темы («зебру»).

Диалог ручного редактирования переносит длинный список номеров по ширине поля ввода.
Горизонтальная полоса прокрутки не используется: все номера можно просмотреть,
перемещаясь по тексту вертикально.

При переходе между строками учеников правая HTML-панель показывает подробную карточку
текущего ученика. В неё включается исходная запись целиком из `*.list`: ФИО,
`student_id`, роль, порядок съёмки, услуга и стоимость, дополнительные услуги, цвета,
цитаты и другие поля `info`, а также любые дополнительные поля будущих версий списка.
Отдельный тематический блок показывает номера выбранных фотографий, их количество,
признак полученного ответа и источник данных. Отчёт формируется через
`pysm_report_api.py` и содержит ссылку на исходный файл списка. После импорта панель
временно показывает результат последней операции; при выборе другой строки снова
открывается карточка ученика.

Внутренняя навигация HTML-панели отключена. Ссылки передаются через
`QDesktopServices` внешнему приложению Windows и не заменяют содержимое отчёта внутри
окна скрипта.

Геометрия и состояние главного окна, а также положение разделителя между таблицей и
HTML-панелью сохраняются через `WindowStateManager` в переменной контекста
`win_state.photo_selection`. Состояние восстанавливается при следующем запуске. Если
закрытие отменено из диалога несохранённых изменений, состояние окна не записывается.

Кнопка «Очистить» полностью удаляет запись о выборе для выделенного ученика или нескольких выделенных учеников: номера, признак ответа и источник. Операция требует подтверждения и считается несохранённым изменением.

Кнопка «Сохранить» атомарно записывает JSON; файл другого списка, сессии или фотосессии отклоняется. В объединённом режиме изменения выбора также сохраняются автоматически перед пересчётом назначений, чтобы вкладки `По фотографиям` и `По ученикам и локациям` всегда работали с актуальным `photo_selection.json`. При закрытии окна с несохранёнными изменениями предлагается сохранить их, закрыть без сохранения или отменить закрытие. В управляемом запуске к окну применяется активная тема PySM.

## Готовность к верстке

Скрипт показывает статус `ГОТОВО К ВЕРСТКЕ`, только если:

- нет блокирующих ошибок;
- `photo_assignments.json` существует;
- содержимое `photo_assignments.json` совпадает с текущим расчётом назначений;
- для всех назначенных номеров есть `.jpg`, `.jpeg` или `.psd` в целевой папке;
- количество отобранных фотографий совпадает с количеством готовых фотографий в целевой папке.

Если выбор изменён, `photo_assignments.json` считается неактуальным до выполнения команды `Создать список` или `Копировать и создать список`.

## Исключаемые папки

Из поиска, копирования, таблиц и отчётов исключаются все папки, указанные в параметре `exclude_dirs`.

`Masks` — только значение по умолчанию и частный пример. Это не специальное правило скрипта.

`CaptureOne` не исключается по умолчанию, потому что для RAW-процесса в ней находятся настройки Capture One.

## Параметры

- `student_list_file` — общий `*.list` класса;
- `session_name` — имя сессии;
- `photo_session` — имя фотосессии;
- `analysis_dir` — папка анализа, в которой создаются `photo_selection.json` и `photo_assignments.json`;
- `source_dir` — исходная папка с изображениями для поиска и копирования выбранных номеров;
- `dest_dir` — целевая папка с файлами для верстки;
- `exclude_dirs` — список имён подпапок, исключаемых из поиска, копирования и отчётов;
- `title` — заголовок окна;
- `message` — HTML-инструкция в начале правой панели окна.

Номер фотографии должен содержать ровно шесть цифр. Длина номера не является
настраиваемым параметром, короткие значения автоматически не дополняются.
