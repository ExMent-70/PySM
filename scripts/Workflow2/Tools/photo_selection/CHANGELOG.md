# История изменений photo_selection

## 2.2026.07.11

### Изменено

- AI JSON-импорт переведён на общие пакеты `pysm_lib.ai` и
  `pysm_lib.gui.ai`. Prompt и разбор ответа теперь используют единый Qt-диалог
  и устойчиво принимают JSON с поясняющим текстом или Markdown-обёрткой.
- Проверка `student_id`, формата номеров и применение выбора остаются в
  предметном коде photo_selection.

## 2.2026.07.01

### Добавлено

- GUI персонального выбора фотографий с импортом CSV, AI JSON и ручными назначениями.
- Вкладки по фотографиям и по ученикам/локациям, предпросмотр, HTML/CSV экспорт и проверки готовности.
- Общий с `photo_selection_apply` слой доменной логики и безопасного копирования в `FaceAnalysis/_common`.
- Асинхронный image pipeline, атомарная публикация результатов и набор автоматических тестов.
