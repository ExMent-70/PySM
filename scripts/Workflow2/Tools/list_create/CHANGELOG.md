# История изменений list_create

## 2.2026.10.29

### Добавлено

- Значение переменной контекста `wf_photo_session` отображается в заголовке окна.

### Исправлено

- Сохранение и закрытие окна завершают редактирование активной ячейки;
  некорректный ввод блокирует операцию до исправления.
- Удаление строк отмечает документ изменённым; повторный ввод прежнего
  значения не вызывает лишний запрос сохранения.
- Загрузка списка предлагает сохранить текущие правки, отказаться от них
  или отменить загрузку.
- Сохранение использует точный путь открытого файла или «Сохранить как»;
  неудачная запись не меняет папку и название документа.
- Ошибки сохранения контекста и автоэкспортов сохраняют признак изменений
  для повторной попытки. Пустой список обновляет CSV и порядок ID в контексте.
- Закрытие окна не записывает контекст до решения пользователя о сохранении.

## 2.2026.10.21

### Изменено

- При импорте фамилий в непустой список теперь можно добавить распознанные
  записи к существующим, заменить список либо отменить операцию.
- Кнопки диалога сохранения изменений при выходе переведены на русский язык.
- HTML-шаблон договора обновлён до версии `2.2` для автоматического перехода
  с сезона `25/26` на `26/27`.

## 2.2026.09.10

### Изменено

- Если столбец `shoot_order` полностью пустой, в
  `wf_student_ids_order.{wf_photo_session}_ids_order` записываются все
  `student_id` в текущем порядке строк списка класса.
- Для частично заполненного `shoot_order` сохранена прежняя механика: в массив
  входят только ученики с указанным порядком съёмки, отсортированные по нему.

## 2.2026.08.20

### Изменено

- Порядок `student_id` текущей фотосессии теперь сохраняется в структурированную
  переменную `wf_student_ids_order.{wf_photo_session}_ids_order`.
- Удалены параметр `wf_output_txt_file`, экспорт `*_children.txt` и формат
  автосохранения `txt`. Имя вложенного поля определяется автоматически.
- Команда ручного сохранения порядка съёмки теперь обновляет контекст PySM.

## 2.2026.07.13

### Изменено

- AI-prompt теперь содержит полную заранее настроенную схему дополнительных
  полей для каждого ученика. Ответ AI применяет все разрешённые поля и
  игнорирует неизвестные ключи без создания новых колонок.
- Пустые значения из ответа AI больше не очищают уже заполненные поля.
- Prompt явно различает имена ключей JSON и свободный исходный текст: AI может
  распознавать значения по смыслу и распространённым синонимам.

## 2.2026.07.11

### Изменено

- Верхняя строка интерфейса заменена кнопками с выпадающими командами. Название
  класса отображается в заголовке окна, а панель импорта фамилий скрывается
  переключателем `Импорт`.
- Команда открытия папки текущего класса перенесена в меню `Загрузить`; кнопки
  и их пункты меню получили тематические иконки PySM.
- Python-модули перенесены из корня скрипта в `_lib/`, а шаблоны и JSON-настройки — в `_lib/resources/`.
- Диалог AI-обогащения переведён на общие пакеты `pysm_lib.ai` и
  `pysm_lib.gui.ai`.
- Prompt формируется из шаблона и справочника `student_id`, а JSON-ответ
  проверяется до изменения `info` учеников. Ответ с Markdown-обёрткой также
  поддерживается.
