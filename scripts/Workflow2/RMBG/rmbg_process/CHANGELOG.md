# История изменений

## 2.2026.08.20

- Удалён выполнявшийся при импорте HTML-баннер, который загрязнял `--help`, тесты и служебный вывод; настройки контекста теперь читаются один раз за запуск.
- Удалён несогласованный CLI-параметр `--model_dir`: Process получает единый путь к моделям из `model.model_dir` JSON-профиля, созданного Configurator.
- Старые профили schema v1 без нового поля продолжают загружаться и получают вычисляемый путь `_BIN/models/RMBG` по умолчанию.
- Относительный `model.model_dir` явно разрешается от корня текущей установки PySM, поэтому профиль и шаблоны можно переносить между дисками и каталогами.

## 2.2026.08.16

- Полный JSON manifest больше не печатается в консоль: основные настройки и итоговые счётчики оформлены HTML-блоками с жирными названиями полей и без служебных разделителей. После обработки таблица ссылок выводится перед статистикой и содержит отдельную папку для каждого включённого результата (`Cutout`, `Masks`, `Composite`), а также исходники и `manifest.json`.
- Устаревшие поля `batch_size`, `max_loaded_models` и `allow_cpu_fallback` сохранены в schema v1 для совместимости, но нормализуются в фактический контракт: batch 1, одна основная модель, без неработающего CPU fallback.
- Добавлено сохранение cutout и composite в JPEG с настраиваемым качеством; прозрачный cutout предварительно накладывается на выбранный цвет, а маска сохраняется в 16-битном PNG.
- Устранены предупреждения Diffusers об устаревшем аргументе `scale` при SDMatte inference; адаптер удаляет уже неиспользуемый аргумент без изменения проверенных upstream-файлов модели.
- Устранены предупреждения `timm` об импортах через устаревшие `timm.models.layers` и `timm.models.registry` при загрузке RMBG-2.0 и lite-моделей; pinned source-файлы моделей остаются неизменными.
- Добавлена production-поддержка `BiRefNet_512x512`, `BiRefNet-HR`, `BiRefNet-matting`, `BiRefNet-HR-matting`, `BiRefNet_lite`, `BiRefNet_lite-2K`, `BiRefNet_dynamic` и `BiRefNet_lite-matting`.
- Model descriptor теперь задаёт `birefnet.py` или `birefnet_lite.py`; оба source-файла скачиваются по pinned revision и проверяются по SHA-256 без переименования.
- Для каждой модели зафиксированы собственные рекомендуемое, минимальное и максимальное разрешения.
- Восемь новых checkpoint-моделей прошли по три CUDA/FP16 inference, проверку manifest и визуальный просмотр масок; все десять BiRefNet-моделей дополнительно прошли inference на минимальной и максимальной границе заявленного диапазона.

- Создан первый обработчик RMBG с разделением context-настроек и runtime-путей.
- Добавлены строгая проверка схемы, поиск изображений и effective pipeline plan.
- Добавлен безопасный `dry_run` без загрузки моделей и записи результатов.
- Непроверенные inference-адаптеры блокируются понятным кодом завершения.
- Добавлен локальный BiRefNet inference-адаптер и smoke-проверка без сохранения результата.
- Добавлена production-обработка `BiRefNet-portrait` с проверкой SHA-256 локальных файлов.
- Добавлена единая постобработка маски без повторного применения параметров.
- Нереализованные режимы `fast` и `SDMatte` теперь блокируются явно.
- Добавлено атомарное сохранение cutout, 16-bit mask, composite и `Reports/manifest.json`.
- Добавлены безопасное возобновление, защита от неполных наборов и запрет output внутри input.
- Выполнена CUDA/FP16 QA-проверка на трёх изображениях с волосами, одеждой и несколькими фигурами.
- Добавлен штатный progress bar PySM: загрузка модели, текущий файл и счётчики обработанных, пропущенных и ошибочных изображений.
- Добавлено автоматическое скачивание отсутствующих файлов проверенной модели с Hugging Face.
- Download manifests фиксируют repository revision, размер и SHA-256 каждого файла всех production-моделей.
- Загрузка выполняется во временный файл с отдельным progress bar и атомарной публикацией без перезаписи существующих данных.
- Адаптер поддерживает абсолютный и относительный импорт `BiRefNet_config`, поэтому скачанный upstream-код не переписывается на диске.
- Устранена регрессия пакетной производительности: GPU inference перекрывается с CPU-постобработкой и сохранением через `io_workers`.
- Добавлен ограниченный prefetch исходников; одна модель по-прежнему вызывается последовательно и безопасно.
- `Reports/manifest.json` теперь записывает промежуточный checkpoint не чаще одного раза в две секунды вместо полной перезаписи после каждого изображения.
- Для PNG добавлен настраиваемый lossless `compress_level`; измеренный сбалансированный default равен 3.
- Удалена повторная SHA-256-проверка готовой модели в одном запуске.
- QA-маски после оптимизации побитно совпали с исходным 16-битным эталоном.
- В production подключены `RMBG-2.0`, `Lucida` и все заявленные варианты BiRefNet; модели автоматически скачиваются и проверяются по SHA-256.
- Для RMBG-2.0 добавлен безопасный FP16-режим через CUDA autocast при хранении несовместимых внутренних тензоров в FP32.
- Все новые адаптеры прошли реальный CUDA/FP16-прогон трёх изображений и визуальную проверку границ.
- Модель теперь всегда явно выгружается после пакетного запуска; устаревшее значение `unload_after_run=false` безопасно нормализуется.
- В manifest добавлена фактическая политика `model_unload_policy=always_after_run`.
- Composite теперь использует один конкретный фон, выбранный в Configurator по относительному пути внутри `background_dir`.
- Удалено автоматическое сопоставление нескольких фонов с исходниками по имени и структуре папок.
- Реализованы `cover`, `contain` и `stretch` с Lanczos; для `cover` доступны центр, верх, низ, лево и право.
- Реализован быстрый CPU-refinement маски; режим `auto` теперь использует его как сбалансированное значение по умолчанию.
- Подключён CUDA-only SDMatte HQ refinement по visual prompt от основной RMBG-маски, включая стандартный и Plus checkpoints.
- Добавлено автоматическое скачивание SDMatte с progress bar, проверкой размера/SHA-256 и изолированным импортом runtime из зафиксированного upstream commit.
- SDMatte прошёл реальный QA-прогон трёх изображений при 1024 совместно с BiRefNet-portrait: 3 обработано, 0 ошибок, визуальная проверка границ пройдена, пик CUDA-памяти 8,74 ГиБ.
- В `manifest.json` добавлены настроенный и эффективный refinement, параметры SDMatte и список скачанных файлов refiner.
- Удалён неработающий CLI-параметр `--input_mask_dir`; SDMatte получает маску основной модели напрямую из памяти. Параметр внешних масок будет добавлен вместе с самостоятельным режимом mask refinement.
