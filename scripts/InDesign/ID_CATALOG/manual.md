# Скрипт "Каталогизатор шаблонов InDesign" (v2025.10.11)

## 1. Назначение

Скрипт представляет собой интерактивный каталогизатор-селектор для шаблонов InDesign (файлов `.idml`). Он позволяет создать централизованную базу шаблонов, визуально просматривать их, организовывать по категориям и выбирать нужный шаблон для дальнейшего использования в сценариях PySM.

Основная задача — предоставить пользователю удобный графический интерфейс для управления большим количеством шаблонов и передать его выбор (данные о выбранном шаблоне) в глобальный контекст PySM.

## 2. Ключевые возможности

*   **Графический интерфейс:** Полноценное десктоп-приложение для управления каталогом.
*   **Управление категориями:** Создание, переименование и безопасное удаление категорий через контекстное меню.
*   **Управление шаблонами:** Добавление, копирование, редактирование и удаление записей о шаблонах.
*   **Интерактивный предпросмотр:** Встроенный просмотрщик изображений-превью с поддержкой:
    *   Масштабирования (зум) с помощью колеса мыши.
    *   Панорамирования (перетаскивание) с помощью левой кнопки мыши.
    *   Быстрого переключения между режимами "Вписать в окно" и "100% масштаб" по двойному клику.
*   **Портабельность:** Скрипт спроектирован для работы с относительными путями. Он автоматически вычисляет и сохраняет путь к файлу шаблона относительно расположения файла каталога, что позволяет легко переносить всю папку проекта.
*   **Интеграция с PySM:**
    *   Автоматически применяет глобальную тему оформления `PySM`.
    *   При запуске считывает из контекста `PySM` ранее выбранный шаблон и подсвечивает его.
    *   При закрытии, если пользователь изменил свой выбор, сохраняет данные нового шаблона обратно в контекст.
    *   Позволяет динамически задавать заголовок окна через параметры.

## 3. Принцип работы

Скрипт работает с файлом каталога `catalog.json`, путь к которому определяется параметром `--idsgn_catalog`.

Для обеспечения портабельности рекомендуется хранить все связанные файлы (шаблоны `.idml` и их превью `.jpg`/`.png`) в подпапках относительно местоположения `catalog.json`. Путь к превью вычисляется автоматически: он должен иметь то же имя, что и файл шаблона, но с расширением `.jpg` или `.png`, и находиться в той же папке.

## 4. Параметры

-   **`--idsgn_catalog`**:
    *   **Описание:** Путь к главному файлу каталога `catalog.json`.
    *   **Поведение:** Если файл существует, он будет загружен. Если нет — он будет создан при первом сохранении.
    *   **По умолчанию:** `{wf_psd_path}/{wf_idsgn_catalog}/catalog.json`

-   **`--idsgn_template_var`**:
    *   **Описание:** Имя переменной в контексте PySM, которая используется для обмена данными о выбранном шаблоне.
    *   **Поведение:** При запуске скрипт читает значение из этой переменной для установки начального выбора. При выходе — записывает в нее новое значение, если выбор был изменен.
    *   **По умолчанию:** `var_album_cover`

-   **`--idsgn_msg`**:
    *   **Описание:** Сообщение, которое будет отображаться в заголовке окна, предоставляя дополнительный контекст для пользователя (например, "Выберите обложку").
    *   **Поведение:** Устанавливает текст заголовка главного окна.
    *   **По умолчанию:** `Каталогизатор шаблонов InDesign`
