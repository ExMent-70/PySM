# Руководство. Скрипт "Генератор разворотов InDesign" (v2025.12.10)

## 1. Назначение

Этот скрипт автоматизирует процесс создания фотоальбомов в программе InDesign. В зависимости от выбранного режима, он может либо создавать многостраничные персональные альбомы, либо заполнять шаблон-виньетку на одном развороте.

## 2. Ключевые возможности

### 2.1. Режим `sheet`
Стандартный режим, работающий по принципу **"один человек — один разворот"**.

### 2.2. Режим `photo`
Работает по принципу **"одна фотография — один разворот"**. Создает для каждой персоны столько разворотов, сколько найдено подходящих фотографий.
**Ограничение:** Работает только для шаблонов с **ровно одной** рамкой для вставки изображения.

### 2.3. Режим `vignette`
Работает по принципу **"все люди → N разворотов с общей виньеткой"**. Заполняет "сетку" из множества рамок и текстовых полей, автоматически создавая столько разворотов, сколько нужно для размещения всех людей.

### 2.4. Режим `personal_vignette` (гибридный)
Этот режим создает многостраничный документ, где **каждый разворот является персональным, но наследует общую виньетку с мастер-страницы**.
- **Мастер-страница** содержит общую виньетку со всеми портретами (`portrait_0`, `portrait_1`, ...) и подписями (`{{..._0}}`). Она заполняется **один раз**.
- **Обычный разворот** содержит персональные плейсхолдеры (`personal_portrait`, `group_photo`). Он клонируется для каждого человека и заполняется его уникальными данными.

### 2.5. Умное кадрирование (`--face_scale`)
В режимах `vignette` и `personal_vignette` скрипт интеллектуально кадрирует портреты в общей виньетке, чтобы визуальный размер и положение лиц были одинаковыми.

### 2.6. Приоритетный выбор фотографий (`--magic_word`)
Если найдено несколько подходящих фотографий, скрипт отдает приоритет файлу, в имени которого есть **"волшебное слово"** (по умолчанию `"Base"`).

### 2.7. Автоматический режим генерации (`auto`)
Это режим по умолчанию. Он говорит скрипту взять тип генерации (`sheet`, `vignette` и т.д.) напрямую из данных о шаблоне, которые были выбраны в **"Каталогизаторе"**.

## 3. Требования к данным

### 3.1. Шаблон InDesign
- **Для режимов `sheet`/`photo`**: Плейсхолдеры располагаются на обычном развороте.
- **Для режима `vignette`**: Нумерованные плейсхолдеры (`portrait_0`) располагаются на обычном развороте.
- **Для режима `personal_vignette`**:
    - **Нумерованные** плейсхолдеры (`portrait_0`) для общей виньетки располагаются на **мастер-странице**.
    - **Не-нумерованные** плейсхолдеры (`personal_portrait`) для персональных фото располагаются на **обычном развороте**.

### 3.2. Файлы с данными (JSON)
1.  `matches_portrait_to_group.json`: Основной файл со списком персон.
2.  `info_portrait_faces.json`: Файл с технической информацией о лицах. **Обязателен для "умного кадрирования"**.

### 3.3. Скрипт-каталогизатор
Перед запуском необходимо в "Каталогизаторе" выбрать шаблон, настроить карту плейсхолдеров и **задать правильный тип шаблона**.

## 4. Параметры

-   **`template`**: Имя переменной контекста с данными о шаблоне.
-   **`output_file`** (опционально): Путь для сохранения итогового IDML.
-   **`data_json_file`**: Путь к JSON-файлу со списком персон.
-   **`source_photos_dir`**: Корневая папка с фотографиями.
-   **`placeholder_image`** (опционально): Путь к изображению-заглушке.
-   **`validate`**: Запустить только режим валидации.
-   **`generation_mode`**: Режим генерации. `auto` (по умолчанию), `sheet`, `photo`, `vignette`, `personal_vignette`.
-   **`magic_word`**: Приоритетное слово в имени файла.
-   **`face_scale`**: Целевой масштаб лица для "умного кадрирования" в режимах `vignette` и `personal_vignette`.
