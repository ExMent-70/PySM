# Руководство по скрипту "Генератор разворотов InDesign" (v1.1.0)

## 1. Назначение

Этот скрипт автоматизирует процесс создания персрнальных разворотов фотоальбомов в программе InDesign. 

На входе скрипт получает одностраничный шаблон персонального разворота, список персон из JSON-файла и папки с необходимыми фотографиями, а на выходе создает единый многостраничный файл InDesign, где для каждой персоны создан свой, уже заполненный, персональный разворот.

## 2. Логика работы

1.  **Валидация:** Перед началом работы скрипт проводит полную проверку:
    *   Существование всех указанных файлов и папок.
    *   Корректность JSON-файла и IDML-шаблона.
    *   Наличие необходимых фотографий для каждой персоны. Если фото нет, будет использована "заглушка" (если указана).
2.  **Создание структуры:** Скрипт распаковывает IDML-шаблон и создает в памяти его копии — по одной на каждую персону из JSON. Он автоматически генерирует новые уникальные ID для всех элементов и корректно обновляет `designmap.xml`.
3.  **Заполнение данными:** Скрипт последовательно "проходит" по каждому созданному развороту и заполняет его:
    *   Находит текстовые плейсхолдеры (например, `{{child_name}}`) и заменяет их на реальные имена.
    *   Находит графические фреймы по их меткам (`ScriptLabel` в InDesign) и вставляет в них соответствующие фотографии (портреты или групповые).
4.  **Сборка файла:** Все обработанные XML-файлы упаковываются в финальный `.idml` архив.

## 3. Требования к данным

-   **IDML-шаблон:** Должен содержать один разворот.
    -   Текстовые поля для имен должны содержать плейсхолдер `{{child_name}}`, `{{child_lastname}}` или `{{child_fullname}}`.
    -   Графические фреймы для фото должны иметь `ScriptLabel` по шаблону:
        -   `portrait0`, `portrait1` и т.д. — для портретов.
        -   `group_photo0`, `group_photo1` и т.д. — для групповых фото.
-   **JSON-файл:** Должен содержать данные о персонах и связанных с ними групповых фотографиях. **JSON-файл:** - формируется автоматически скриптами PySM
-   **Папки с фото:** Структура папок с портретами и групповыми фото должна соответствовать меткам в шаблоне (например, фото для метки `portrait0` должны лежать в папке `.../portraits_dir/portrait0/`). Необходимая структура папок формируется автоматически скриптами PySM.

## 4. Параметры

-   **`template`**: Путь к вашему IDML-файлу с одним разворотом.
-   **`output`**: Полный путь, куда будет сохранен итоговый многостраничный IDML.
-   **`data_json`**: Путь к JSON-файлу со списком персон.
-   **`portraits_dir`**: Путь к главной папке, внутри которой лежат подпапки с портретами (`portrait0`, `portrait1`...).
-   **`group_photos_dir`**: Путь к главной папке, внутри которой лежат подпапки с групповыми фото (`group_photo0`, `group_photo1`...).
-   **`placeholder_image`** (опционально): Путь к изображению, которое будет вставлено, если нужное фото не найдено.
-   **`validate`**: Если включено, скрипт только проверит все данные, но не будет создавать итоговый файл. Полезно для быстрой отладки.

## 5. Обновления

-   **v1.1.0**: Развороты альбома формируются в алфавитном порядке.
-   **v1.1.0**: "Мягкий" поиск групповых фотографий (файлы ищутся не точному совпадению, а по вхождению).
